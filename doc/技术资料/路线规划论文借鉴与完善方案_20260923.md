## 业务与当前实现

医师选择拓扑决定工作块；点云/Mesh 提供 XYZ 几何支持；明确未选区域构成绕行约束；采集或建模缺失保留覆盖需求，需要有依据的重建或补采。每个成功规划的块内部必须连续，无法满足时列为待处理。

v4 已实现选区组件分块、受实测 Mesh 支持的贴面连接、未选像素整边避让、缺失支持分类、未完成结果保留旧轨迹。阶段 C 当前只生成独立候选表面，未准入规划。本轮补全路线质量检查及历史入口；路线坐标、算法版本、所有门限、JSON/CSV 键与格式、文件名不变。

## 本轮已实现

历史区域导出记录中，选择轨迹后点击“查看规划检查”。后台校验轨迹文件哈希、区域来源、网格与选择意图，直接分析保存的轨迹，不重新生成、不改写文件。已有旧版本可按原版本读取，并保留当前产品规则提示。新生成的 `trajectory_report.txt` 自动包含同样的检查。

`femto.planning.trajectory_quality` 按 `ordered_items` 重算：

- 链内扫描长度、连接长度、总长及连接占比；不包含跨链/跨块弦长。
- 采样步长 min/P50/P95/max 和相邻重合点数。完全相同的相邻 XYZ 只在转角计算的临时副本中合并。
- 离散转角 P50/P95/max 及最大的五处位置；列出工作块、链、route_index、row_index、W0 XYZ 和连接/扫描属性。0° 是同向，180° 是反向。该值依赖采样密度，不是曲率或机械臂关节角。
- 全部行距样本的界内、超差、不确定、不可测计数。按 `measurements` 重新计数，不用过滤后的有效分布代替完整检查。无样本明确待复核；全采样界内仍不推出全表面覆盖。
- 逐块待处理清单：断链、禁区阻断、实测表面不连通、无支持、缺少参考深度、深度冲突、未规划碎片、丢弃切片片段等。即便 `status=planned`，有几何待确认像素仍列为待处理。

此处待处理是检查报告，不是新增的自动发布门禁；既有 `result_complete` 和历史清理策略不变。空间单链连续、行距满足、平顺性和工具覆盖是不同性质，报告不合并为一个“通过”。相关 JSON 继续 `execution_ready=false`、`physical_accuracy_verified=false`，`orientation_fields=null`。

本项目近期最值得借鉴的是 **Boustrophedon 内部分区 + 已有受约束贴面连接**。拟议流程：

1. 只在一个医师选择组件内部分析行区间的分裂与合并，生成内部扫掠单元；明确未选孔洞保持障碍，选中但缺几何的像素保持待确认覆盖需求。
2. 单元内继续逐行折返；依据邻接关系组织单元访问次序。不要因拆成多个单元就把同一个医师工作块改成多个“成功小块”。
3. 单元之间的过渡必须沿同一工作块内可信支持面，整条连接不能穿过未选像素；几何上无证据连接时保留待处理，不画一条直线宣称解决。
4. 对相同选区比较当前 v4 与实验算法的链数、连接长度、重复经过、全量行距分类及最大转角；完整覆盖还要另有工具作用范围模型。

这是一项待实现的实验算法设计，不是本轮检查功能已经完成的算法替换。即使邻接图可遍历，也不保证零重复经过、最短路径或治疗剂量均匀；连接段是否允许工作属于后续业务决定。

## 后续实现补充：可信面内连接缩短（v4.1）

2026-09-23 在上述检查之后增加局部连接优化：保持扫描行和已成功的边界折返，只缩短网格边回退路线。连续同面折线在整边选区检查通过时改成面内弦线；跨面交点仅沿两支持面的真实共享边移动，每段仍落在原实测三角面上。该方法是项目内的保守实现，不声称复现 Heat Method、BCD、NUC 或 NURBS 论文。它不涉及新的平滑容差，不解决缺面，也不能替代下面的行序、行距与覆盖研究。方法、版本兼容和真实对照见 [v4.1 交付记录](../历史开发记录/三维路线连接优化_v4.1_交付记录_20260923.md)。

## 后续研发顺序

1. **带孔选区内部分区**：优先用 Boustrophedon 的连通性事件与单元邻接思想研究块内扫描顺序，保持医师工作块身份及绕行约束。测试环形、C 形、多孔、窄通道、同高度分裂/合并、缺面与多块混合场景。采用显式实验算法，保留冻结 v4 可复现。
2. **曲面间距优化**：以曲面距离或误差反馈调整下一行。先用平面、斜面、圆柱/球面及带洞选区对照，比较完整行距上下界与漏扫；测地算法仍需受选区约束。近似距离先做对照分析，不能悄悄替换有界判定。
3. **受约束折返平滑**：仅在同工作块的已有可信支持面内试验 NURBS/样条。每条候选曲线固定已绑定的端点，检查采样与整条边的面支持、未选像素、禁区和源面归属；曲线不满足时不准入。不能用简单 XYZ 样条穿过孔洞，也不能平滑跨块 gap。
4. **覆盖模型**：用户提供有效作用宽度、期望重叠及边界处理规则后，再研究工作覆盖带。论文中的 `行距 = 宽度 × (1 − 重叠率)` 只适合作为模型起点。覆盖遗漏、重复经过与连接段是否工作须分开记录。
5. **缺面修复闭环（独立前置条件）**：继续阶段 C 的证据核验、跨视角诊断和接缝评估；获准的派生几何单独保存并注明来源，再研究如何进入规划。不能补齐的像素列入补采需求。它不必等上述优化结束；缺乏支持时，上述算法也不能输出完整结果。

以上涉及新算法、补面准入、允许拟合偏差/曲率、有效作用宽度/重叠或派生数据层的内容尚未实施，尤其阶段 C 的八项用户决定仍见 [待决项文档](三维表面轨迹_选择组件分块与派生表面待决项_20260923.md)。当前没有从论文照搬门限，也未声称完成实物或临床验收。

# P4 严格路径构造与支持契约

P4 提供显式启用的 `constructed-surface-route-v1` 和 `constructed-coverage-refined-surface-v1`。默认生成仍为 `quality-constrained-surface-v3`；旧 v3、P3 和覆盖文件按其保存版本读取。新版本证明当前输入数值网格中的构造支持关系，不提高原始测量精度，也不把宽度、质量或物理覆盖升级为精确证明。

## 构造来源与坐标

沿用 W0／RDF／米、P1 的完整源 Mesh 和 `float32 → float64` 规范网格。原始完整场景 RGB-D、原网格、原选区和目标数组不修改。路径支持在与导出 PLY 相同的区域网格上计算；面编号是区域局部面编号，通过修订中的 `triangle_indices` 对应完整源网格。边和顶点编号是该绑定区域网格的顶点编号，不能解释为另一个网格的同名编号。

每个新路径点有 `surface_anchor`：

| 字段 | 语义 |
| --- | --- |
| `schema` | `femto-constructed-surface-point-v1` |
| `face` | 绑定区域网格中的支持面 |
| `barycentric` | 三个非负、和为 1 的精确有理数 |
| `edge`、`edge_parameter` | 恰在边内时，两个有序网格顶点编号及从较小编号至较大编号的参数 |
| `vertex` | 恰在顶点时的网格顶点编号 |

有理数保存为既约 `[分子, 分母]`，分母严格为正，整数不能使用布尔值；分子绝对值和分母各不超过 4,096 bits。读取方不得通过浮点数中转大整数。边／顶点字段须能从同一重心构造唯一重现，错误附加字段不接受。

`xyz_m` 是构造点的舍入显示值。内核将重心坐标作用于规范网格的精确二进制输入值，重建权威点；不把舍入 XYZ 当作恢复共面关系的依据。输出面、重心、边参数、显示 XYZ 和绑定修订共同保存。CSV 新增 `surface_anchor_json`；显示、播放和图示使用同一条已接纳轨迹，不在保存时重新生成另一条路线。

## 支持判定

低层实现为 [surface_support.py](../../femto/geometry/surface_support.py)，不导入规划、Qt、VTK 或设备层。`MeshSupport.chord()` 的方法为 `exact-constructed-chord-intervals-v1`，结果有三态：

| 状态 | 结论 |
| --- | --- |
| `passed` | 在所声明的有效域和同一工作块内，整个参数区间 `[0,1]` 有数值表面支持 |
| `rejected` | 精确区间并集留下正长度缺口，或两个端点属于不同工作块 |
| `unconfirmed` | 退化候选面、表示预算或计算预算使结果未能确定 |

同面重心构造可由三角形凸性直接证明；共享边／顶点可以在另一端的 incident face 上精确重表达同一点。其他情况先用向外包围的浮点 AABB 排除，再对必要候选做精确共面及重心区间裁剪。只合并相交或端点相等的区间，不闭合任何已知正长度微缝。浮点筛选不承担模糊情况的直接接纳。

非共面孤立接触记录为 `isolated_contacts`，不能补足正长度支持区间；真正退化面没有二维支持语义，可能影响缺口时保留未确认。零长度段在有效构造面内可通过支持检查，覆盖种子生成仍排除零长度扫描边。所有候选面限制在原有效域及端点所属工作块，最终路径另外核对工作块归属。

记录 `support_queries`、`construction_fast_paths`、`interval_queries`、`face_checks`、`filter_comparisons` 与 `aabb_rejected_faces`。`interval_queries / support_queries` 表示进入区间求解分支的比例，包含因预算不足退出的尝试；不能解读为物理误差率。

## 从常规路线构造新候选

[strict_path.py](../../femto/planning/strict_path.py) 接受已验证且带原目标台账的 v3 路线。每个原点在其原支持面上作精确最近点构造；这是新候选，不证明原 XYZ 本来就在该面内。两端的精确弦先检查支持，必要时仅在真实共享两个顶点的边上求精确最近交点候选，再分段验证。支持区间边界保留，采样数通过精确平方比较满足原步长。

所有新子边重新调用原质量、作用宽度、参考残差、边界检查及严格支持接口。显示点与权威点之间的精确 L1 位移上界并入原包络半径，增加时向外舍入。原质量和边界计算继续保留其已有数值语义，不声明所有外包计算都获得了精确误差证明。

未构造、支持拒绝或质量拒绝部分保留断点。空结果阻断安装；部分结果记录已处理原边数、原边总数、逐边原因和停止原因，不缩小原目标。旧 `quality_constraint` 与 `reconnection` 报告作为常规路线基线保留；新结果以 `surface_support.records`、`edge_outcomes` 和当前统计为准，`checked` 仅表示已检查，不等于子边全部接纳。

默认参数均为当前工程限额，可由内部 API 调低，不能调高：

| 参数 | 限额 |
| --- | --- |
| 输入源面 | 4,000,000 |
| 累计支持面检查 | 200,000 |
| 累计 AABB 候选比较 | 20,000,000 |
| 重建子边检查／输出点 | 各 200,000 |
| 原点构造位移／共享边候选距原弦 | 各最多 `1e-6 m` |
| 最终总长度 | 不超过原总长度加 `0.01 m` |
| 新严格轨迹 JSON | 64 MiB |
| 原工作台操作期限 | 120 秒，不放宽 |

`1e-6 m` 是重构候选的工程限制，不是相机或实物精度上界。已知误差仍不得补填为零：`registration_uncertainty_mm=null`，`physical_accuracy_verified=false`，`execution_ready=false`。

无可保留结果和构造预算失败保存到新派生目录 `strict_attempts/attempt_*.json`；先完整写入并同步，再发布失败记录。失败记录不能作为有效路线导入。取消和失败不替换当前路线、覆盖或目标缓存。

## P2／P3 与版本绑定

新严格修订的 `algorithms.support` 绑定原 v3 计算摘要、原轨迹语义摘要和预算；目标身份与所有目标数组保持，台账清单只为新计算修订重绑定。严格重建和恢复常规路线都移除当前旧覆盖，需另行核验 P2。覆盖继续使用 `layered-anchor-ball-subedge-coverage-v2`，路线绑定为 `femto-accepted-constructed-coverage-source-v1`，包含精确锚点和构造报告；种子、名义作用模型与既有 P2 证明语义不变。

严格补充另用 `constructed-coverage-refined-surface-v1`。候选排序、名义增益、共同分区及 P3 限额沿用 [P3 契约](P3_补充规划与覆盖增益契约.md)。新增候选及共享面图输出都须重建精确锚点，再重新逐边验收。已保留严格路径及连接两端的原锚点不移动，不能靠第二次投影修改保留路线。连接输出不能通过时保留断点；支持预算退出明确记录。原 P3 容差验收流程不改写。

当前新建补充操作使用显式绑定的 v2 参考筛查与对称短段策略；参考筛查不替代严格支持，新增扫描及实际采用的连接仍完整构造并验证。过长可选连接保留断点，原累计限额不扩大。旧无策略字段的 v1 报告按原规则重放，详见 [候选诊断与性能优化契约](覆盖与回读优化_候选诊断契约.md)。

每轮仍完整重算当前试验路线的 P2 覆盖并比较共同分区；严格补充报告保存新增支持工作量、构造来源及逐边支持记录。覆盖输入排除引用自身的 `refinement` 报告，其来源和预算已绑定到修订；完整补充报告在独立回读时重放验证。恢复补充前严格路线时，可恢复其完全相同的原覆盖；继续恢复常规路线时清除当前覆盖。

## 保存、读取与交互

[strict_validation.py](../../femto/planning/strict_validation.py) 验证规范有理数、原边顺序、工作块、预算、构造报告与当前修订；有 Mesh 时，从绑定原路线完整重建，并比较最终路线、构造和逐边决定。无外传区域时使用修订内的原选区，不放弃工作块限制。新版本的上下文保持参与验证，不能通过重算外层哈希替换原路线绑定。

原生包保存 `surface_support_report.json` 并纳入完整性清单；读取时必须与 `trajectory.json` 中的报告相同。常规包混入孤立严格报告亦拒绝。新严格轨迹仍完整保留原 v3；原生 `reproduce=True` 从绑定输入重新生成原 v3 后核对。便携 ZIP 保留原目标资产和完整轨迹；严格 P3 同时保留最多三组独立覆盖证书，缺件、孤立或混合轮次均拒绝。沿用原 P3 同一次双包保存的进程内验证凭据，独立读取仍完整重放。

Qt 路线页只在带台账的常规 v3 提供“严格重建路径”；严格基本版本提供“恢复常规路线”，覆盖已重新核验时可“严格补充规划”。补充版本先恢复补充前路线；历史只读页隐藏所有修改入口。工作仍在冻结输入后台任务中执行，模型、修订、代次及完整计划摘要均参与迟到结果拦截；纯导航保留结果，真正改变上游输入才失效，成功后重新人工核对并保存新版本。

此阶段没有引入依赖、设备控制、3DGS／SPZ／Web、变宽作用模型或跨会话配准。解析真值、真实回放、性能和最终回归分别见 [P4 交付记录](../历史开发记录/严格路径构造与几何判定_P4_20261009.md)。

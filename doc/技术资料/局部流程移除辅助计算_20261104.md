# 局部流程移除辅助计算

## 范围和行为

按用户要求，选区后局部重建直接不再执行只供显示或辅助报告使用的计算，没有新增“按需生成”步骤或算法选择。后续仍为固定参考图上的原选区 → 局部重建 → 模型检查 → 几何路线 → 保存与回读。非选区的旧场景演示、研究与训练入口保持原有行为。

| 模块 | 调整及保留内容 |
| --- | --- |
| `pipeline/scene_reconstruction.py` | 局部流程不估计点云显示法向，不做全云到网格距离与层一致性统计，不导出 Gaussian 初始化、多帧纹理和相机轨迹展示 PLY；不预备纹理视图缓存。保留全部原始深度输入、位姿、选区映射、测量网格、网格法向、观测支持和小分量过滤。 |
| `geometry/fusion.py` | 局部中间导出仅写完整 PLY 和基本数量记录；不为辅助拓扑统计创建 Trimesh 或枚举边/分量。最终路线导出及其他调用默认不变。 |
| `pipeline/complete_demo.py` | 不生成局部 RGB-D 拼图、演示 HTML、综合结果报告或 Nerfstudio 训练目录；JSON 来源、处理状态及验证记录仍保留。 |
| `local/local_processing.py`、`pipeline/local_offline.py` | 局部后台作业不在每次状态更新时写 HTML。发布仍检查来源、会话、完成回执、模型和选区资产，支持取消、失败回滚和迟到结果隔离。 |
| `reconstruction_profile.py`、`pipeline/reconstruction_sources.py`、`annotation/odometry_reference.py` | 显式识别 `local-route-geometry-v1`，不再用“Gaussian 已初始化”的旧状态描述局部结果；旧结果按原规则识别。 |
| `viewer/scene_demo_viewer.py` | 兼容没有 Gaussian 的新局部模型；不在打开时重新估计被删除的点云法向，隐藏不可用的点云法向着色。固定参考 RGB、网格顶点颜色和模型检查仍可使用。 |

局部结果状态为 `complete_local_geometry`。被移除的诊断记为 `not_computed`，不写零值或“检查通过”。实际相机位姿仍随原 RGB-D 来源绑定；删除的是展示文件。点云的点序、坐标和颜色保留，因不再存储显示法向，点云 PLY 字节允许变化。

## 路线契约

单个实际贡献帧仍用像素邻接建面；多个实际贡献帧仍用原局部 TSDF。未采用此前的单帧稀疏 TSDF 原型，未降低网格密度、放宽门槛或补造表面。原选区及支持带保持，周边不作为路线目标。

没有修改路线生成、作用宽度、重叠率、沿线采样、整边支持、参考深度、断点处理、坐标系或保存回读算法。工作台已有的目标面积按需计算保持；未计算的面积不能声称已覆盖。`SaveValidationSession`、独立回读、源文件与计算修订核验继续执行。

新的重建产物配置与旧产物共存。新程序可读取旧重建；旧程序可能因状态或辅助文件缺失而拒绝新重建，应使用当前源码。路线/便携工程格式本轮不变，也不修改已有保存资产。

# 专利申请选题建议：参考深度一致性约束的体表覆盖路径生成

日期：2026-09-30。性质：供技术交底与代理师检索评估的具体选题，不是已通过查新或保证授权的结论。

## 推荐选题

**一种基于参考深度一致性约束的体表覆盖路径生成方法**

申请对象为计算机处理采集数据、筛选有效表面域并生成路径数据的方法。当前不把治疗执行、临床覆盖合格、呼吸补偿或补扫自动更新写成已实现能力。正式名称及权利要求客体由代理师结合具体内容审定；仅改为数据处理名称不能自动排除治疗方法相关问题。

## 要解决的具体问题

重建网格可能在参考深度缺失、冲突位置仍保留表面。如果只在网格上检查路径中心或仅按工具半宽缩进，生成的路径覆盖范围仍可能进入缺少实测支持的位置。另一方面，删除不可靠面后，不能把原先选中的缺失范围误记成无需覆盖或已经完成。

## 拟交底的具体技术链

1. 将原始参考深度、选区、网格投影及投影关系绑定，在同一参考图上区分质量支持、缺失和冲突，并记录观测深度与网格投影的残差。
2. 根据参考图质量支持筛选原网格面；当前实现要求三角面投影顶点包围矩形内全部像素均为选中且一致支持，保留原始面索引与几何。
3. 将筛选后产生的内部边界与外边界共同用于候选路径约束；不能只检查医师画出的外轮廓。
4. 对扫描边与连接边均实施整段检查，结合有效作用半宽与局部观测残差，并检查真实网格支持及参考投影包络；拒绝不合格边并分段。
5. 保留原始选择需求；将质量缺失范围记录为待检查/补扫，不为没有几何支持的位置编造三维坐标，不将成功生成部分路径判为全部目标完成。

独立项可围绕步骤1—4的相互依赖构建，步骤5是否进入独立项需看其对后续计算的作用，不应仅以界面提示主张技术贡献。包围矩形、积分图、哈希和版本字段适合作为具体实施例或从属候选，不能因实现具体就当然认定有创造性。

## 当前代码基础

- `femto/planning/quality_constrained.py:evidence`：形成参考质量证据及观测残差。
- `femto/planning/effective_domain.py:build`：原网格面筛选及有效域；`:missing_regions`：原选区缺失需求清单。
- `femto/planning/quality_constrained.py:edge_checks`：扫描/连接边的整段支持与余量检查；`:constrain`：拒绝边分段与报告。

残差是深度/网格的观测差异，不是校准误差上界或统计不确定性。有效域是合格面子集与隐式路径谓词，不是已经构造完整预内缩网格。仅复核代码事实，本轮未运行新实验。

## 必须正面对比的已有技术

1. CN109069855A（2018-12-21公开）：扫描、三维图像、表面ROI与引导路径；故不主张宽泛体表选区流程为创新。
2. CN108422670A（2018-08-21公开）：非连续栅格三维点云路径，权2已有边界误差控制、线宽与半线宽缩进，权6已有空洞处关闭/抬升喷头；说明书实施例涉及皮肤缺损模型。故不能把“误差＋半宽＋空洞”这个泛化组合视为尚无公开。
3. WO2014145471A1：复杂表面分区、几何不确定性与完成状态。
4. arXiv:2201.04310v1：测量不确定性约束、视点优化与原始测量点覆盖目标。
5. CN110123487A（2019-08-16公开）：权1包含呼吸补偿的皮肤原位打印，权9涉及依据涂布感应信息补偿打印。不能把“人体＋运动补偿＋反馈补做”直接当作备用创新方向。

本轮未在已读文献中确认“同一参考图实测一致性整面筛选→质量内部边界→半宽加局部残差整段及投影包络检查”的完整组合。但CN108422670A与质量约束文献的结合会提高创造性风险，需要进一步对比；不是检索通过。

## 可以写申请材料前还需补什么

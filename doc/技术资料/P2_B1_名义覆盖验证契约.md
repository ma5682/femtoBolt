# P2 / B1 名义模型覆盖验证契约

本模块是后续迭代方案的 B1 算法原型。它验证给定名义球模型下的表面子集；默认路线仍为 `quality-constrained-surface-v3`。正式界面、保存版本、历史回退接入属于 B2，补充路线属于 P3。

## 输入及坐标

- 工程入口为 `coverage_domain.from_plan(model, region, plan)`。依次核对当前 P1 计算修订、原 v3 路线、质量域和可重现的原目标台账。旧记录缺少 P1 台账时拒绝直接升级。
- 坐标为 W0 / RDF，长度单位为米；内参、选区和源几何沿用 P1。源顶点使用既有 `float32 → float64` 规范表示，原面编号不变。
- 纯数值正反例可以调用 `CoverageDomain.mesh()`，范围明确为 `declared_nominal_mesh_only`，`acquisition_geometry_verified=false`。手工声明的种子不代表通过 v3 路线准入。
- 原目标、原路线、源 Mesh 与 RGB-D 不修改。覆盖细分是新的派生层；质量剔除和预算不足均不缩小已定位原目标的面积分母。

## 固定名义作用模型

`footprint_model.nominal(width_mm)` 生成 `femto-nominal-fixed-ball-v1`，宽度范围为 `(0, 1000] mm`，记录半径 `width_mm / 2000` 的二进制浮点数值。转换后半径必须仍为可表示的正数。

模型假定中心偏移为 0；真实中心偏移上界、配准误差和标定误差均为 `null`。没有把未知物理误差写成零，也没有建立物理作用或临床精度结论。所有结果保持 `execution_ready=false`、`physical_accuracy_verified=false`。

工程种子只来自已接纳的非零扫描边端点。边的角色由右端点决定，沿用 v3：`role='connector'` 不作用，缺省或 `null` 的角色为扫描。公共端点按“源面 + 原 XYZ”去重；仅连接段不会产生种子。完整轨迹摘要与 ordered-items 摘要同时绑定，不能拿其他路线的证据替换。

## 精确数值构造与证明

### 原单元和锚点

P1 的浮点裁剪单元仍是原目标与名义面积台账。B1 根据规范源顶点、内参和半像素边界，以有理数重新构造每个 `source_face / pixel_index / child_index` 三角单元；不把 P1 已舍入的 XYZ 当作精确构造。若同父单元的精确正面积 fan 编号与 P1 不一致，保留 `target_construction_unconfirmed`，不重新分配原身份。

路线点 `p` 不移动。只在它声明的支持面上精确构造正交投影锚点 `a`，并核验锚点在该面内。以原半径 `r` 构造内球半径 `r_in`，满足：

`r_in > 0` 且 `r_in + ||p - a|| <= r`。

距离上界和半径扣除使用向外舍入，并以精确距离平方校验。极小距离先缩放再开方，避免平方下溢导致逐 ULP 校正失控。没有有效面内锚点或扣除后半径非正时，该种子保持未绑定。这个扣除只处理数值构造偏移，不是物理误差标定。

### 整单元确认

同一个内球包含三角单元全部三个顶点，才可依据球的凸性确认整个平面三角单元位于球内。多个球分别包含不同顶点不能合成整面证明。

快速筛选使用批量浮点区间，各减法、平方及求和向外舍入；区间无法决定时回退有理数比较。空间网格及单元包围盒仅排除不可能候选，不产生正覆盖结论。正面积交叠但未完全包含的单元按精确中点四分。

### 球内连通与多球并集

每个球分别建立到其锚点的证明树。树根是包含该锚点、与种子同源面且整面在该球内的叶单元；后续单元必须通过正长度的公共子边连接，且整条树链始终使用同一个球。

- 原面边以原顶点 ID 对为键；原面内部边以精确重心平面直线为键。
- 粗细叶单元用公共子区间正长度重叠维护邻接；仅碰顶点不能连接。
- 不按 XYZ 距离焊接邻近或异层面。即使网格全局连通，绕到球外再回来的路径也不能建立该球的覆盖证明。
- 完全重复的规范几何面按 P1 规则只计一次，重复面种子映射到保留的代表面；普通相邻面仍须共享原拓扑 ID。
- 根证明一旦成立即保留，后续全局拓扑计算超预算不会抹去它。多球仅在最终叶分区上求并，每片叶面积最多累计一次。

当前策略在某单元已被至少一个球完整包含后停止细分。它可能漏掉其他球需要进一步细分才能建立的连通路径；因此未确认不能解释为已证明未覆盖。

## 面积与状态

`root / depth / code` 可重建叶单元。每个原单元的叶权重为 `4^-depth`，用整数 dyadic 权重核验其完整分区之和恰为 1。面积统计采用“P1 名义原单元面积 × 叶权重”；该数值不是物理面积或浮点面积误差的严格界。

| 状态码 | 字段值 | 含义 |
| --- | --- | --- |
| 1 | `confirmed` | 同球整面包含及到锚点的公共子边证明已成立 |
| 2 | `quality_excluded_or_pending` | 原 P1 质量资格不可用，包括剔除、区域外或待核验 |
| 3 | `outside_inner_seed_balls` | 当前内球种子不能确认该单元；不代表连续扫掠或其他模型均不覆盖 |
| 4 | `ball_connectivity_unconfirmed` | 整面包含候选存在，但到种子的球内连通尚未确认 |
| 5 | `subdivision_limit` | 已达细分层级上限 |
| 6 | `target_construction_unconfirmed` | 精确重建与原 fan 身份不能一致绑定 |
| 7 | `budget_unprocessed` | 计算预算下未处理完的单元 |

只有全部原单元确认、原目标构造完整、无未知像素、无质量排除且无预算标志时，才返回 `model_coverage_complete`。空目标和零种子不算完成。部分定位像素仍计未知；未知面积为 `null`，不能把已定位面积当成完整目标面积。

## 预算与取消

| 项目 | 默认值 / 上限 |
| --- | --- |
| 原目标输入单元 | 200,000 |
| 新增叶单元 | 200,000，按相对原目标的新增量计算 |
| 最大细分深度 | 默认 4，显式配置最高 8 |
| 已绑定种子 | 20,000；原始输入记录最多 400,000 |
| 包含/距离比较 | 1,000,000；空间索引候选另记 `spatial_candidates` |
| 邻接比较、证明节点 | 各 1,000,000 |
| 覆盖计算时间 | 45 秒，可调低 |
| 数组 / 清单资产 | 256 MiB / 1 MiB |

预算耗尽保留原目标分区，并给出 `calculation_incomplete`。最大深度达到上限也会记录未完成；此时仍可能存在有效的部分确认集合。时间预算按确定性步骤记录停止边界，回读在相同步骤复算；不要求两次机器耗时相同。

取消检查贯穿种子、单元、邻接、证明和资产处理，取消异常向上传播。数组大小限制不是整个 Python 进程的内存硬限；峰值内存另行实测。CLI 外层还设置 600 秒总任务期限，包含工程读取及回读复算。

## 独立归档与复算

证据 schema 为 `femto-model-surface-coverage-prototype-v1`，算法为 `exact-anchor-ball-subedge-coverage-v1`。独立目录只含：

- `coverage_certificate.json`：原目标 / 修订 / 路线 / 作用模型 / 种子摘要、预算、统计和数组描述。
- `coverage_certificate.npz`：叶身份、状态、见证索引、逐球证明树及种子记录。

`coverage_archive.save()` 使用既有 staging / publish，回读复算通过后原子发布到新目录；已有目录拒绝覆盖。失败或取消清除本次 staging，不安装部分结果。

`coverage_archive.read()` 必须收到来自调用方可信来源的 domain、seeds、footprint 和 route binding。读取检查清单上限、NPZ 条目精确集合、重复条目、压缩方式、解压总量、NPY 版本/头长/shape/dtype/字节长度，禁止 object 与 Fortran 资产，再使用原输入完整重算。重新计算外层 SHA 不能绕过见证、面积、索引或修订核验。

研发入口：

```powershell
.venv\Scripts\python.exe -X utf8 tools\check_nominal_coverage.py evaluate --project <P1方案.region.zip> --output outputs\coverage_experiment_001
.venv\Scripts\python.exe -X utf8 tools\check_nominal_coverage.py verify --project <同一P1方案.region.zip> --archive outputs\coverage_experiment_001
```

`--case <数值实验.json>` 可代替 `--project`，JSON 必须声明 `femto-nominal-coverage-case-v1`、`world_rdf`、`metre`、vertices、faces、seeds、完整 footprint 和两个 false 标志。工程读取在临时的 `outputs` 工作目录内进行，源便携文件不改写。

原 P1 `planning_context`、`target_surface` 及正式 region ZIP 字段不扩展；旧采样覆盖率保持原名和原语义。本原型证据不能冒充 B2 的正式产品保存或历史版本。

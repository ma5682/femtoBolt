# 标注、测量与规划约定

> 本文保存从 `CLAUDE.md` 迁出的完整标注、测量和区域规划细节；W0、坐标、精度与执行边界仍保留在 `CLAUDE.md`。

当前工作台新路线保持既有 v3，并带独立的完整计算修订及质量筛选前原目标台账。新增 `planning_context`、`target_surface.json` / `.npz`、读写校验、预算和旧记录语义以 [P0／P1 数据契约](P0_P1_目标台账与计算修订契约.md)为准。它补充本页的原有格式，不将名义面积或旧采样覆盖解释为覆盖证书。

蛇形生成的共享面图在每次搜索中独立准备一次 `ReferenceEnvelope`，其质量分类、微米残差、内参、积分图及绑定网格／允许面数组只读。仅复用准备结果；每个原检查批次使用独立的残差邻域工作计数，完整边谓词继续处理同一顺序的所有候选，有限细分深度、图累计检查和点数预算保持。外部 `edge_checks` 及保存／独立回读仍重新校验各自输入，没有“已验证”跳过标志、跨请求缓存或边接受缓存。P3 继承该共享面图时仍按原方式计入每条边；候选和覆盖调度版本不变。诊断阶段只输出耗时，失败和取消仍传播。验收须同时核对完整操作耗时、逐点及逐边结果、断点／排除报告、图工作计数、目标台账数组、取消保留及真实保存回读；不得以缩小选区、减点或放宽约束取得提速。

## 标注、测量与区域规划

- 产品默认 `mesh-slice-serpentine-v4.4`（2026-09-23，用户允许调整块内访问顺序）：每个实测碎片内按相邻切片 e1 区间的互为唯一正重叠形成条带，先扫完局部蛇形再按确定性入口距离访问下一条带。首段与首段方向、全部原扫描段/样本、物理行身份、选择组件与碎片边界不变；所有新邻接重新生成 gap 并走 v4.3 贴面路由，廉价入口距离不证明连接可行。原行距采样/测量保持规范扫描顺序，仅在全体查询顶点确定后停止当前层 Dijkstra，报告只允许实际展开次数减少，不改距离或上限。v4.4 合并链允许回访低行号，但逐点绑定块与实测碎片行范围；CSV 行号按逐点真实行导出，播放器只用精确行号+XYZ 对应定位。旧算法及旧逐整行访问顺序保留历史重算，不用于新生成默认入口；API 默认仍 v4，CLI 新增 `--selection-v4-3`。schema、JSON 固定键、文件名、采样/搜索/测量门限、W0 与安全标志不变。

- 保留的旧版 `mesh-slice-serpentine-v4.3`（2026-09-23）：继承成功的 v4.1 连接，仅把补充面内搜索换成有向双端 A*；两端共享原候选/节点/可见性预算，反向扩展按最终正向运动验边，达到完整路径下界才结束，不在首次相遇时结束。节点合法性、全像素包围盒与原禁区边界包围盒排除共同证明面内可见时可批量判定，边界不确定仍逐条原谓词检查，最终采样验真不省略。旧 v4/v4.1/v4.2 精确重算，API 默认仍 v4；120 秒与 200000 各类搜索/总采样上限不变。大区域搜索超限和最终轨迹总点数超限是两个限制；后者不得删点、改步长或分批截断来伪装成功。详见 [交付记录](../历史开发记录/三维路线大区域搜索优化_v4.3_交付记录_20260923.md)。
- 复杂禁区判定性能优化（2026-09-23）：`surface_polygon_index.PreparedPolygonIndex` 仅在一次规划/校验上下文内预处理不变多边形边数组与包围盒，原奇偶规则、`1e-9` 包围盒容差与 `1e-12` 相交乘积容差保持；命中的候选边仍走原标量谓词。诊断临时替换禁区时重建，跨校验不复用旧约束；不改变算法版本、轨迹结果、文件格式、120 秒任务预算或节点/采样预算。详见 [性能交付记录](../历史开发记录/三维路线复杂禁区判定提速_交付记录_20260923.md)。
- 保留的 `mesh-slice-serpentine-v4.2`：继承 v4 医师选择组件、三种断开、单面支持和整边未选/禁区约束；保留 v4.1 成功路线，仅失败时经真实流形共享边内部的投影像素区间候选点进行单端面内补充搜索。不跨未选区、块、碎片或缺面；有限候选搜索失败仍待处理。旧 v4 API 默认及 v4/v4.1 原版重算保留，CLI 可显式选择旧版；API `selection_algorithm` 只用于版本分派，不另存 JSON 参数键，已有 `planner.algorithm_version` 是版本依据。新旧版播放均只读校验、不重规划，选择组件模式仅绘真实掩膜轮廓，不绘旧多边形跨块桥线。阶段 C 待决、全部门限与安全标志不变，详见 [v4.2 交付记录](../历史开发记录/三维路线面内补充连接与显示修正_v4.2_交付记录_20260923.md)。
- `annotations.json` `version=1`：绑定源网格绝对路径、几何 SHA-256、`world_rdf`/`metre`、`local_context`、`origin_reference`、`data_layers`（`femto-data-layers-v1`，按字典相等作为绑定键，改它会让所有旧标注/路径/记录不可回读）。每次保存新建目录；回读时 `distance_to_origin_m` 与两点距离总是从 XYZ 重算，磁盘不回写。区域以 `triangle_indices` 为准，边界每次重算，孔洞保留，`exclusion_polygons` ≤32 个、每个 3–512 角点。
- 选择意图（2026-09-23 起，`femto.annotation.selection_intent`）：固定 RGB 页保存的区域在 `region.selection_intent`（`femto-selection-intent-v1`）里带最终涂抹掩膜（行优先游程 + SHA-256）、涂抹禁区掩膜、4 连通选中组件、8 连通内部未选孔洞（含所属组件与其中禁区像素数）、组合方式与 `missing_geometry_policy=retain_coverage_requirement_not_unselected`；掩膜是医师意图的权威记录，`triangle_indices` 只是派生几何绑定（`selection_rule=visible_triangle_centroid_pixel_in_selection_mask`，面心像素在掩膜内且通过遮挡 / 深度 / 有效像素门禁）。`region.selection_support`（`femto-selection-support-v1`）逐像素记录 measured_mesh / no_surface_reference_depth_present / no_surface_no_reference_depth / outside_depth_range / depth_conflict / no_source_pixel（证据仅参考帧原始深度与绑定网格）。回读时意图重算拓扑比对、支持记录按证据重算并锁定 `depth_range_m`、`source` / `evidence` / 类别映射 / 解释口径与 `derived_surface`（必须为 `not_generated` 记录；`validate_selection_support(..., expected_depth_range_m=)` 供知道数据集重建范围的调用方核对），篡改或缺失拒绝；`set_exclusions` 只从掩膜减像素；两条记录都在 `region` 内，因此进入 `region_signature`，旧记录无该键、签名不变。三维表面轨迹 v4 以此定义工作块，见《三维表面轨迹_选择组件分块与派生表面待决项_20260923.md》。阶段 C 目前只有 `femto.planning.derived_surface_candidates` 的候选诊断（`femto-derived-surface-candidates-v1`，`status=candidate_not_admitted`）：绑定逐视角原始深度 / 标定 / 位姿（支持记录的深度范围须等于数据集 manifest 的重建范围），候选面整面像素必须属于同一选择组件，写入导出目录下 `derived_surface_candidates_<12hex>/`，回读重新绑定并逐字比对全部原始证据，不进入 `selection_support`、规划或轨迹。
- 固定 RGB Qt 规划页（`qt_planning`）：K6 去畸变初始照片 → 射线打到 W0 网格首次命中；参考深度在量程内时要求 |z_hit − depth| ≤0.01 m 否则 `depth_conflict`；无参考深度但有网格命中记为 `new_support`（青色，不是覆盖率证明）。单 worker、120 s 预算、代际计数丢弃迟到结果。它也是 `.region.zip` 规划工作台的宿主（传文件而非目录时启用规划页签）。
- 区域规划：`region_project.save_project/open_project` 原子写 ZIP（`femto-region-project-v1`，≤1 GiB，逐文件 SHA），工作副本在 `outputs/region_workspaces/`；路线算法 `region_path.raster_path`（像素行）、`metric_region_path`（网格边最短距离等值线，≈5 mm）、`serpentine_path`（水平蛇形 v1/v2）、`region_coverage`；结果带 `plan_binding`（`femto-plan-binding-v1`：区域指纹、几何 SHA、参数、算法版本、结果摘要），`planning_state.state()` 决定按钮可用；名称/备注不进区域指纹，禁区或三角面变化使旧路径失效；采样预算 200000 点。`route_motion` 只是按弦长恒速的播放演示。
- 治疗头参数（2026-09-24，`femto.planning.treatment_head`）：轨迹目录可带 `treatment_head.json`（`femto-treatment-head-parameters-v1`，绑定 `result_sha256`、列入文件哈希清单）。只有 `row_spacing_mm` 进入规划器参数（直接指定，或有效宽度 ×（1 − 重叠率），0.5–100 mm 外拒绝不夹取）；治疗深度、治疗头直径、安全边界为 `recorded_only_not_used_by_planner`。几何覆盖估算规则 `region_face_centroid_within_half_effective_width_euclidean_3d_of_nearest_scan_sample`，连接段不计，`claim=geometric_estimate_on_measured_region_mesh_not_treatment_coverage`、`decision_use=none`；`load_trajectory` 回读时重算并逐字比对。
- `measurement_audit`：手工尺量记录（`femto-manual-distance-test-v1`）与只读证据审计，`physical_accuracy_verified` 恒为 False。

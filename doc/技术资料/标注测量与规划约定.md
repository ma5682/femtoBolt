> 本文保存从 `CLAUDE.md` 迁出的完整标注、测量和区域规划细节；W0、坐标、精度与执行边界仍保留在 `CLAUDE.md`。

## 标注、测量与区域规划

- 三维表面轨迹产品默认 `mesh-slice-serpentine-v4.1`：继承 v4 医师选择组件、三种断开、单面支持和整边未选/禁区约束，仅在已求得的网格边回退路线可信面内缩短连接。旧 v4 API 默认及原版重算保留；API `selection_algorithm` 只用于版本分派，不另存 JSON 参数键，已有 `planner.algorithm_version` 是版本依据。新旧版播放均只读校验、不重规划。阶段 C 待决、全部门限与安全标志不变，详见 [v4.1 交付记录](../历史开发记录/三维路线连接优化_v4.1_交付记录_20260923.md)。
- `annotations.json` `version=1`：绑定源网格绝对路径、几何 SHA-256、`world_rdf`/`metre`、`local_context`、`origin_reference`、`data_layers`（`femto-data-layers-v1`，按字典相等作为绑定键，改它会让所有旧标注/路径/记录不可回读）。每次保存新建目录；回读时 `distance_to_origin_m` 与两点距离总是从 XYZ 重算，磁盘不回写。区域以 `triangle_indices` 为准，边界每次重算，孔洞保留，`exclusion_polygons` ≤32 个、每个 3–512 角点。
- 选择意图（2026-09-23 起，`femto.annotation.selection_intent`）：固定 RGB 页保存的区域在 `region.selection_intent`（`femto-selection-intent-v1`）里带最终涂抹掩膜（行优先游程 + SHA-256）、涂抹禁区掩膜、4 连通选中组件、8 连通内部未选孔洞（含所属组件与其中禁区像素数）、组合方式与 `missing_geometry_policy=retain_coverage_requirement_not_unselected`；掩膜是医师意图的权威记录，`triangle_indices` 只是派生几何绑定（`selection_rule=visible_triangle_centroid_pixel_in_selection_mask`，面心像素在掩膜内且通过遮挡 / 深度 / 有效像素门禁）。`region.selection_support`（`femto-selection-support-v1`）逐像素记录 measured_mesh / no_surface_reference_depth_present / no_surface_no_reference_depth / outside_depth_range / depth_conflict / no_source_pixel（证据仅参考帧原始深度与绑定网格）。回读时意图重算拓扑比对、支持记录按证据重算并锁定 `depth_range_m`、`source` / `evidence` / 类别映射 / 解释口径与 `derived_surface`（必须为 `not_generated` 记录；`validate_selection_support(..., expected_depth_range_m=)` 供知道数据集重建范围的调用方核对），篡改或缺失拒绝；`set_exclusions` 只从掩膜减像素；两条记录都在 `region` 内，因此进入 `region_signature`，旧记录无该键、签名不变。三维表面轨迹 v4 以此定义工作块，见《三维表面轨迹_选择组件分块与派生表面待决项_20260923.md》。阶段 C 目前只有 `femto.planning.derived_surface_candidates` 的候选诊断（`femto-derived-surface-candidates-v1`，`status=candidate_not_admitted`）：绑定逐视角原始深度 / 标定 / 位姿（支持记录的深度范围须等于数据集 manifest 的重建范围），候选面整面像素必须属于同一选择组件，写入导出目录下 `derived_surface_candidates_<12hex>/`，回读重新绑定并逐字比对全部原始证据，不进入 `selection_support`、规划或轨迹。
- 固定 RGB 窗口（`fixed_rgb_viewer`）：K6 去畸变初始照片 → 射线打到 W0 网格首次命中；参考深度在量程内时要求 |z_hit − depth| ≤0.01 m 否则 `depth_conflict`；无参考深度但有网格命中记为 `new_support`（青色，不是覆盖率证明）。单 worker、120 s 预算、代际计数丢弃迟到结果。它也是 `.region.zip` 规划工作台的宿主（传文件而非目录时启用规划页签）。
- 区域规划：`region_project.save_project/open_project` 原子写 ZIP（`femto-region-project-v1`，≤1 GiB，逐文件 SHA），工作副本在 `outputs/region_workspaces/`；路线算法 `region_path.raster_path`（像素行）、`metric_region_path`（网格边最短距离等值线，≈5 mm）、`serpentine_path`（水平蛇形 v1/v2）、`region_coverage`；结果带 `plan_binding`（`femto-plan-binding-v1`：区域指纹、几何 SHA、参数、算法版本、结果摘要），`planning_state.state()` 决定按钮可用；名称/备注不进区域指纹，禁区或三角面变化使旧路径失效；采样预算 200000 点。`route_motion` 只是按弦长恒速的播放演示。
- `measurement_audit`：手工尺量记录（`femto-manual-distance-test-v1`）与只读证据审计，`physical_accuracy_verified` 恒为 False。

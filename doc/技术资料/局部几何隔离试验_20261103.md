本轮仅在 outputs/isolated_geometry_20261103 下复制生产 Python 文件并修改候选。生产源码未合入任何候选，原始数据未改写。用户授权范围是逐项隔离验证和 ABBA 对照。

结论：八子盒候选在当前桌面实采的完整点云检查中显示阶段收益，值得进入下一轮更完整的接入验证。面积复用收益区间重叠；裁剪分组、面积策略查询外提、球盒排除不推荐直接合入。没有重测整套重建、生成、保存和回读，不报告整链路加速或十秒达标。

## 试验条件与结果

沿用上一轮同一 1920×1080 桌面实采、546948 点及 237306 目标像素。Windows / Core Ultra 7 251HX / Python 3.12.10 / NumPy 2.2.6 / Open3D 0.19.0。每项独立基线、独立候选，每次独立进程，按 A→B→B→A 串行执行且关闭细分计时。没有清空系统缓存或锁定系统其他负载，单样本两次候选不足以外推全部输入。

前三项测量固定已保存前沿的目标台账重放，核对全部数组和指标；后两项测量完整点云层一致性检查，核对总计数 278625。数据加载在这些子阶段计时之外，不能当作完整生成/重建耗时。

- 面积复用：保留四元素 polygon 接口，通过局部列表附属映射携带已算面积；visible 和 sum 顺序保持。32 项既有目标/裁剪/投影/面积错误策略测试通过。此候选的非默认浮点策略通知次数仍需专门对照，不能仅凭既有测试宣称完全覆盖，因此本轮不合入。
- 裁剪分组：仅遍历实际 cut 行出现的 sizes，保留 overflow 防御和原末尾 copy，32 项相关测试通过。np.unique 分组本身有成本，本候选无收益；没有因此排除其他跳过空扫描的实现。
- 面积循环：仅在单次 _pixel_target_children 内读取 under 策略，再传给原标量函数；不跨任务冻结。保留原 fallback，32 项既有测试含 ignore/warn/raise/call 及混合尺度下溢通过。尚未采用 tolist 或改变数组所有权。墙钟无收益，不推荐。
- 球盒：对当前 a,b 作向下舍入距离下界与向上舍入半径平方比较，非有限或边界不排除；非默认 NumPy 策略走原函数。30 项点云/半径/二级见证测试通过。
- 八子盒：独立于球盒试验，按粗格实测包围盒中点分类到 8 组，对各组实测极值继续原带保护的高度包络判定；空组不参与。粗格及 27 邻格遍历保持，子盒阈值附近不能证明负例时保持未定。非默认策略走原函数。30 项相关测试通过。

上述集合存在导入重复，不累加为唯一测试数量。错误策略测试中的旧参考 matmul 下溢警告保留，测试通过不代表消除警告。

八子盒减少约 31.9% 完整邻点关系；完整点云检查两次均比对应基线快约 3～5 秒。球盒排除量不足以抵消新增计算。诊断将准备和查询放在包络总阶段计时内，没有单独计量建盒时间，不能把 2.000 秒当作纯建盒成本。

两项额外检查在随机 500 点、非单位法向、0/±1e6 坐标原点上逐个核对候选证明的负例均无旧判据正例。此为有限差分验证，不是任意浮点输入的形式化证明。实采比较当前只核对最终总数；八子盒正式接入前仍需实采逐点分类差分、阈值邻接浮点/极端尺度/资源故障，以及完整重建保存回读验证。临界浮点保护需随这些测试进一步审查。

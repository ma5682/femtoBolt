# 单帧、多帧页面交互排查

本轮检查四阶段工作台，修复两处历史页交互问题，清理一个空设置入口。单帧、多帧各通过 35 项实际数据断言，原始采集及原测量重建文件均未改变。

## 已修正

| 问题 | 原行为 | 当前行为 |
|---|---|---|
| 历史页隐藏返回入口 | 切到模型/参考画面时整个图层工具栏隐藏；只有区域、没有路线的记录无法直接切回区域。同属“模型与路线”的当前阶段按钮不能代替组内切换。 | 保留图层选择与适应视图按钮；侧栏按内容收起。 |
| 三维视图勾选几何色层无可见效果 | 色层属于固定参考图，勾选后仍停在三维窗口。 | 自动切到参考图显示色层，原选区及只读状态保持。 |
| 选区页空“高级设置” | 周边宽度已固定为 0，入口内只剩说明和错误信息。 | 正常状态移除入口；失败时展开“失败详情”，重试保留笔画和撤销记录，恢复后隐藏。 |

前两项先用测试复现失败，再修正通过。失败证据在 `outputs/workflow_audit_20261105/baseline/reproduced_bugs.log`。本轮未改动 TSDF 参数、路线算法、保存格式或原数据。

## 逐节点核对

| 节点 | 核对结果与验证方式 |
|---|---|
| 01 开始、暂停、完成 | 事件测试覆盖无有效帧、单帧完成、暂停、失联、旧会话事件隔离；未操作现场相机。 |
| 01 → 02 固定参考图 | 有限 RGB-D 夹具验证选区前不启动重建、空选区不可提交、采用已保存帧及有效位姿。 |
| 02 清空、撤销、失败重试 | 两份真实参考图与原选区验证恢复一致；正常无空设置，失败保留选区。 |
| 02 → 03 重建和加载 | 成功才切换页面，失败/取消可重试，迟到结果不安装；单/多帧统一 TSDF profile。真实模型加载及生成与有限夹具重建分别验证。 |
| 03 模型、参考图、路线 | 固定选区只读，无二次涂抹/清空入口；两份实际数据的生成、播放、暂停保持同一条路线。 |
| 03 修改参数 → 04 | 改参数后旧路线不可用，不能保存；恢复原参数仍需重新核对。 |
| 04 保存与取消 | 生成前不能进入保存，核对前不能保存；双格式保存成功；忙碌切换被阻止，取消保留方案。 |
| 保存 → 历史 | 两份数据的选区和路线回读一致；图层可往返；读取失败恢复原来源标题和原记录。 |
| 历史 → 修改版本 | 两份数据进入独立模型对象，保留原 TSDF profile、选择及旧工程；版本保存、查找由回归覆盖。 |
| 规划/历史 → 采集 → 返回 | 两份数据均同来源返回，草稿模型、路线、备注保持；不发送相机指令。 |
| 新任务、关闭、失败重试 | 工作台、历史及完整流程回归覆盖上下文隔离、忙碌限制、异步结束和错误恢复。 |

## 功能与限制

- 已移除正常选区页的空“高级设置”。身体部位选择、阶段重建检查、局部规划页二次涂抹等旧入口已隐藏或退出主流程，本轮未重新暴露。
- 保留 RGB、深度、实时/累计点云，它们用于不同采集问题。“查看已保存结果”和“打开已保存方案”分别进入应用回看与文件夹；另存支持自选位置，作用不同。
- 算法试验保持折叠，面积与覆盖检查按需执行；“设备与模拟”是独立研发联调入口，不属于规划必经步骤。未删除历史读取和核验能力。
- **现有限制**：第 02 步重新涂抹依赖当前进程保留的原采集会话。重启后或仅打开历史工程时，不能直接恢复该会话重新选区。待选区原始采集仍在磁盘，当前没有恢复入口，本轮未扩展此能力。
- **范围边界**：原生 Windows 观察确认了单帧历史参考图及 VTK 三维显示；成套断言用离屏 Qt 与渲染替身。新拍相机数据、人体现场、设备断电、不同 Windows 缩放、ARM 性能及机械臂执行未验收。

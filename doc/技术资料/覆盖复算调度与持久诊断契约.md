# 覆盖复算调度与持久诊断契约

本轮针对固定作用模型的 P2／P3 性能和诊断闭环。P5 专用补线、真实偏移有界模式和 P6 跨会话继承不属于此轮实现。

## 版本与原目标

P2 首次覆盖及 P5 变宽覆盖继续使用 `layered-anchor-ball-subedge-coverage-v2`。固定名义模型在同输入下重新核验已有覆盖时，工作台使用 `retained-first-anchor-ball-coverage-v1`，先重验原确认集合再搜索剩余目标。旧 B1、B2 及 P3 v1–v4 保存包继续按原算法、候选策略和停止边界完整重放，不改写旧版本解释规则。

当前 P3 报告为 `femto-coverage-refinement-v5`，试验覆盖为 `interleaved-partition-anchor-ball-coverage-v5`，显式绑定 `coverage_policy`；当前几何候选仍为 `quality-screened-symmetric-face-slices-v2`。外层常规／严格路线版本不变。输入绑定前一轮完整证据摘要及确定性调度策略。旧 v3／v4 引擎源码保留，显式传入旧策略仍执行旧版本；策略和算法交叉绑定、参数类型改变、修改参数后重新计算摘要均不能绕过版本核验。直接 `refine(..., coverage_policy=None)` 的旧 API 语义保留。P5 变宽路线不能从此入口补线。

原目标 ID、全部原目标数组、原扫描点和严格锚点继续保留。新计算修订只重绑定头部，不能用新增确认范围替换原目标，也不能把几何缺失当作未选择。完整场景 RGB-D、源 Mesh 和旧阶段证据不覆盖。坐标仍为 W0／RDF／米，物理误差未知，`execution_ready=false`、`physical_accuracy_verified=false`。

## 同一输入的 P2 复算接纳

独立 P2 仍从当前输入重新计算，墙钟预算可能使新候选少于以前已确认的范围。安装已有覆盖的同一方案前，先核对原目标、路线、扫描种子和作用模型绑定，再以完整共同分区比较原集合。丢失整数权重只要非零，就拒绝新候选，保留原方案、原覆盖与显示；新增汇总面积不能抵消集合损失。比较支持取消，发生在任何缓存替换和显示重建之前，单列 `coverage.recalculation_admission` 诊断阶段。旧证据仍作为原版本保留，不把其状态合并到新候选，也不声称新候选重新证明了旧范围。

上游输入变化后没有原覆盖字段的方案仍按当前输入新建覆盖；显式恢复原路线使用其对应旧版本，不把其他修订的缓存当作保留依据。存在原覆盖清单但缺少匹配资产时拒绝安装；不能靠缺失缓存绕过集合检查。该接纳检查不代替计算、独立回放或发布验证。

新 P2 仅接收完全相同的 domain、route、顺序扫描种子与固定名义作用模型。使用旧输出作为不可信的分区及候选父路径提示，复用 v4 的当前球包含与正长度子边判据。全部原确认叶重验后，重新分类球外区域，为本轮已复证单元建立边索引，再搜索其他未确认单元。边索引每条边计入原邻接预算，不能跳过计数；未完成的重验不能沿用旧确认状态。索引让剩余搜索可以连接到本轮已证明的单元，单纯重验后不建立索引可能没有新增确认。

新证据附带且只附带一层 `recalculation_hint_coverage_certificate.json`／`.npz`。连续复算只保留上一份输出的清单和数组，不复制其更早提示；独立回读从当前输入重新证明本次输出，不把提示当作已验证旧覆盖。提示摘要参与计算绑定，提示及输出数组合计不超过原 256 MiB。加载前检查剩余数组限额，缺件、孤立、递归提示或篡改均拒绝。P3 的每组历史覆盖可携带这对提示；没有补线被接纳时，最终覆盖仍携带其 P2 提示。原生、便携、完整回读和发布凭据都核对实际提示资产。

## 引导分区必须重新证明

前一轮证据仅提供完整分区及候选证明路径。每次试验重新绑定当前扫描种子，重建当前原面／像素裁剪单元，并重新检查使用到的整单元球包含、锚点归属和正长度公共子边。旧 `confirmed` 标志及旧证明数组不能直接安装为新结论。

P3 v5 先选择候选父路径并完整重验原确认集合。新扫描叶按最近新种子分组，组内按锚点面、根盒距离、叶编号排序，组间每次轮取 8 叶；先访问锚点面上至多 128 叶。随后重做当前源面／像素组／根排除，像素组按当前未确认名义面积降序处理。剩余任务每次交替处理 32 个新扫描叶与至多 8 批遗留分类，每批遗留至多 128 叶、根批至多 128。遗留根按当前未确认面积降序、根编号排序，候选组内按叶面积降序、叶编号排序。面积和近邻只安排工作，不赋予覆盖资格。

交替搜索可能改变排队叶的状态，因此每批分类前重新过滤当前仍活动且未确认的叶，不能覆盖新见证或已细分单元。当前分类均完成后才能安装；停止边界按步骤而非阶段墙钟配额回放。全部排序和频率写入策略绑定，仍共享原 4 秒及累计几何预算。前置复证在时间内未完成时，不进入新搜索，该轮不接纳；不存在保证任何设备负载下都能获得增益的额外预算。旧 v4 的先完整遗留分类、再搜索新邻域顺序保持。

引导分区必须完整、不重叠，父证明只能引用更早且属于同一个球的证明，见证索引必须指向对应叶。分区验证完成后才整体替换计算中的根分区；输入分区保持数组表示，访问单元时才创建可变节点。输出未访问范围时只使用当前质量状态及本轮完成的排除结果，绝不复制旧确认／见证字段。构建或证明被预算中断时，全部原目标权重仍有明确归属，尚未重新证明的范围保持未确认。对已在本轮重验的单元尝试其他球时，即使在连通处理中断，也恢复其当前有效见证和确认状态；不能把中间的待连通状态作为最终结果。只搜索新增球的单元不能被标成“已检查且在全部内包球之外”。

独立回读先完整验证原路线、原目标及原覆盖，然后重建每轮候选、连接、逐边检查和引导复算；最后比对全部历史证据及最终结果。当前输入缺少所绑定的引导证据时，不能独立认证这一新覆盖记录。损坏、混合修订、变更作用模型、伪造父路径和重新封装摘要均不能绕过复算。

便携读取在重定位来源字段前，通过 `planning_state.validate_binding` 检查原方案绑定和区域签名；该入口不提供几何验证资格。随后 `region_path.load_path` 执行一次完整 `planning_state.validate`，重验路线支持及播放器投影，并继续重建目标和完整回放覆盖。数值路线、规划上下文、作用模型与覆盖输入不被重定位修改；没有可跳过验证的标志或跨次凭据。这样消除同一路线两次完整几何验证的重复，原 120 秒期限保持。重新封装并计算合法绑定的错误播放器坐标仍由完整投影核验拒绝。

## 等价几何计算

当前同输入 P2 和 P3 v5 通过 `PreparedResidualEngine` 复用单次重验中的候选编号、坐标和已绑定种子的半径数组。候选缓存以源面及当前限制种子在本面候选中的位置为键，限制键最多 128 bits，不保存整个种子集合；数组只读，最多 4,096 项，每项至多 128 个候选，候选数组合计最多约 16 MiB，较密源面直接计算。叶单元的包围盒最小值／最大值只提取一次，候选距离沿用原 float64 平方和及平方根。它们不保存球包含、球外分类或连接接纳结果。每次实际访问仍执行原有向舍入／精确回退、逐候选计数及同球正长度公共子边证明；访问顺序、停止边界和被中断时的状态恢复保持。旧 v4 逐叶实现保留，作为等价对照和旧策略入口。

深度／子地址对应的 float64 四叉系数另以最多 4,096 项只读缓存保存，只含与源数据无关的精确二进制系数。批量区间乘法与逐次向外求和保持；球区间复用同次计算中的绝对值中间数组，布尔归约直接使用数组方法。没有跨输入的几何或证书缓存，也不放宽任何工作计数、时间、细分或资产限额。

v4 对当前精确根的三个 XYZ 顶点先取得有方向保证的浮点区间。深度至多 8 的非负四叉系数是可精确表示的二进制数；每个乘积和两次求和分别向外舍入，批量得到各个子叶的三个顶点区间。包含模糊时才构造对应的当前精确 XYZ 并回退，不能以近似区间接纳模糊结果。非有限或不明确的插值区间回退到整个根盒；根本身无法精确重建时不产生子叶结论。当前根在本轮已成功重建的事实可复用，上一轮证明不能复用。根顶点区间另有最多 4,096 项的当前实例缓存，所有构造仍在原覆盖预算内。

新扫描邻域同样使用当前齐次整数单元；整单元球包含、锚点归属、子边规范直线及有理端点比较保留原精确语义。细分只创建同一根下的四个精确子地址，不插值或修改原 Mesh。共同顶点捷径仅限同一源面：两个不同公共顶点可证明公共边；仅有一个公共顶点时，两条边还必须严格共线且方向相同，才有正长度重叠。端点接触、相反方向、正长度缝隙和不同源面不获得该资格，其余情况回到完整的精确子边比较。

每面相机投影系数先转成精确整数基；逐像素只构造整数半空间系数。同一裁剪平面上每个顶点的余量只计算一次，输出时去除相邻重复点，保留原顶点顺序和边界归属。路径覆盖重验使用同一齐次整数裁剪和细分坐标，在需要明确有理数结果时才构造 Fraction。每个 XYZ 分量的浮点区间通过整数交叉乘积检查舍入方向；批量球包含仍使用原逐运算向外舍入判据，模糊情形回退到精确运算。

公共子边在当前输入内使用整数规范直线及有理端点比较。同一非退化根内的两个四叉子单元，可在单位参考三角形中检查正长度公共子边；当前根仍须成功精确重建。只有正长度交集允许连接，端点接触和任意正长度缺口均不合并；不同源面或不同源边编号不能按距离焊接。此表示只用于内存运算，不改变原目标数组或旧证明数组格式。

同一源面内两个当前精确重建的非退化三角形，若具有两个不同且齐次整数值完全相同的顶点，可直接证明它们共享正长度边；其余情况仍使用精确子边区间。该充分判据减少重复直线构造与对象分配，不使用距离容差，不跳过原邻接计数。独立 Fraction 参考在实际像素目标上核对所有已使用证明的球包含、锚点归属及正长度子边。

像素两侧半空间与原面 Z 范围给出整个像素裁剪单元的保守三维包围盒。当前 P3 进一步将像素射线区间与当前源面方程相交：法向叉积、平面点积和深度商均逐运算向外舍入；分母跨零、溢出、投影无界或相交区间不明确时，保留原保守盒。此优化仅在新策略显式开启，原 API 默认盒构造保持。

整个包围盒被当前球包含时，可作为该叶包含的充分判据；否则仍重建精确叶几何并执行原区间／精确回退。每个使用叶所属的当前精确根仍先重建；根盒已证明包含时，可延迟构造子叶坐标，直到锚点、子边或后续包含检查需要它。锚点归属与连通路径仍重验，包围盒不单独赋予任何覆盖资格。独立 Fraction 裁剪检查包括倾斜源面、极小／极大尺度、跨相机平面及分母跨零；批量构造与逐面构造保持一致。

范围外分类先按当前源面包围盒检查，再按像素包围盒查询本轮种子空间网格；不同格箱的原根分组处理，每个查询最多访问 4,096 格，过大或坐标不可安全索引时退回源面候选查询。向外扩展使用当前模型搜索半径，候选表只排除不可能接触的球。v4 先用一组当前像素盒的并集包围盒排除整组不可能相交的球，再对各根保留仍可能相交的球；两层均完成后，结果才能供子叶使用。这些结论只来自本轮已核验的坐标、区间和球，不能从旧 `outside` 标志或旧候选表获取。

含已重验确认叶的根也检查其余未知叶。子叶从当前精确根取得向外舍入包围盒，只检查本轮根筛选后仍可能相交的球。每个叶在遇到第一个可能相交的球后可以停止范围外搜索，但保持 `budget_unprocessed`，不由此生成确认、连通或范围外结论。只有排除了全部必要当前球的叶才标为 `outside_inner_seed_balls`。分类保存在当前分区的叶状态中，不改动已有当前见证。组／根／子叶分类中的实际盒／球比较均计入原 `comparisons` 限额；分组节省的候选比较另行统计，不把未执行的比较冒充已核验。批次最多 128 根或叶，单次数组运算最多 4,096 对；批量计数最多隔 32 项检查一次时间／取消。中断时只安装已完整完成的分类批次，其余原目标权重保持未知。

缓存属于当前只读几何域或当前重验器，不保存跨修订的覆盖资格。面、投影基和根构造缓存最多 4,096 项，像素缓存每种表示最多 2,048 项，点及重验几何缓存每种最多 8,192 项。另有各最多 4,096 项、与源数据无关的单位四叉细分系数及子边缓存。缓存以弱引用访问所属对象，避免绑定方法形成循环引用；不修改进程垃圾回收开关。当前原根像素包围盒是至多 200,000 × 2 × 3 个 float64 的索引数组，遵循原根输入上限，不保存覆盖状态。缓存命中不免除工作计数和新证据绑定。

## 预算与验收口径

整个产品操作保持 120 秒，工作台 P2 核心保持 30 秒，P3 每轮覆盖保持 4 秒；最终证据数组构造和界面准备仍计入整个操作耗时。P3 两轮、每轮四候选、累计新增边检查及输出点 200,000、总新增长度 0.1 m、新增扫描见证门槛 0.1 mm²，以及累计包含比较／邻接／证明各 1,000,000 的限额均保留。

验收同时记录：

- 完整操作耗时及分阶段耗时；重复运行列出全部结果和范围。
- 各类未确认叶数量、原目标整数权重和加权面积；叶数变化不能单独代表改善。
- 统一分区下的新增确认面积，并单列新增扫描点见证的增益。
- 原确认集合丢失权重；只有为 0 且新扫描见证达到门槛才接纳。

不同作用模型的面积不能作为性能优化增益比较。数值模型、真实采集回放和物理准确性验收分别报告，不能以合成正例替代真实补线结果。

`tools/benchmark_surface_coverage.py` 使用新的输出目录保存全部运行、证据数组和诊断。默认对 128／2,048 面声明网格重复首次覆盖、新 P2 复算和 v5 新球重验；指定工程后，每次真实 P2 都以同一原已验证证据为起点。分别保存原始候选与接纳后结果：原集合未完全保留时，`recalculation.status=retained_previous`，选用原覆盖，不能将候选当作已安装结果。真实 P3 默认固定使用第一次当前 P2 接纳后的结果；若拒绝则使用原覆盖，也可用 `--refinement-guide-assets` 指定先经过完整回放和集合检查的固定起点。引导另存 `fixed_refinement_guide_assets`，来源和摘要写入结果。`--compare-legacy` 对相同固定输入交替运行旧 P2／P3 v4；`--require-p2-acceptance`、`--require-gain` 分别将当前 P2 未接纳和当前 P3 无接纳记为失败，继续保存后续运行。

`--replay` 从保存资产逐一回放数值案例、每个 P2 原始候选及各份 P3 完整历史。被拒绝的 P2 候选及后续重复候选也单独回放，不能以 P3 的初始覆盖回放代替。计时分别记录计算耗时、CPU 耗时、含统计／证据写入的观测总耗时和 20 ms 采样 RSS；后者不是严格内存峰值。墙钟停止可能导致不同集合，必须保留全部结果。用法见 [重复验收与诊断](../使用说明/覆盖性能重复验收与失败诊断.md)。

基准的 `budget_change` 明确列出同一原目标上的前值、后值及有符号差值，分别对应叶数、整数权重和名义面积。预算遗留减少与新增确认是不同指标：确认面积增加并不保证预算遗留减少，减少球外分类遗留也不等于目标已经覆盖。必须同时报告，不能只给叶数或只挑增益最大的一轮。

## 分阶段耗时和失败日志

诊断默认追加到本工作区 `outputs/diagnostics/`；命令行验收可以通过进程环境变量 `FEMTO_DIAGNOSTICS_DIR` 指向本次独立输出目录。每次操作创建新目录，不改写旧记录或业务 latest 索引。

`operations/*/operation.json` 保存操作状态、总耗时，以及目标准备、逐边检查、覆盖、原证明重验、新扫描邻域、保存和回读等阶段的调用次数、包含子调用的耗时和自身耗时。`events.jsonl` 记录阶段开始与结束，最多 512 条；超过后明确计数省略，汇总仍累计。异常保存最多 512 KiB 的 traceback。预算中止、取消和失败分别记录。Qt 记录的是后台计算过程，界面安装及整个按钮操作另由产品验收计时。

v4 新增 `coverage.residual_recheck` 阶段，指标包含本轮子叶检查数、球外分类数、短路后仍未确认数、实际子叶比较次数、根顶点构造数、组盒比较数及组筛选省去的候选对数。它们解释计算花在哪里，不作为覆盖证明或新的操作预算。

新 P2 增加 `coverage.retained_frontier`，记录实际索引的本轮复证叶及边数。P3 v5 增加 `coverage.new_scan_order`、`coverage.new_scan_batch` 和 `coverage.interleaved_search`，记录种子组数、交替周期、完成批数和已变化叶的跳过数量；沿用复证、分类及停止阶段指标。交替阶段未进入时，不能把前置阶段耗尽预算误归因为交替频率。

普通路线的已验证 v3／v4／v5 补线摘要直接读取已经由后台工作流或读取器验证的报告，刷新标签不再调用路线反序列化并重跑几何检查。此处只影响显示开销，保存、回读、修订核验和覆盖证明入口仍完整执行原校验。

子进程异常或取消后，在结束该任务进程组后，将日志保留到 `subprocess_failures/*/`，同时记录退出码、耗时和内存观测。16 MiB 以内保留完整字节；超过则保留末尾 16 MiB，明确原大小、截断状态和所保存字节的摘要，不声称取得原完整日志摘要。临时调用目录被清理后仍可回查。

诊断不序列化函数参数、命令行、环境变量或原始帧；不进入覆盖修订、数值证明、人工核对资格和发布凭据。诊断写入失败不能改变原计算结果或掩盖原异常。此功能不自动重试失败任务，也不把一次未定位异常改称已经修复。

# 真实硬件接入资料交接清单

用于机械臂、底座、治疗头及发生器到位前与厂家/集成方确认接口。当前软件仅有原相机采集与开发模拟，没有真实机械运动或治疗输出适配器；下面的待提供字段不能用模拟值代填。

## 每台设备先确认

| 资料 | 厂家/集成方需提供 | 软件对应约束 |
| --- | --- | --- |
| 身份与连接 | 型号、序号、固件、协议版本、SDK/传输方式、认证及连接参数 | `DeviceConfiguration` 不赋予连接成功或能力；设备、种类、来源及连接代次绑定 |
| 命令与能力 | 查询、准备、暂停、继续、停止各命令的请求/应答格式、支持范围和错误码 | `Capabilities.protocol_id` 与 supported_intents 明确声明；未知协议不能下发动作 |
| 请求关联 | 厂家请求序号、去重/重试策略、取消关联、迟到/重复/乱序处理 | `request_id`、`related_request_id`、binding、intent、反馈序号均核对；重连换代，不重发旧任务 |
| 完成语义 | 收到、开始、完成、失败、取消分别代表什么；是否有实际到位反馈 | `received` 不等于 `completed`；收到回执不能当作已完成物理动作 |
| 持续状态 | 心跳、故障、就绪、实际静止/输出关闭、状态更新频率及最大年龄 | `DeviceStatus` 含单独序号、时钟域、秒时间戳；未知保持None/unknown |
| 时间与超时 | 原始时间戳单位/时钟源、同步机制、请求/状态/停止各期限及依据 | 只有同域时刻可比较；软件模拟的2秒请求期限、0.5秒状态年龄不是实机参数 |
| 断连与重启 | 断连后设备实际行为、是否保留运动/输出、重连/进程重启后的状态核对方式 | 未确认结果保持未知；重启只读回看/待核对，不自动续跑或重发 |
| 停止确认 | 停运动和停输出各自的反馈、拒绝/超时/故障时行为、独立急停/联锁资料 | 机械停止不能替代输出关闭；软件停止不等于硬件急停 |

软件边界为 `DevicePort.connect/close/capabilities/status/submit/poll`。现有 `DeviceRequest` 不包含真实轨迹点、速度或能量载荷；`SimulationStep` 仅引用软件步骤，不能直接映射成厂家实机运动/输出命令。真实载荷需拿到厂家协议后按版本新增并验证。

## 各设备额外资料

| 设备 | 必须明确的空间/状态资料 | 到位后需补的实测 |
| --- | --- | --- |
| 机械臂 | 基坐标、法兰坐标、轴方向、位置/角度单位、旋转表示、工具姿态、运动限制及实际状态 | 同步的 `T_BF(t)`、时间域与同步误差、到位/停止反馈及可达性 |
| 底座 | 固定安装还是可控底座、安装ID、锁定/解锁/移动/未知反馈、参考建立方式 | `T_W0_B` 及有效条件；底座变化后撤销当前链、重新建立会话的验证 |
| 相机与安装 | 相机序号、彩色光学RDF、安装关系、位姿与图像同步方式；原始时间戳不得丢弃 | `T_FC`、首帧同步位姿、安装来源及误差；深度系不能当作彩色系直接套用 |
| 治疗头 | 工具坐标、工作轴、真实外壳、头/发生器是否分开控制、参数版本和有效范围 | `T_FU`、工具标定、碰撞/间隙/接触条件及真实停输出反馈 |
| 超声发生器 | 输出与联锁状态、开启/关闭命令语义、故障码、异常后的输出实际行为 | 独立的 `output_off` 证据；声学、剂量和安全验收另行完成 |

## 坐标和失效规则

`T_AB` 将B系坐标变换到A系，平移统一米，旋转矩阵。C指对齐深度对应的彩色光学RDF；W0是当前会话的首个有效彩色相机参考。eye-in-hand 使用 `T_BC = T_BF · T_FC`，有当前有效底座关系时 `T_W0_C = T_W0_B · T_BF · T_FC`，工具链为 `T_W0_U = T_W0_B · T_BF · T_FU`。

缺外参不补单位矩阵。相机移动时必须有同步位姿。底座移动/解锁/未知、拆装/碰撞、标定版本或安装绑定变化会撤销当前依赖；历史记录保留，不能把旧坐标沿用到新会话。旋转结构容差不是实测精度，导入矩阵及来源摘要一致也不表示标定合格。

## 到位后按顺序验收

1. 先做身份、协议、连接/断连、序号与时间域验证，确认真实、模拟、回放不会混用。
2. 独立确认机械静止与输出关闭；模拟覆盖迟到、重连、乱序、故障及停止反馈撤销。没有反馈时显示未知，不补造成功。
3. 接入实测安装/工具标定与同步证据，核对坐标方向、单位、参考失效及误差范围。
4. 定义真实轨迹/输出载荷，验证限位、可达、碰撞、联锁和异常状态，再进入受控实机集成。
5. 重新验证采集、保存、回读、备份恢复、进程退出和记录失败。实机停止、物理精度及治疗相关验收独立完成。

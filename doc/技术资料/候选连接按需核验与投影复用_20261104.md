# 候选连接按需核验与投影复用

本轮针对仅选区重建后的初始路线和整段核验提速。操作流程、零周边默认、网格、作用宽度、行距、点距、路由版本与保存版本不变。所有最终路线继续核验原选区、孔洞、禁入多边形、参考深度、宽度和整段表面支持。

## 修改及依据

- `femto/planning/surface_row_turns.py`：初始候选的网格边资格原来在建图时全部计算，现在在搜索访问该边时才调用原 `_state`，仍按原方向和原判据缓存一次。相邻关系、边长、搜索顺序及路径选择不改。每个图独占顶点、内参、图像大小、选区和禁入多边形的快照，旧模型、重选或参数变更不会复用这个图的结果；取消和失败不写入未完成资格。
- 图像任一边超过 8192、非默认 NumPy 异常策略、特殊选择数组、覆写 `_state` 的子类或快照分配失败保留原提前计算路径。投影端点靠近像素半整数边界（1e-3 像素以内）也保留提前计算。后者只决定是否使用优化，不改变接纳阈值：最小反例证实原 supercover 在近角点可能触发长度预算异常，本轮仍保留该异常，没有借延后检查掩盖它。
- `femto/planning/quality_constrained.py`：一次参考包络检查中的外球和最终球中心、标定相同，复用其投影中心与原 `np.linalg.norm` 结果。两次半径运算、乘除顺序、floor/ceil、残差查询与扣费均保留；数据只活到这一次 `probe` 返回，没有跨点或跨请求缓存资格。

细分计时确认切片求交相关工作约 0.6 秒，并非初始阶段最大开销，因此没有改写求交数学公式、降低三角面密度或替换剩余 `lstsq`。候选连接准备、最终核验及参考包络更值得优先优化。剖析开销与关闭细分探针的正式计时分开记录。

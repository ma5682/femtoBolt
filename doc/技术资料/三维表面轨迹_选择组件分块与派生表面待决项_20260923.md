## 1. 业务语义

- 医师选定的工作区域是覆盖目标；工作块由医师选择的连通关系决定，不由 Mesh 连通关系决定。
- 点云 / Mesh 只提供 XYZ 几何支持；明确未选的区域构成绕行约束；采集或建模缺失是数据质量问题，不等同于医师未选，也不自动取消该处的覆盖需求（`missing_geometry_policy=retain_coverage_requirement_not_unselected`）。
- 每个成功规划的工作块内部必须是一条连续轨迹；做不到时块标 `incomplete` 并逐条记录原因，整体状态不显示全部成功。

## 2. 数据契约（附加字段，既有键不变）

### 2.1 `region.selection_intent`（`femto-selection-intent-v1`）

| 键 | 含义 |
|---|---|
| `coordinate_frame` / `unit` / `image_size` | `undistorted_reference_rgb` / `pixel` / `[w, h]`，与 `view_reference.image_size` 一致 |
| `selected_mask_runs` / `selected_mask_sha256` | 最终选中掩膜（工作区 − 禁区或有效范围 − 禁区），行优先 `[值, 游程, …]`，精确无损 |
| `painted_forbidden_runs` / `painted_forbidden_sha256` | 医师涂抹的禁区掩膜（可为 null） |
| `components[]` | 4 连通选中组件：`component_id`、`pixel_count`、`bbox`、`hole_ids` |
| `explicit_unselected_holes[]` | 8 连通、不触边的未选区域：`hole_id`、所属 `component_id`、`pixel_count`、`bbox`、`painted_forbidden_pixel_count` |
| `selection_method` | `work_only` / `work_minus_forbidden` / `full_minus_forbidden` |
| `connectivity` | `4_connected_selected_pixels_8_connected_unselected_pixels`（对角相触视为分离） |

回读时重算组件 / 孔洞并逐项比对，掩膜哈希、计数、拓扑、策略、尺寸任一不符即拒绝。`.region.zip`、规划草稿、`annotations.json`、`region_N.json` 均原样携带。

### 2.2 `region.selection_support`（`femto-selection-support-v1`）

逐像素分类：0 未选、1 `measured_mesh`、2 `no_surface_reference_depth_present`（派生表面候选）、3 `no_surface_no_reference_depth`、4 `outside_depth_range`、5 `depth_conflict`、6 `no_source_pixel`。证据仅为参考帧原始深度与绑定网格首次命中（`evidence=reference_frame_raw_depth_only_not_multiview_cloud`）。回读时按绑定证据重算，不允许手改。

### 2.3 三角面选取规则

`selection_rule=visible_triangle_centroid_pixel_in_selection_mask`：可见面心像素（`floor(uv+0.5)`）在掩膜内，遮挡射线、|z−depth|≤10 mm、`image_valid` 门禁不变。规划器用同一规则把区域 PLY 的每个面归属到选择组件；面心不在掩膜内的导出视为不一致并拒绝。

### 2.4 `trajectory.json`（v4 附加）

- `planner.parameters.selection_blocks=true`，`algorithm_version=mesh-slice-serpentine-v4`。
- `blocks`（`femto-surface-trajectory-blocks-v2`）：每块 `status ∈ {planned, incomplete, unplannable}`、`fragments[]`（网格碎片：面清单哈希、状态、行 / 链 / 链接方式）、`continuity`、`coverage`、`selection`（选中像素、孔洞数、支持分类计数）、`revisit`、`link_failure_counts`；`selection_binding`（意图 / 支持哈希、组件数、孔洞数）；`link_rule`、`fragment_rule`、`order_rule`。
- gap 原因新增 `selection_break`（仅块间）；块内 gap 的 `detail.link_failure_reason ∈ {disconnected_measured_surface, forbidden_blocked, outside_reference_image, no_surface_path, budget_exceeded}`；`surface_gap` 的 `inferred_cause` 可为 `explicit_unselected_hole_likely` / `geometry_unconfirmed_likely`（仍 `decision_use=none`）。
- 点级：connector 采样可带 `revisit=true`。
- `statistics`：`planned_block_count`、`incomplete_block_count`、`continuity_status`、`coverage_status`、`geometry_status`、`uncovered_fragment_count / uncovered_face_count`、`connected_detours`、`revisit_connector_sample_count / _length_m`、`geometry_unconfirmed_pixel_count`、`link_failure_counts`、`treatment_coverage_claim`。
- `selection_semantics`（播放视图）说明块、块间 gap、块内 gap、重复经过与覆盖声明的含义。

### 2.5 链接规则（v4）

1. 相邻行：冻结的 v2/v3.1 边界带折返（`SNAP_M=1e-8`，禁区整边检查，歧义顶点拒绝，e2 带限制），且其每条边的完整投影都必须落在本块选中像素上，否则视为失败转入第 2 条。
2. 其余（同行绕孔、非相邻行、边界带失败）：该网格碎片自身网格边上的最短路径（A\*，欧氏启发；解与 Dijkstra 相同），端点经所在三角面顶点接入；每条边落在同一选中三角面上、不离开参考图像、不触碰涂抹禁区 / 排除多边形、完整投影只经过本块选中像素。
3. 永不：跨网格缺口、跨碎片、跨块、穿越禁区或明确未选像素、二维补线、虚构深度。
4. 重复经过判定：connector 采样落在其所连接两行之外的已扫描行采样的名义半行距内。该判定用名义行距，不是治疗头宽度，`decision_use=none`。

### 2.6 明确未选与禁区的判定粒度（2026-09-23 审查后：一律像素级严格）

- 权威掩膜决定一切：扫描采样、连接采样以及任意两个相邻采样之间的整条边，其投影经过的每一个参考像素（`segment_pixels` 超覆盖走格，像素归属与采样相同的 `floor(uv+0.5)`）都必须属于本块的选择组件；落在明确未选像素、涂抹禁区或其他块像素上的采样被丢弃并切段（`dropped_fragments` 原因 `outside_reference_image_or_selection_or_short_supported_run`），无法绕过的链接记 `link_failure_reason=explicit_unselected_blocked`。"面心在选区内"只决定三角面是否进入区域 PLY，不再代表整个三角面可用。
- 涂抹禁区 / 排除多边形在此之上继续按既有多边形语义整边检查。
- 校验（`check_projection_inside_selection`）按导出意图重算组件标签，对每个点和每条边做同样的像素检查；一像素宽的未选条带也会在边上被捕获。

### 2.7 "结果完成"的唯一判定（2026-09-23 审查后）

`trajectory_history.result_complete`：所有块 `planned` **且** `continuity_status=complete` **且** `coverage_status=complete` **且** `geometry_unconfirmed_pixel_count=0` **且** `uncovered_fragment_count=0`。`block_summary.complete`、历史列表的 `result_complete` 和旧轨迹清理分支都只用这一个判定；路线连续但存在几何待确认像素或未覆盖碎片的结果发布为"未完成结果"，旧轨迹保留、不替换、不删除。

## 3. 阶段 C 待用户决定项（派生工作表面）

仓库中没有已确认的"在 Mesh 孔洞内由点云重建表面"的方法与门限（核对见交付记录第四节）。在获得确认并验证前，`selection_support.derived_surface.status=not_generated`，候选像素只报告，不生成表面、不参与轨迹。需要决定：

| # | 决定项 | 现状 / 参考值（均非本用途门限） |
|---|---|---|
| 1 | 可采用的点来源与绑定方式 | 融合点云角色为 `display_and_diagnostics`；`initial_observed_points` 是 stride-16 显示子集；原始逐视角深度可按 `T_W0_Ct` 反投影。区域清单目前未绑定任何点云文件（需新增路径 + SHA-256 + 坐标系 + 来源）。 |
| 2 | 是否允许派生面进入测量 / 规划层 | `data_layers.interpolation_policy=no_display_hole_fill_or_texture_used_as_measurement`（绑定键，改动会使旧标注 / 路径不可回读）；方案 §5.3 "不补面"。 |
| 3 | 孔洞最大尺寸（边界环半径 / 面积 / 像素） | 深度补洞 ≤64 px、≤12×12 px（图像空间）；`fill_small_mesh_holes` 仅测试用 6 mm。 |
| 4 | 邻域半径 / 最小点密度 | 10 mm 深度一致性；KD 半径 10 mm、第二层 4 mm；视角接纳膨胀 / 腐蚀 20 mm；ICP 体素 12 / 6 / 3 mm。 |
| 5 | 与周边网格的深度差 / 法线差（不同表面 / 遮挡判定） | 10 mm 面支持；30 mm 跳变仅诊断；纹理 15 mm 启发式。 |
| 6 | 拟合误差与置信度门限 | 深度补洞 RANSAC：内点 max(3, thr/3) mm、≥80% 内点、残差 std < thr/2、修复误差 ≤50 mm；`repaired_confidence=0.30`。 |
| 7 | 多视角支持要求 | ≥1 视角（`retain_observed_triangles`）或 ≥2（`multi_frame_supported` 诊断词汇）。 |
| 8 | 派生面的标签与校验 | `geometry_support` 目前只允许 `measured_mesh`；需新增如 `derived_point_cloud_surface` 并定义校验、来源记录（输入点云来源 / 坐标 / 哈希 / 方法 / 参数 / 支持范围 / 误差状态）与 `data_layers` 扩展方式。 |

确认后的实现顺序：绑定点云 → 逐像素候选筛选（深度突变、不同表面、遮挡、邻域支持）→ 派生表面单独保存（原始点云与 Mesh 不变）→ 轨迹点标派生支持并与实测 Mesh 支持分开统计 → 校验与回读。

## 4. 阶段 C 第一步已实现：候选诊断（2026-09-23，`femto.planning.derived_surface_candidates`）

用户核查 4 份新导出后指定的范围：绑定原始深度与位姿 → 独立生成候选表面 → 严格检查选区边界 → 保存诊断；不插值无深度区域、不改原网格、不替换旧轨迹。

| 项 | 实现 |
|---|---|
| 证据 | 导出 `origin_reference.source_dataset` 下逐视角原始 Depth / RGB / Pose（`T_W0_Ct`）与 6 个标定文件；校验 `calibration_sha256`、参考 Pose 路径 + SHA-256 + 单位矩阵、参考 RGB / Depth SHA-256、去畸变内参与图像尺寸；`selection_support.depth_range_m` 必须等于该数据集 manifest 记录的重建深度范围（审查修正，2026-09-23）。不使用显示点云、纹理或补洞深度。 |
| 候选面 | 参考帧原始深度按 `build_pixel_mesh` 既有像素邻接规则建面（门限不变）；只保留 三顶点同属一个选择组件、无 `depth_conflict` 顶点、深度在参考范围内、含至少一个"有深度缺面"顶点、三边与内部像素全部属于该组件 的面。 |
| 覆盖口径 | 候选像素"已覆盖" = 其实测点是某保留面的顶点；逐组件统计；任一候选像素未覆盖或存在 `depth_conflict` 像素即"未完成"。 |
| 诊断 | 接缝顶点到区域网格距离分位数（不拼接）；他视角在既有 10 mm 尺度内 / 外计数与分位数、全部视角一致 / 任一超出 / 未观测像素数，`gate=none`。 |
| 产物 | 导出目录下 `derived_surface_candidates_<12hex>/`：JSON、候选 PLY（W0 / RDF / 米）、面与像素 CSV、示意图、哈希清单；拒绝写 `derived_surface_blocked.json`。回读重验哈希、导出与意图 / 支持绑定、每面整面像素归属，并重新绑定原始证据（逐视角 RGB / Depth / Pose 字节、`frames.jsonl`、数据集 manifest、标定联合哈希、参考 W0 单位位姿、深度范围）与记录逐字比对，任一改变拒绝。 |
| 不变 | `selection_support.derived_surface.status=not_generated`；v4 规划、`geometry_support` 词汇、`data_layers`、`result_complete`、历史清理、已保存轨迹、原网格、原始数据。 |

# P5 变宽补充规划与独立回读契约

开发状态：已实现，19 项新增专项与 64 项既有兼容回归通过，持久样例完整回读通过；范围见[交付记录](../历史开发记录/P5变宽补充规划_20261011.md)。旧 P3/P4/P5 版本保留原含义，真实大工程稳定性与实采验收保持独立待完成。

新路线版本为 `nominal-variable-width-refined-surface-v1`，补充报告为 `femto-variable-width-refinement-v1`，逐边报告为 `femto-variable-width-refined-edges-v1`。仅接受已完成覆盖核验、模型仍有效的未补充 P5 路线。模型及原目标固定；新增段与连接段沿用原生成包络、选区与严格表面支持约束。

1. 原目标数组全部保留，只将台账头绑定到新的计算修订。每条连续链含连接边的 float64 弦长之和仍用精确有理数累计，新增边后重新计算整条链的归一化区间；每段上下界检查端点和全部内部节点。不得复制旧边下界或旧覆盖状态。
2. 候选筛查与连接搜索继续采用原生成宽度这个保守包络。每个完整候选路线再按本段上界检查所有旧、新扫描边与连接边，使用同一严格支持引擎；上界超过包络、支持/质量未知或预算到限均不能接纳。内包半径只取扫描边下界并扣除原锚点显示舍入位移，连接边不提供种子，零下界不确认正面积。
3. 每轮从当前边界/种子重新核验完整原目标。前轮分区与路径仅作为无权威的调度提示，每个球、包含和公共正长度子边重新证明；模型摘要相同仍不能继承重参数化前的半径。比较共同四叉树分区，原集合损失必须为零，新扫描端点见证的新增权重必须为正且达到原最小增益。旧点半径变化带来的计算增益不替代新扫描见证。
4. 使用既有补充预算上限：至多两轮，每轮四候选，新增长度 0.1m，输出点/边检查各 200000，比较/邻接/证明各 1000000，每轮覆盖至多四秒。初始与每轮完整变宽逐边检查也计入同一个边工作量；构造、连接与全路线检查共用一个严格支持预算。所有轮次累加，不嵌套重置。
5. 安装前核对完整当前输入、模型有效日期与整方案摘要；Qt 使用冻结快照、请求代次及取消。无可接纳增益时只保留失败诊断和原方案/缓存，不能发布零增益的新补充版本。初始证明与每次已执行覆盖核验的拒绝/接纳试验均保存完整证明；在外包检查阶段拒绝的试验保存拒绝诊断，不伪造覆盖资产。数量仍不超过三份历史加最终证明；回读按新版本独立重建候选、宽度、逐边支持、预算、停止边界及共同分区比较，不信任重新封装的哈希/诊断。
6. 原生与便携包保存模型、逐边变宽报告和完整补充历史。仅同一次双格式保存可使用进程内已验证资产凭据，所有实际写出资产仍回读核对；独立打开完整重放。恢复首先精确回到补充前 P5 路线与覆盖，再由原 P5 操作恢复模型前 P4 路线。模型过期可只读回看和恢复，禁止新补线、核验或发布；恢复不突破上游输入变化检查。

验收包含实际正例增益、非恒定模型的旧区间重绑定与全路线再验收、零下界、段内上界峰值、连接不计覆盖、累计预算停止、无增益保留、取消、模型过期、输入/整方案变化与迟到结果、两级恢复、资产删除/篡改/重新封装拒绝和原生/便携独立完整回读。物理偏移上界仍未知，`execution_ready=false` 与 `physical_accuracy_verified=false` 保持。

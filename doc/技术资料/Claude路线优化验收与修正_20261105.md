## 正式代码修正

| 位置 | 复现的问题 | 当前处理 |
| --- | --- | --- |
| `triangle_certificates.py` | 原快速正例证书在大尺度、细长三角形及接近平面容差的输入上，可与原逐点判断不一致 | 复用已有 `TriangleSolve` 条件数/残差界证明；不能证明时仍由原逐项判据决定 |
| `edge_check_batch.py` | 首次分块残差准备只计费而未安装状态，后续批次可能再次计入启动成本；边界预算写死 | 成功后一起发布分块状态与计费结果；遵守原 `MAX_DISTANCE_CHECKS`，预算临界回退原循环 |
| `edge_check_batch.py` | 超长边界可能展开巨量子段，近邻候选数组也没有明确大小上限 | 索引最多 262144 个子段，单轮查询最多 262144 个点/候选组合，超限回退；增加准备过程取消检查与尺度相关误差保护 |
| `io_utils.py` | 紧凑 JSON 的一次性 `encode` 在取消/大小检查之前遍历全部数据 | 恢复增量 `iterencode`，保留短 token 写入合并，原子替换与旧文件保留规则不变 |
| `surface_trajectory.py`、`trajectory_export.py` | 仅按对象身份复用验证，不能发现嵌套内容修改，复制后的上下文也可能继续跳过验证 | 导出入口完整验证并绑定全部轨迹内容摘要、线程及活动作用域；复用前核对，发布前再核对，关闭作用域立即失效 |
| `small_vectors.py` | 全部乘积为负零时，省略 BLAS 的正零初始累加项会改变结果位模式 | 恢复 `+0` 初始项；当前环境对混合符号、步长视图和正负零进行逐字节对照 |
| `selection_blocks.py` | 每个不连通选区各保留一张全尺寸布尔掩膜，驻留内存随选区数增长 | 只复用最近一个选区掩膜，连续同区线段仍共享准备结果 |
| `quality_constrained.py`、`surface_trajectory.py` | 快速路径可能绕过已替换的原谓词，影响预算/取消插桩的检查语义 | 原谓词被替换时保留逐项入口；默认生产调用继续使用通过保护条件的快速路径 |

路线算法版本、作用宽度、目标意图和保存格式没有因这些修正调整。待检查像素、原始缺口和未核验覆盖状态仍保留。

## 验证方法

`tests/test_claude_optimization_acceptance.py` 包含 16 项专项：

- 批量/逐项判定、拒绝原因、余量及连续两次残差计费对照；矩形最大值与直接切片对照。
- 原边界预算、超长边界分配上限、近邻距离与穷举结果、阈值附近回退和取消。
- 300 组旋转、缩放、细长三角形及平面容差附近输入的正例证书核对；小向量逐字节对照。
- 紧凑 JSON 遍历中取消、旧文件保留、多选区掩膜驻留数量。
- 导出前/中途嵌套修改、关闭或复制上下文、跨线程及发布回调修改；无效输出不得发布。
- 两个新写入进程分别使用快速路径和强制逐项路径，在相同合成几何、选区 ID 和参数上生成；各自启动独立读取进程打开原生和便携结果。路线点段、统计、缺口、间距、行报告和工作块逐值一致，保存回读保留各自完整结果。测试资料全部在临时目录。

联合回归还覆盖路线预算、准备复用、旧版本读取、覆盖/补充路线、可变宽度、保存中断恢复、选区先行重建以及单帧/双帧/三帧的生成—保存—回读衔接。不是全仓库测试，也不代表现场相机或真实物理精度验收。

在仓库根目录用 PowerShell 复跑同一模块集合：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
$env:PYTHONPATH = 'tests'
$env:FEMTO_DIAGNOSTICS_DIR = Join-Path $env:TEMP 'femto-claude-acceptance-diag'
$acceptanceModules = (Get-Content -Raw -Encoding UTF8 'doc/技术资料/Claude路线优化验收结果_20261105.json' | ConvertFrom-Json).modules
& .venv/Scripts/python.exe -X utf8 -m unittest @acceptanceModules
```

初次 247 项回归有一项旧夹具失败：界面已默认延后目标面积计算，该测试仍期望 `_construct` 执行一次。该用例现在明确准备完整目标，再检查同次双格式保存只构造一次、两个独立读取器各重新构造一次，原断言强度保留。新进程对照夹具还补写了源网格文件，并固定随机选区 ID，避免把不同输入摘要误判为算法差异。

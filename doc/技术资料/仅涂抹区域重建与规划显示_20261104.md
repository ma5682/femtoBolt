# 仅涂抹区域重建与规划显示

## 当前行为

用户要求重建、规划和规划模型显示都只处理医师最终涂抹区域。新局部请求默认周边为 0 mm，取消工作台中扩大重建周边的控件；涂抹保留、擦除排除，内部留空和分离区域保持。完整原始 RGB-D、标定和位姿继续保存，固定参考 RGB 仍用于编辑。

新请求使用 `femto-region-first-reconstruction-v2`，`geometry_scope=selected_surface_only`、`support_margin_mm=0`。旧 v1 请求的 25–200 mm 周边仍可由后端明确回放，不自动改成零；旧产物不覆盖。v2 不接受非零周边，也不能重标为 v1 后通过读取。

主要建面和积分只消费筛选后的深度：参考帧直接以原掩码取点；其他帧由内参、真实位姿和深度一致性投影回固定参考，只有命中选区的可靠观测进入重建。缺深度、遮挡、无法确认的原目标仍保留。零周边不再计算距离变换。输入解码、标定、位姿和映射准备仍可能读取整帧，不能将它们称为选区内计算。

实际贡献一帧仍使用像素邻接建面，多帧仍用局部 TSDF。TSDF 的有限体素和三角面本身有离散边界；保留原观测支持和小分量过滤，不通过填洞补面或放宽门槛扩大可规划区域。此次改变重建范围和边界，规划派生表面、法向、面编号及路线可能改变，不能按上一轮的逐字节等价提速解释。

## 规划模型显示

原路线计算已经以选区为目标。本轮继续保留原有效域、作用宽度、整边支持、深度和缺口判据，修改的是新重建范围及三维展示范围。

规划页和保存结果回看中的三维视图仅显示当前确认选区对应的表面。完整内部三角形原样保留；边界三角形按固定参考像素掩码的矩形并集裁剪，孔洞和分离块不闭合。裁剪结果仅为显示副本，不写回模型，不改变已生成路线和保存坐标。每个显示三角形保留原面编号，拾取返回原坐标系下的位置。未确认或清空选区时不退回显示整模型；更换选区重设视角以适应当前模型。

显示裁剪不建立目标面积台账。最多 100000 个掩码矩形、20000 次边界面/矩形裁剪；超过预算时提示并返回参考图，不放大显示范围或冒充完整渲染。历史无像素意图的记录只按已有面集合显示，不能声称补出了原涂抹边界。原生 GPU 窗口的人工视觉验收尚未完成；本轮核对了数值显示几何和 VTK 数据接口。

## 模块

- `geometry/local_region.py`：v2 零周边默认、双版本读取、直接掩码和实际位姿筛选；保留来源与原掩码核验。
- `app/qt_region_capture.py`、`app/qt_workflow.py`：固定仅选区重建，更新操作提示；错误详情入口保留。
- `viewer/selected_surface.py`、`viewer/vtk_scene.py`：仅选区的可视化副本、内部留空和原面编号映射。
- `app/qt_vtk_viewport.py`、`app/qt_scene_panel.py`、`app/qt_review.py`：只安装选区模型，正确拾取，按当前区域复位视角，保存结果按同样范围显示。
- `pipeline/scene_reconstruction.py`：无可用观测时的提示改为“请求范围”，计算和拒绝规则不变。

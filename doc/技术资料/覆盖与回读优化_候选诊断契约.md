# 覆盖与回读优化、补充候选诊断契约

本轮完善 V1.0 方案中的 P2／P3／P4：提高既有覆盖计算与完整回读的效率，并改进补充候选选择和失败解释。没有引入 P5 变宽作用模型或 P6 跨会话目标继承。完整场景 RGB-D、源 Mesh、原目标数组和既有归档保持；坐标仍为 W0／RDF／metre。

## 精确覆盖与回读

`exact_surface.clip_pixel` 在裁剪内部使用齐次整数重心三元组，分量之和为正的隐式分母。平面系数统一为整数，交点按整数线性组合构造，最终仍返回规范 `Fraction`，保留原多边形顺序、半像素边界及退化语义。向外舍入边界使用整数交叉乘法判断浮点舍入方向，不减少包含或连通判据。

每个 `CoverageDomain` 增加最多 8,192 项的点构造缓存，缓存本实例只读源几何的精确 XYZ 与向外舍入界。不同修订不共享缓存；数组返回值与缓存隔离，不能借返回数组修改证明几何。没有缓存覆盖结论、候选准入或归档验证结果。

覆盖算法仍为 `layered-anchor-ball-subedge-coverage-v2`，保留 B1 算法；候选球顺序、调度、工作量计数及保存的停止边界不改。相同证书必须逐项重放出相同清单和数组；速度提升只允许在同一墙钟预算内完成更多原计算。

便携工程读取中的重复目标读取合并为一次：`region_project` 先核对当前修订，再由 `region_path.load_path` 完整读取并从原输入重建目标，向覆盖读取器和最终模型交付同一台账。无覆盖的 P1 工程同样执行完整目标验证。任何损坏或不一致都拒绝；独立打开仍完整重放目标、原路线、支持证据和所有实际计算过的覆盖证书。原 120 秒整个操作期限不变。

## 新候选策略与兼容

新建补充操作使用 `quality-screened-symmetric-face-slices-v2`，普通与严格路线共用选择规则。外层路线 ID 仍分别为 `coverage-refined-surface-v1` 和 `constructed-coverage-refined-surface-v1`。新报告 schema 为 `femto-coverage-refinement-v2`，完整候选策略保存在 `algorithms.refinement.candidate_policy`、轨迹参数及报告中，参与计算修订摘要。

旧报告 `femto-coverage-refinement-v1` 不带 `candidate_policy`，按原中心最长边切片策略完整重放，不用新策略解释旧证据。内核 `coverage_refinement.refine` 默认仍为旧策略；工作流显式选用当前策略，显式传入 `None` 可执行旧策略。策略的键、值及类型必须严格匹配；未知版本、扩大限额、缺失策略或混合 schema 均拒绝。

只考虑 `outside_inner_seed_balls` 且原有效域允许的面。质量、定位、连通、构造及预算未知不转换为扫描缺口。沿用同工作块共边分组与未确认面积排序，每轮最多筛查 256 个面，每面最多尝试 3 个未确认叶中心；不修改原目标范围。

每个位置比较原三角面的三条边方向，选择能容纳的最长对称面内区间，端点内缩 2%。候选最短 2 mm、最长 4 mm，采样沿用原路线步长。先筛查最短段的参考图包络；较长段不通过时最多二分 6 次。每轮实际送入完整准入的候选仍最多 4 条。

筛查直接复用 `quality_constrained.ReferenceEnvelope`：原名义宽度、局部残差、投影矩形、选区与质量判据不变。每次参考筛查都计入原累计 200,000 次边／搜索检查预算，局部残差邻域仍受累计 100,000,000 像素工作量上限约束。筛查通过只表示可继续检查，随后仍执行表面边界和整边支持准入；严格候选还须构造精确锚点并逐边重验。

## 可选连接与预算

过长的可选连接保留为明确断点，避免一个绕行耗尽其他短候选的总长度预算。每条候选的连接额度不超过：

`min(总新增长度预算 / max(1, 轮数上限 × 每轮候选上限), 当前总长度剩余额度) − 本段扫描长度`

额度为负时按零处理。先用端点直线距离排除不可能满足额度的连接，再检查图路径长度；严格模式还检查重构后路径长度。所有真正采用的连接仍逐边验收，连接不贡献作用覆盖。超过额度记录 `connection_length_budget`，不声称不存在更短可行路径。实际扫描和连接总长度仍受原 0.1 m 累计上限约束，点数、支持检查、每轮 4 秒覆盖及全操作 120 秒限制均保持。

## 诊断与完整重放

每轮 `candidate_search` 记录排名数量、筛查面／位置数、实际参考检查及像素工作量、送审候选数、拒绝原因计数、未检查面数。最多保存 32 个拒绝示例，计数不截断；有界搜索未检查的位置仍未知，不能记为不可行。

`quality_diagnostics` 保存候选实际子边的详细原因、参考像素范围、越出选区像素数、质量待确认像素数及局部残差。可区分：无法投影、越出参考图、越出工作区域、质量待确认、两者同时存在、边界余量不足及整边表面支持未确认。原粗粒度逐边结果仍保留，兼容旧报告。

界面详情与文本报告消费已安装的验证结果，展示候选检查、未通过原因、连接断点和覆盖回退；摘要显示不在 Qt 主线程重新验证整份历史。发布和独立回读仍重新生成候选、执行每条边及连接准入、重算每轮覆盖，并完整比较诊断、预算、结果及停止原因；诊断不能靠重新计算外层哈希伪造。

## 四项验收口径

| 指标 | 口径 |
| --- | --- |
| 耗时 | 分别记录相同旧包回读、新覆盖、补充、双格式保存、独立回读与恢复的整个操作时间。分析器开销不算作产品耗时。 |
| 预算遗留 | 同时报未处理叶数量和按原目标根单元加权的未处理面积／整数权重。细分增多可能使叶数增加，不能据此判断覆盖退化。未定位像素另列。 |
| 新增确认面积 | 对同一原目标的四叉前缀共同分区计算新增集合；区分更多覆盖计算取得的增益与新增扫描点见证的增益。 |
| 原确认集合 | 必须检查 `lost_weight_units == 0`，不得仅比较总面积。新增补充未完整保留原集合时整轮拒绝，保留原路线及证书。 |

每轮试验仍完整重算覆盖，不能拼接旧确认结果、删除困难目标或放宽预算取得接纳。失败、取消和预算耗尽均保留未完成状态。真实样本若没有新增接纳也如实交付原因；合成正例验证有效新增扫描能够被接纳。

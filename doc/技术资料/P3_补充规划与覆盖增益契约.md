# P3 补充规划与覆盖增益契约

本契约对应 `coverage-refined-surface-v1`，在保留的 `quality-constrained-surface-v3` 路线与 P2 核验上增加受界补充；P4 对应 `constructed-coverage-refined-surface-v1`。默认生成路线仍为 v3；用户在核验覆盖后显式选择“补充规划”。原算法、P1 裁剪及旧覆盖算法的解释不变。

## 输入与修订

输入必须是通过当前验证、带 P1 原目标和覆盖资产的未补充 v3／P4 路线，接收原 B2 或同输入优先复算的 P2 证据。同一原目标的图像、深度、规范完整场景网格、标定、W0、选区、质量及作用宽度均保留。P3 创建新的计算修订，`algorithms.route` 为新版本，`algorithms.refinement` 绑定原计算摘要、原路线语义摘要、原覆盖摘要及补充预算；`target_id` 不变。

`planning_context` 仍只有 `schema/revision/target` 三个字段。目标数组逐项保留，只将目标清单绑定到新的计算修订。名称、备注和可搬迁文件路径不参与计算身份。当前输入有变化时，补充结果及恢复操作均停用；纯导航不使结果过期。

新结果的 `planner.kind=coverage_refined_surface`，`parameters.coverage_refinement` 必须与修订一致。完整原 v3 轨迹保存在 `gap_report.refinement.base_trajectory`。原扫描边与连接边的坐标、角色、面索引和相对顺序保留；加入新段后重新编排全局访问索引。多个工作块仍按原顺序访问，块间没有已规划转场。

## 原因分流及候选

| B2 原因 | P3 处理 |
| --- | --- |
| `confirmed` | 保留已有确认集合。 |
| `outside_inner_seed_balls` | 仅在原有效域允许的真实面片上生成候选。 |
| `quality_excluded_or_pending`、未定位像素 | 检查或补采；不补造坐标或面积。 |
| `ball_connectivity_unconfirmed` | 继续核验连通性，不能解释为行距不足。 |
| `subdivision_limit`、`budget_unprocessed` | 继续计算或检查预算，不能直接当作可改善缺口。 |
| `target_construction_unconfirmed` | 检查目标构造，不能生成扫描段。 |

一个证书中已经明确的可用缺口可以进入候选，其他预算未处理范围仍保留。本版不把“预算未完成”整体转换为覆盖缺口。

旧 `femto-coverage-refinement-v1` 候选按同工作块内的原面共边关系分组，以未确认名义面积降序、原面编号确定优先级。每个候选在相应面的未确认目标叶单元中心作面内切片，方向取该面最长边；端点向面内收缩 2%，最短候选 2 mm，采样步长沿用 v3 的 1 mm。该候选本身不扩展或插补 Mesh，也不构成严格路径证明。

当前工作流使用 `femto-coverage-refinement-v5` 报告，将 `quality-screened-symmetric-face-slices-v2` 候选策略与 v5 覆盖交替策略分别绑定。保留原候选分组排序，每轮最多筛查 256 面、每面 3 个未确认叶中心，生成最长 4 mm／最短 2 mm 的对称面内短段，复用原参考包络筛查后仍逐边验收，每轮仍最多 4 条。筛查计入原边预算；过长的可选连接保留 gap，不耗尽其他候选的长度份额。旧报告按旧策略重放。候选参数见 [优化契约](覆盖与回读优化_候选诊断契约.md)，当前复证、交替顺序及完整回读见 [复算契约](覆盖复算调度与持久诊断契约.md)。

所有候选边调用原 `quality_constrained.edge_checks`，保存接纳、拒绝原因和参考残差余量。候选可以被拆成多个通过检查的子段。同块原路线末端与新增段之间调用原 `VerifiedSurfaceGraph`；搜索输入只带两端邻近的扫描点，网格共享面节点与整边判定不变。候选路径缺失不证明不可达，未找到连接时保留 gap。搜索输出的每条连接边再经过相同验收器并保存独立记录；连接边不计入作用覆盖。

## 覆盖比较与接纳

每个有可接纳扫描段且未超出长度或点数预算的试验路线都重新运行绑定版本的覆盖核验。v5 先重验原确认集合，再轮转新增扫描位置并交替分类遗留范围。旧证书和新证书的叶单元可以不同，但必须来自完全相同的原目标数组。

比较采用深度 8 的四叉前缀整数区间。一个深度 d、编码 c 的叶单元对应 `[c·4^(8-d),(c+1)·4^(8-d))`；按原目标单元逐一求区间交集，分别累计保留、新增和丢失的权重。检查每份分区无缺口、无重复，避免直接相减不同分区的汇总面积。面积采用原目标名义面积乘二进制可精确表达的细分权重；不是物理面积或舍入误差上界。

同时检查新增确认范围的见证来源：新证书的 leaf → proof → seed → 输入扫描端点必须对应本轮新增扫描点，不能只靠旧扫描种子的额外计算通过增益门槛。接纳要求：

- 原已确认集合完全包含于试验确认集合，丢失的整数权重必须为零。
- 由新增扫描点见证的新确认权重大于零，名义面积达到配置门槛。
- 累计检查、点数和路径长度均在预算内。

新增确认面积是证据集合的增长，不表示此前未知范围必然没有真实作用覆盖，也不表示物理治疗增益。被拒绝的试验证书、候选及比较仍保存；最终路线与证书继续采用上一接纳结果。

## 软件预算

| 参数 | 默认值及上限 |
| --- | --- |
| 补充轮数 | 2 |
| 每轮面内候选 | 4 |
| 连续低增益停止轮数 | 2，可收紧至 1 |
| 累计新增边验收和搜索检查 | 200,000 |
| 最终输出点数 | 200,000 |
| 允许增加的总路径长度 | 0.1 m；总上限为原路径长度加此值，包含新增扫描与连接 |
| 新扫描点见证的增益门槛 | 默认 0.1 mm²，可显式配置 0～0.1；新增见证权重仍必须大于零，不是临床参数 |
| 每轮覆盖计算时间 | 4 s，最多 2 轮 |
| 各轮累计比较／邻接／证明 | 各 1,000,000 |

P2 自身的新增叶、深度、种子和数组限制不放宽。时间、计数或深度退出保留未确认范围。重跑相同输入时，时间预算可能导致不同停止步骤；每份保存证据按其记录的停止步骤确定性重放。P3 不在已补充版本上嵌套循环并重新获得预算；恢复补充前版本后才可开始新的显式尝试。

所有阈值都是本阶段的软件工程限制，未校准为临床参数。任务仍遵守原 120 秒操作限制；耗时、峰值及实际覆盖收益见[交付记录](../历史开发记录/补充规划与覆盖复核_P3_20261009.md)。

## 保存与完整回读

覆盖清单与数组保持原基础格式，算法由各份证据显式绑定。原覆盖和每轮真正计算过的试验覆盖另存为 `refinement_0_coverage_certificate.{json,npz}`、`refinement_1_…`、`refinement_2_…`，0 对应补充前 v3／P4 证据；未运行覆盖的轮次没有伪证书。最多三组历史资产与一组最终资产，全部列入原生或 portable 清单。若某组是新 P2 优先复算，另带相同前缀的 `recalculation_hint_coverage_certificate.{json,npz}`；提示仅一层，发布凭据和独立回读均核对实际数组。没有接纳补线、最终仍为新 P2 时，其提示也必须保留。

清单 1 MiB、单组数组 256 MiB、工程清单 100 MiB、ZIP 总解压 1 GiB 的上限保持不变。NPY 头、形状、类型、成员、字节数和摘要校验沿用原受界读法。不能只保存 P3 路线摘要而不保存证据；缺失、孤立、混合轮次和重算哈希后的伪造均拒绝。

最终证书的 P3 route binding 绑定数值轨迹、来源、规划参数、修订、目标、统计与原质量报告，排除 `gap_report.refinement` 本身，避免“试验证书成为自身输入”的循环。该报告不是因排除而被信任：发布和回读必须重现原覆盖，重新生成候选、执行原 v3 验收与连接搜索、按每轮保存步骤重新核验覆盖，逐项比较候选、边记录、比较和停止原因。原生 `reproduce=True` 另外从当前绑定输入重建原 v3 路线。可搬迁路径和显示信息不影响语义比较。

最终采用的原证书或某轮证书仅在种子及作用模型完全相同、原目标数组逐项相同的情况下重绑定到最终路线修订；不改变证明数组，也不补造确认。发布验证重放该证明来源一次后检查最终绑定，避免重复计算同一证明。完全未新增时原路线已经逐边通过 v3 检查，最终逐项相同的点列复用该检查。

同一次 Qt 双格式保存另有进程内验证凭据：原生包的目标、原证明、全部候选／试验证明完整回读和重放、发布成功后才签发；第二份便携包必须匹配完整轨迹语义（包括补充报告）、目标清单、最终及全部历史证书，重新检查实际数组摘要，再对新写出的每一组资产作受界读回。只有完全相同的内容复用此次验证，减少两份格式重复运行同一证明的耗时。凭据不序列化、不从文件恢复，不用于独立打开或另一次保存；任何绑定／数组变化拒绝复用。旧 v3 的保存流程保持不变。

## 交互与边界

新按钮接入原冻结输入后台任务，依赖模型、计算修订、请求代次及整份原方案摘要拦截迟到结果。取消、旧请求和输入变化不能安装结果；准备显示失败时也保留所有原缓存。成功结果需要重新核对并保存。历史只读显示结果、原因和覆盖图层；“恢复补充前路线”同时恢复原目标修订及覆盖资产，保存仍建立新的版本。

W0／RDF／metre 不变；参考残差不等于实物误差上界，配准和标定不确定性保持未知。`execution_ready=false`、`physical_accuracy_verified=false`。严格路线另按 [P4 契约](P4_严格路径构造与支持契约.md) 构造并逐边重验，原 P3 容差语义保留；尚未引入 P5 变宽作用模型、P6 跨会话目标继承、设备执行或人体运动补偿。

# P5 名义变宽模型与回读契约

当前软件阶段在既有严格路线中应用显式分段线性半宽模型，复用 P4 支持判定和 P2 整单元证明。路线版本为 `nominal-variable-width-surface-v1`，模型为 `femto-nominal-piecewise-ball-v1`，逐边报告为 `femto-variable-width-route-v1`。默认生成仍为原 v3，P0–P4 和固定宽度旧包保持原语义。

## 参数、单位与来源

独立参数是每条已保存连续路线的归一化累计弦长，从 0 到 1，包含该链中的连接边；每遇原有断点，新链从 0 开始。弦长按保存的 float64 XYZ 计算，再把各长度作为精确二进制有理数累计及归一化。该定义是可重放的数值模型参数，不是设备速度、时间或真实声场规律。模型不能自动搬到另一条重新采样或重新排列的路线。

模型包含 2–128 个严格递增节点，必须覆盖 0 和 1。每个节点记录 `position`、`lower_half_width_m`、`upper_half_width_m`，满足 `0 ≤ 下界 ≤ 上界 ≤ 0.05 m`。界面输入位置百分比及半宽毫米，保存为米。导入原生模型 JSON 上限 64 KiB；拒绝重复字段、非有限数、错误单位、错误类型及非规范内容。未经编辑的导入模型保留原值与摘要，不因界面单位转换改变身份。

来源名称、模型版本、插值规则及可选 UTC 生效／截止日期参与摘要。日期范围含两端；过期或尚未生效的模型不能用于新计算和发布，已有记录仍可完整只读回放。仅有离散样本且没有插值规则时，整段上下界保持未核验，不能生成新变宽路线或覆盖证书。

## 上下界和连接语义

在每条原边的参数区间内，计算两个端点和全部内部节点的极值，不以端点宽度代替段内峰值。插值及极值比较用有理数，半宽下界向内、上界向外舍入。

当前入口作用于 `constructed-surface-route-v1`，保留全部原点、角色、断点与精确锚点。模型全局上界不得超过原生成有效半宽：原 v3／P4 的连接搜索已在该更大的固定包络内完成，P5 保存这一上界关系，并对每条扫描边及连接边按局部上界重新执行参考质量、边界余量和严格支持检查。上界超出原生成包络时，独立保存拒绝原因，要求调整生成宽度后重新生成；不沿用按更窄条件搜索的路径。

原外包检查最小全宽为 0.5 mm。更窄模型的外包仍使用这个更大的保守范围，内包半径不抬高。质量残差邻域保持累计 100,000,000 像素预算，边检查保持 200,000 条上限，严格支持沿用原预算。每条实际保留的连接仍有完整检查记录，连接不贡献作用覆盖；此入口不增加新连接或跨工作块移动。

## 内包覆盖

每条已接纳扫描边的端点提供球种子，半径使用整条原边的半宽下界。与固定版本一样，重复的同面同坐标端点按首次出现确定来源；不把沿段采样解释为连续覆盖。精确表面锚定时仍扣除 XYZ 到锚点的位移，零半径不产生确认面积。

覆盖沿用保守单球整单元包含及正长度公共子边连通证明、原调度／计数／停止边界与原数组格式。空间索引按全局上界建立候选范围，真正包含判定使用各球自己的下界半径。零内包模型允许输出未完成覆盖，不能升格为完成。

模型变化会产生新计算修订，保留原目标身份与所有目标数组，但清除旧覆盖和人工核对资格。不同作用模型下的确认集合和覆盖比例不能直接作增益排名。相同固定半宽退化模型则应与旧固定球计算得到相同证明数组。

## 偏移证据边界

此版本仅支持 `mode=nominal`，名义中心偏移假设为 0；物理中心偏移、配准及标定不确定性仍为 `null`。`offset_evidence` 明确记录 `kind=unknown`，确定性上界与统计区间保留为不同的空字段。没有把参考深度残差解释为设备误差，也没有用可重新计算的哈希替代标定可靠性验证。

带真实偏移证据的有界模式仍待设备试验及适用距离／姿态验证。当前导入不接受伪装成确定性上界的统计区间、手填设备偏移或未知模型类型。`execution_ready=false`、`physical_accuracy_verified=false`，W0／RDF／米、完整场景 RGB-D 和源 Mesh 保持。

## 保存、回读与恢复

完整模型同时绑定计算修订和路线参数；报告记录原严格路线、原边身份、参数区间、上下界、逐边准入、支持证明及连接计数。原生包独立保存 `variable_footprint.json`、`variable_width_report.json`，并保留 `surface_support_report.json` 与 CSV 锚点。便携工程包含同一模型、报告、原目标及可选覆盖数组。

独立回读必须重建目标、验证原严格路线、重新计算逐段界及逐边检查，完整比对当前覆盖证明；原生完整回读继续重建原 v3。缺件、孤立模型文件、混合修订、重新封装哈希的诊断伪造均拒绝。

同一次 Qt 双格式保存可复用原生发布完成后签发的进程内验证凭据。凭据绑定实际模型、路线、目标和覆盖资产，便携写入仍逐文件受界回读及核对；不序列化凭据，独立打开和单独保存仍完整重算。保持整个操作 120 秒、工作台覆盖核心 30 秒及原文件预算。

应用、更改和恢复采用冻结输入后台任务；取消、输入代次或整个方案摘要改变时不安装旧任务结果。成功后须重新核对并保存新版本。过期模型可恢复原严格路线，但实际选区、源数据或生成参数已改变时不能借恢复绕过失效。

“恢复应用模型前路线”恢复原 P4 点列及锚点，并清除变宽覆盖；随后可用 P4 的“恢复常规路线”。旧包仍保留。需要 P3 补充规划时先回到原 P3／P4 工作流；当前不在变宽版本上生成补线，也不把其他模型的旧覆盖拼接进来。

P6 继续保持独立会话模式。跨会话坐标继承还需要固定物体配对采集、独立对应参照、错误对应及姿态扰动试验，不能仅凭任务相同或文件名相近建立继承。

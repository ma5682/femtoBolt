## 热点与改动

既有细分诊断显示，固定目标前沿重放的裁剪约 2.8 秒、深度与状态检查约 1.6 秒、子面扇构造约 2.2 秒。生成、原生保存与独立回读会执行这些步骤。本轮不重复已无稳定收益的面积复用、循环常量外提和裁剪大小分组试验。

两个候选位于 `femto/planning/target_surface.py`：

- 在已有 float64 标量三角面积路径中，用 `tolist()` 获取坐标，替代逐元素 `map(float, ...)`。减法、叉积、左结合平方和及平方根的顺序不改。
- 将每个可见多边形的深度列一次转换为 Python 浮点，按原先“先所有深度范围、再残差”的优先顺序判定，减少小 NumPy 临时数组。仅在 float64、测量值和深度绝对值不超过 1e70 且下溢通知关闭时进入；其他类型、非有限／极端值及下溢通知策略继续原 NumPy 路径。没有扩大容差或改变严格比较。

转换只在本次像素检查中使用，不跨请求缓存，也不复用旧检查结论。面积和深度判定仍逐子面／逐点执行。采样、目标身份、未知状态、逻辑预算、独立保存核验和回读语义保持。

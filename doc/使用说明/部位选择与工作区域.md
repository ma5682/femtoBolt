# 手动工作区域与任务记录

2026-11-02 起取消部位选择、人体示意图和部位记录入口。直接进入局部采集，连接相机并框选扫描范围；检查模型后手动涂抹工作区域，再生成路线、核对和保存。

任务记录不再保存部位、患者侧别、正背面和体位。任务名称可在采集详情中修改，但不用于自动识别部位、患者身份或推断坐标。

“重新采集”在同一任务下创建独立会话；扫描框、参考坐标、模型和路线均需重新建立。“新建采集”创建新的任务标识。缺口后续请求仍绑定原方案和几何证据，不继承旧覆盖结论。

新数据使用任务 v2 和缺口请求 v2，已退役的 v1 部位数据不支持导入。本工作区旧历史已按用户要求物理清理。详见[医师操作流程](医师操作流程.md)和[退役前历史说明](../历史开发记录/部位选择与工作区域_退役前说明_20261102.md)。

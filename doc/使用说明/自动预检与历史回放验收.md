# 自动预检与历史回放验收

本工具用于检查当前工作区环境、枚举设备，并以只读方式核验指定的历史模型或已保存方案。适用于暂时无法配合现场采集时的自动检查；不启动相机流、不获取新帧、不创建新采集。

## 运行

在 `E:\测试3D人体关节坐标-ui` 打开 PowerShell，使用本工作区独立环境：

```powershell
.venv\Scripts\python.exe -X utf8 tools/check_body_surface_replay.py --source outputs/complete_demo_20260926_042446/reconstruction --native-render
```

`--source` 可重复提供，支持现有重建目录或保存的 `planning.region.zip`：

```powershell
.venv\Scripts\python.exe -X utf8 tools/check_body_surface_replay.py --source outputs/complete_demo_20260926_042446/reconstruction/surface_paths/trajectory_3a42283b1d1e/planning.region.zip --source outputs/complete_demo_20260924_233531/reconstruction/surface_paths/trajectory_61dcaf37ec49/planning.region.zip --native-render
```

指定其他历史路径时使用实际存在的记录，不根据文件名猜测任务或部位。`--native-render` 检查本机原生 Qt/VTK 渲染；省略时报告明确记录该项 `not_run`。原生图形检查需要可用的桌面/OpenGL 环境，不能用 offscreen 空白窗口代替。

**当前输入边界：** 工具复用固定参考图规划加载器。局部采集沿用原参考凭据；2026-09-30 起，完整成功的通用顺序里程计记录可在原始/派生来源、位姿链、标定与质量报告核验后进入规划。仅有模型文件或第一帧单位位姿仍不能放行，损坏的局部记录不回退到通用证明。物品实际操作见 [物品采集与工作区域规划](物品采集与工作区域规划.md)。

默认在 `outputs/body_surface_acceptance/<时间>_<唯一标识>/` 创建新报告目录，包含 `report.json`、`report.md` 和请求原生渲染时生成的 `native_*.png`。可用 `--output <新目录>` 指定位置；已有目录或输入记录内部的目录会被拒绝，避免覆盖历史和前次报告。

便携工程按现有加载器规则解包到 `outputs/region_workspaces/` 派生缓存。只读指不改原始 RGB-D、原历史模型及 ZIP；不表示完全不创建派生文件。

## 检查内容与结论

| 检查 | 通过的含义 |
|---|---|
| 工作区环境 | 采集/UI 解释器、源码及核心依赖来自当前独立环境。 |
| 设备枚举 | SDK 枚举正常完成；`detected` 表示发现设备，`not_detected` 表示未发现设备。未发现设备时仍可检查历史，不能据此声称相机就绪。 |
| 历史恢复 | 当前加载器可恢复记录，沿用来源、标定、参考帧、W0 和方案校验；不自动补全缺失部位或新建选区。 |
| 当前选区诊断 | 对已有区域计算网格与参考深度一致像素及待检查像素；诊断结果不写回历史。 |
| 原生显示（可选） | VTK 帧缓冲有内容，相机保持/复位和原始三角面拾取通过，输入几何未改动。 |
| 原件保护 | 检查前后源文件 SHA-256 相同；重建目录核验相关模型、报告及已声明数据集中的帧资产，ZIP 核验原包。 |

`automatic_status=passed` 只表示请求的自动检查通过。它允许“历史成功恢复，但选区仍需复核”的结果。需同时查看各条记录的 `quality`、`review_required`、`confirmed_body_available` 和 `native.status`。运行失败、子进程超时、无记录、环境失败或请求的原生渲染失败会得到失败结果；正常完成时退出码为 0，自动检查失败为 1，参数或输出目录错误也不会返回成功。

“一致比例”是扣除历史禁区后参考影像选区内的像素比例，不是表面积、治疗覆盖率或临床合格阈值。没有保存区域的模型不计算这一比例；缺失部位保持待确认，当前不支持的旧部位不转换为可新建状态。历史禁区、内部留空、分离工作区域及路线原值继续保留。

报告固定标明：`new_capture_performed=false`、`field_acceptance=not_run`、`physical_accuracy_verified=false`、`execution_ready=false`。SDK 枚举不验证帧同步、跟踪或移动采集；原生图形通过也不代表 NVIDIA/CUDA 训练或人体几何能力通过。

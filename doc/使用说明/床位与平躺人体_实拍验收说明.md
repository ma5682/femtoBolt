# 床位与平躺人体实拍验收

当前能力：从可靠深度/重建表面选两个点，计算三维直线距离。床长、床宽和可见人体部位的端点距离可用此方法测量；自动识别部位、曲面路径长度、围度和标准身高尚未实现。屈膝、脚部朝向、呼吸与体动会改变躺卧端点距离，不将它等同于标准身高。

## 1. 采集前准备

在床体刚性部件上设置两处清晰可见的固定标记，用尺或卡尺测量直线距离，记录工具与读数。不要用软床垫或呼吸中的人体作为固定长度基准。至少选择一条长度，条件允许时再添加另一方向/另一位置的参考。床体两端必须有真实深度，单视角拍不全时使用多视角。

先写明可接受的尺寸绝对误差（mm）与三次重复距离极差（mm），当前软件不替用户设定验收容差。至少做3次独立开始/停止的移动采集，而不是对同一段录像建模3次。

人体检查单独记录：目标体表区域、是否被床单/四肢遮挡、是否有缺面/重影、扫描期间是否呼吸或移动。报告尚未自动分析人体ROI覆盖、呼吸运动、全身围度或表面厚度；这些项目保留待现场检查。

## 2. 报告入口

重启主程序，移动采集重建完成后点原有“报告”按钮，优先打开 `result_quality.html`。报告自动汇总原始/跟踪/关键帧数量、重复与拒绝情况、配准内部一致性、几何规模及待验收项目。历史报告缺少新版字段时显示“未提供”，不推测数值。

位姿失败时，派生位姿目录也保存报告；失败没有可用重建模型。不能用双向残差或训练视角PSNR证明毫米级尺寸精度。

## 3. 记录端点并填写验收模板

每个结果目录自动生成 `field_acceptance_spec.json`。文件已经绑定当前重建目录，空值必须由实际数据补齐，不覆盖用户已填写的模板。

- `targets[].id`：同一对物理标记的名称；跨次采集保持一致。
- `ground_truth_distance_mm`：尺量距离。
- `ground_truth_source`：例如工具名称、读数记录、测量日期。
- `absolute_tolerance_mm`：允许最大绝对尺寸误差。
- `repeatability_range_tolerance_mm`：允许重复距离极差。
- `trials`：至少3个独立采集的重建目录，每次使用自己模型的端点坐标。
- `measurements[].point_a_world_m / point_b_world_m`：三维端点坐标，单位米。

在现有模型查看器中用“选点模式/两点测距”选同一对标记，保存标注。`annotations.json` 的 `points[].point_world_m` 提供该模型的米制坐标。必须确认标注来源正是对应 trial 的模型，不能把上一模型的坐标复制给新模型。

也可使用现有 `validate_scene_scale.cmd --reconstruction <重建目录> --pick --ground-truth-mm <实测距离> --geometry-source tsdf_mesh`，在窗口里 Shift+左键选择两点并关闭窗口，生成 `scale_validation_spec.json` 后复制该次两个端点到统一验收模板。

统一验收默认端点吸附半径2mm；如果端点不在真实重建表面附近，计算拒绝。不要为了通过验收扩大吸附半径。测量使用网格/点云，不使用Gaussian渲染中心。

## 4. 生成尺寸验收结论

在项目目录命令行运行：

```powershell
& '.\生成实拍验收报告.cmd' 'E:\测试3D人体关节坐标\outputs\某个结果目录' --spec 'E:\测试3D人体关节坐标\outputs\某个结果目录\field_acceptance_spec.json'
```

模板中的 trials 必须包含该结果模型。程序重新读取每个模型几何、计算端点距离和误差；报告记录几何SHA-256及原始RGB-D内容指纹。同一段原始采集即使复制目录或重复重建，也不能计作独立重复试验。

输出 `result_quality.html`、`result_quality.json`：参考/容差/测点/次数不足时 PENDING；已完成测点超过容差时 FAIL；所有指定距离满足容差且至少3次独立测量时 PASS。PASS只代表所填距离项目通过，人体动态、完整表面、机器人定位没有因此自动验收。

当前没有床体尺量距离、容差和三次对应测点，因此尚无真实尺寸或人体长度验收结论。已有历史实拍示例不是床位人体新采集。

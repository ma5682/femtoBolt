# 局部采集：最多三帧，完成后涂抹选区

适用于 2026-11-05 更新后的源码工作台。准备和采集中共用同一全宽页面，右侧栏及“详情”入口已移除。关闭当前程序后用本工作区 `start_femto_app.cmd` 重新启动，旧 EXE 不含此次更新。

1. 连接相机，等待有效 RGB-D 画面。顶部显示“0 / 3 帧”，点击“开始采集”即可；任务自动命名，无须先框选范围。
2. 首帧通过深度、位姿和写入检查后显示“1 / 3 帧”，点亮第一段进度。此时即可点击“完成采集并选区”。
3. 也可缓慢移动、保持重叠，停稳后点击“停稳补采一帧”。最多接纳 3 个有效视角，含首帧；两帧时也可提前完成。第三帧和对应位姿保存成功后自动结束并进入选区，不再接纳第四帧。重复、不合格或写入失败的帧不计入。
4. 提前完成或满三帧自动结束后显示固定首帧 RGB。涂抹目标，再点击“确认选区并重建”；仅重建涂抹区域，不扩大周边。原测量层仍按实际贡献帧数生成：单帧保留实测深度像素邻接表面，多帧保留按各自位姿融合的测量模型。单帧、多帧生成新路线时共用独立的 TSDF 规划表面，不覆盖原测量层。
5. 局部重建完成后自动进入模型与路线页，原始选区自动恢复。核对模型和缺口后生成路线、保存。选区缺失、遮挡和参考深度未知仍须处理，帧数满三帧不代表质量合格。

原始连续跟踪帧数量可能多于界面接纳帧数；内部五帧候选窗口属于停稳检查，不计入三帧进度。原始完整 RGB-D、标定、位姿继续保留；未用补洞或假位姿替代缺失观测。派生规划表面沿用 5 mm TSDF 及原测量支持核验，参数不代表实物测量精度。

仍保留 5 分钟会话时限及离线时间/内存预算，不放宽位姿、重叠、深度或局部移动范围门禁。暂停后须恢复跟踪并停稳才能提前完成；取消保留原始证据。

模型页的“标记/重建”可复用本进程中的本次采集帧，调整区域后生成新模型，旧模型和保存方案保留。关闭程序后恢复未完成选区会话的界面入口暂未提供。

历史记录按其实际帧数显示，已有四帧或更多帧的记录不截断、不改写。新采集三帧自动结束已通过模拟边界验证；本轮未操作实际设备。采集帧数、选区大小及几何复杂度都会影响后续耗时，不能仅凭帧数保证全链速度。

2026-11-04 源码更新改善了涂抹响应、模型连通性检查及目标计算，沿用上述操作，无须新增设置。实际只有一帧对选区贡献时，即使采集了多帧，也会自动采用单贡献帧处理；两帧及以上贡献保持局部融合。重新启动本工作区源码程序后生效，已有 EXE 未更新。保存和打开工程仍会独立核验，请等待完成提示；不会以显示路线代替保存成功。真实单贡献帧离线对照有改善，但采集、固定参考和所有其他阶段尚未普遍提速，范围见[本轮记录](../技术资料/全流程响应与计算提速_20261104.md)。

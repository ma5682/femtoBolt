# 局部采集三视角自动结束

适用于2026年10月28日更新后的源码工作台。先关闭当前程序，再用本工作区`start_femto_app.cmd`重新启动。已有R7 EXE尚未包含此更新。

1. 连接相机，在实时画面框选扫描范围，开始局部采集。
2. 初始参考视角通过检查后显示“1/3 帧”。缓慢移动相机，保持画面重叠，停稳后点击“停稳补采一帧”。
3. 达到“3/3 帧”后自动结束采集并生成模型，无需再点击完成。重复视角、质量不合格帧不会占用名额。
4. 模型生成后核对扫描范围、目标与边界，再确认进入规划。有缺口时点击“重新采集”，调整取景；本次已经结束的会话不能增加第4个视角。

上限包括初始参考帧，总共最多3个用于融合的有效视角。后台连续原始帧用于位姿跟踪及停稳检查，文件数量可能超过3；候选帧进度的“/5”表示独立的五帧稳定性提示。收尾和重建期间仍可取消，原始数据保留。

历史记录按其原帧数回看，不会截成3帧。模型生成成功仍需检查覆盖；这次帧数限制不增加机械臂执行或实物精度资格。

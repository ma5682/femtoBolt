# 第一批：定位数据基础与距离测试

本次新增可操作的实验记录与追溯入口，不代表设备定位精度已达标。

## 使用方法

1. 重启程序，打开局部模型的固定 RGB 选区窗口。
2. 在同一刚性测试物上选择两个可以用尺准确辨认的表面点。
3. 在右侧标记列表按 Ctrl 选中这两个点，点击“记录实测距离（选中两点）”。
4. 填写测试编号、两点间独立尺量的直线距离、参考测量误差界限、实验允许偏差、量具和条件。
5. 点击“数据质量 / 精度测试报告”查看统计；“打开精度测试记录”打开记录与历次报告目录。

这里录入两点间直线长度，不能录入沿皮肤的曲线长度，也不能用相机外壳到目标的尺量距离替代。参考测量误差界限应依据量具和读数方法填写，不能为获得通过结果随意设为零。

同一测试编号用于同一物理目标。改变目标、参考长度、量具或条件后单独记录。相同模型反复选点只表示选点重复性，不表示相机重新采集的重复性。单次实验显示界限内/界限外/参考误差导致不确定，均不升级系统临床状态。

## 保存内容

当前 `reconstruction/measurement_validation/` 下：

- `records/<uuid>.json`：两个点、三角面、W0坐标、参考图指纹、模型指纹、人工参考及条件。
- `report_<uuid>/report.json`：可追溯证据、现有融合诊断快照、当前可匹配的实验和分组统计。
- `report_<uuid>/measurements.csv`：实测明细，可在表格软件查看。
- `report_<uuid>/报告.md`：中文概览。

生成报告会重新验证点是否位于对应三角面、参考图/模型绑定并重算距离；不相信旧记录中缓存的误差值。不同模型和参考图记录被排除并写明原因。原始采集、模型和旧记录不会被覆盖。

区域 GLB/PLY 导出的 JSON 及路径 JSON 新增统一数据分层契约。GLB照片纹理、显示法线、显示路径管线都不是新的测量数据。新契约不匹配时拒绝回读；旧文件沿用已有几何指纹、坐标系和原点校验。

## 检查范围与限制

校验标定和参考RGB/Depth指纹；记录帧清单、位姿、源模型和现有报告指纹。其他采集图像检查是否存在，不全量重算内容哈希；报告没有重新执行整条融合算法或逐面支持检查。原始深度支持声明与内部残差不是独立物理真值。

选点区分“参考深度一致网格交点”和“首帧缺深度但网格有支持”；两者都是派生几何，不是独立验证后的治疗坐标。已有补洞隔离和原始深度支持筛选未放宽。

10–20 mm没有自动写入融合门限；实验允许偏差由用户填写，仅用于实验比较。两点距离测试不能证明绝对XYZ、表面法线、患者呼吸运动下的定位或接触安全合格。

后续仍需独立真值、重复采集实验和不同工作条件的验证。本批未实现机器人控制、接触力控制或实时呼吸补偿。

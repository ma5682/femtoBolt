# 从局部采集到方案保存

当前工作台使用五个连续步骤：**局部采集 → 检查模型 → 标记区域 → 生成路线 → 核对保存**。顶部可点击当前记录中可用的步骤切换，当前步骤用绿色下划线标出；灰色步骤尚不可用，悬停可查看原因。也可用 Tab 定位可用步骤，再按空格切换。步骤位置不表示质量通过，进入后续步骤仍须满足原有条件；历史记录不据此推断此前采集或人工核对已经完成。

返回“标记区域”“生成路线”或“核对保存”会保留当前标记、参数、路线和核对状态。只查看不会让路线过期；修改区域后须重新检查并计算，修改路线参数后须生成与当前参数一致的路线并重新核对。首次从采集进入规划仍需确认模型，不能用步骤栏跳过。

关联采集可以核验时，可点击前两步回看本次记录。已结束采集的“局部采集”明确显示“回看”，不会启动相机或修改原采集；修改扫描范围请新建采集。从回看页点击规划步骤可直接回到原草稿；预览读取失败后也能返回已加载的规划。缺少关联采集的便携方案会禁用相应步骤，历史方案的标记与路线始终只读，编辑需点击“基于此版本修改”。采集（含暂停）、建模、读取、计算或保存期间暂时禁用步骤切换，完成或取消结束后恢复。

1. **局部采集**：连接相机，等待有效 RGB-D 画面后点击“框选扫描范围”。扫描框应包含目标及所需周边；它不等于后续涂抹的工作区域。框选不会自动启动采集。
   点击右下角“确认范围并开始局部采集”。按停稳、跟踪和范围提示采集不同视角；“停稳补采一帧”和“完成采集并检查质量”固定在底部，暂停和取消也在同一操作区。完成仍需满足原有视角、位姿和设备准入条件；至少三帧不代表覆盖已经完整。
2. **检查模型**：读取成功后，若存在已经核验的扫描范围检查图，会先展示“缺口检查”。检查紫/橙色待处理范围，再切换“三维模型”核对目标与边界；必要时使用“重新采集”。没有扫描范围证据时显示模型并明确提示尚未核验。参考图像像素比例不是完整三维表面覆盖率。进入规划仍需原来的明确确认。
3. **标记区域**：右侧使用“涂抹工作区”和“擦除”，调整笔刷大小，可撤销、重做；不要把扫描框当作工作区域。常用工具下方直接显示“选区检查”、颜色说明和“定位待检查处”。清空、复位、适应选区及名称备注放在“更多”中。顶部“来源与操作”可展开完整任务来源、坐标说明及打开/返回入口。底部“下一步”仍会执行原有区域与几何检查，折叠详情或切换色层不改变标记和检查结论。
4. **生成路线**：选择直接指定行距，或按有效作用宽度与重叠率计算；当前模式只显示参与行距计算的输入，有效作用宽度始终保留用于覆盖带检查。核对参数来源和单位后，点击底部“计算三维蛇形路线”。生成后右栏显示行距、宽度、工作块与连续路线数，参数表自动收起；画面上方可播放、暂停或重播路线。待核对项数、当前选区待检查像素、块内断点和未规划的块间移动直接显示，“展开检查与统计”可查看完整清单、几何检查、报告和重算入口。修改参数后旧路线仅供参考，播放和保存会禁用，需重新计算；未知质量仍显示待核验，生成成功不等于覆盖通过。
5. **核对保存**：逐项查看区域、断点和覆盖提示，再明确勾选核对并保存。存在待处理项时仍按原规则保存为待复核研发草稿；历史修改保留原版本并另存新版本。

操作示例：连接相机 → 在当前 RGB 框选扫描范围 → 按提示采集 → 检查缺口和三维模型 → 涂抹工作区域 → 生成路线 → 核对并保存。无需选择部位、侧别或体位。

界面只展示当前阶段可用的统计和入口。未开始采集时不显示“0 帧”和不可用报告按钮；采集后仍可检查质量、打开报告。任务名称、设备与参考位置明细位于右栏“展开任务与设备详情”；完整诊断仍可通过左下角“状态详情”查看。扫描范围确认后可在右栏修改；底部准备操作始终不随右栏滚动。过期、缺失或错误警告优先显示在画面上方，底部不重复同一句警告。

本次更新没有自动计算补扫方向或移动距离，没有新增病例身份绑定、患者运动补偿或设备执行能力。实际操作连贯性、真实 Windows 缩放和相机现场体验仍需人工验证。

### 取消与历史回看提示（2026-10-12）

规划或历史读取中点击取消后，按钮会显示“正在取消…”并暂时禁用。请等待当前处理结束后重试或切换；请求取消不等于保存产物全部撤回，实际保留结果以结束后的提示为准。

历史回看只开放该记录实际包含的图层：没有保存区域时不能选择区域图层，没有可回显路线时不能选择“已保存路线”。如需编辑，使用“基于此版本修改”；仅有模型的记录使用“开始工作区域规划”。参考图与三维视图的检查不会直接编辑历史文件。

任务栏、历史来源及读取提示中的长英文名称和路径可换行显示，完整来源路径可在来源提示中查看。显示换行不会改写任务名、路径或保存内容。

### 参考图编辑与固定三维检查

参考图左键涂抹/擦除，右键平移，滚轮缩放。色层仅显示已涂抹选区的几何检查结果；未涂抹时不会给整张照片着色。切换三维后隐藏编辑工具，拖动平移、滚轮缩放，朝向固定。修改后的选区核验成功才显示三维区域；返回参考图可继续修改。更新源码后请正常退出并重新启动工作台生效。

三维检查现在自动展开至整个工作区，隐藏右侧编辑/检查面板及底部常规操作；左上角切回参考图即恢复。处理中与失败时仍显示任务反馈。

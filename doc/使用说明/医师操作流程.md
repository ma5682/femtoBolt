# 从局部采集到方案保存

当前源码工作台围绕四个可见阶段组织：**采集 → 涂抹选区 → 模型与路线 → 保存**。不需要先选身体部位。顶部突出当前阶段，底部主要按钮表示下一步；灰色阶段尚不可用。界面步骤不代表几何质量已通过。

准备和采集中共用全宽取景页，移除右侧栏及“详情”入口。顶部显示 **0 / 3 帧** 和三段进度，接纳后原地更新；任务自动命名，直接按完整画面开始采集，之后再涂抹工作区域。连接状态、异常提示和开始、完成、暂停、取消操作仍在主页面。

## 完成一次规划

1. **采集**：连接相机，等待有效 RGB-D 画面，点击 **开始采集**，保存完整原始帧。按停稳、跟踪和深度提示采集；接纳一帧或两帧后即可点击 **完成采集并选区**。最多接纳 3 个有效视角，含首帧；第三帧和对应位姿保存成功后自动结束采集、进入选区。重复、不合格或写入失败的帧不计入进度。
2. **涂抹选区**：在固定参考 RGB 图上涂抹，可直接选择擦除、撤销、重做、清空或视图复位。可以画多个分离区域，擦除可以形成留空。点击 **确认选区并重建**，程序只重建最终涂抹区域，不再额外扩大周边；擦除和留空不纳入。无需选择算法或设置周边宽度。边缘没有足够实测支持时保留缺口和待确认提示。

   提交成功后按钮立即改为 **正在重建局部表面…**，显示处理提示和进度动画；动画表示任务仍在处理，不代表完成百分比。若未能提交，会说明原因并保留涂抹。完成后自动进入模型与路线页，后续表面分析会单独显示处理状态。
3. **模型与路线**：局部重建完成后自动进入路线规划，直接展示已按涂抹区域过滤的三维模型、缺口提示和路线参数，无须再点“已查看模型，继续规划”。在本页核对模型、有效作用宽度和重叠要求，点击 **生成路线** 即确认使用当前模型并开始计算；自动进入页面不会写入人工确认，也不会清除缺口。重建前的完整选区自动恢复并核验，无须重画。此页不提供涂抹、擦除、笔刷、撤销和清空按钮，参考图只用于核对；需要修改区域时返回第 02 步并重新建模。算法试验、采样与调试选项放在折叠设置中；已配置的有效参数在同次工作台中保留。单帧和多帧使用同一流程。
4. **保存**：查看路线顺序、缺失区域和断点，勾选核对后保存。默认自动命名并保存模型关联的原生路线和可编辑工程，不要求选择中间文件或手填路径。成功后显示 **规划方案已保存**；需要指定位置时可使用另存入口。重新打开时从历史方案列表选择记录。

完整示例：连接相机 → 开始采集 → 一帧或两帧提前完成／满三帧自动结束 → 固定图上涂抹 → 确认选区并局部重建 → 自动进入路线规划 → 生成路线 → 核对保存。

新生成的路线默认先完成路线坐标和几何检查，目标面积与覆盖统计按需计算。可以直接播放、核对并保存路线；需要面积和覆盖结果时，点击 **计算面积与覆盖**。没有点击时显示“尚未计算”，不会给出覆盖完成结论。检查会保留当前路线坐标和顺序，完成后需重新核对并保存。旧方案已有的面积及覆盖结果继续按保存版本核验；含新待计算状态的工程需使用当前源码版打开。

## 查看结果和问题

局部重建已取消自动生成点云辅助统计、Gaussian 预览、多帧照片纹理、训练目录和独立 HTML 报告，无须选择或等待这些步骤。固定参考图、带顶点颜色的完整测量模型、模型检查、路线规划和保存回读保持。处理状态和来源仍记录在结果中；未做的辅助统计不表示已通过质量验收。需要重新启动源码工作台生效，旧 EXE 不会自动更新。

- 固定参考图的显示清晰度与三维计算密度分别管理。缩放图片不会自动提高建面或规划密度。
- 原始 RGB-D 保留完整画面。主要建面和融合只使用按位姿映射到最终选区的可靠观测；不同帧不直接套用相同像素裁剪。
- 原始测量层仍按实际贡献帧数保存：一帧保留完整像素邻接网格，多帧保留按实际位姿融合的测量模型。生成新路线时，两者共用独立的 TSDF 规划表面；原 RGB-D 和完整原测量模型不会被覆盖。处理详情分别记录采集、接纳、位姿有效及实际建模帧数。
- 一帧和多帧使用相同的选区、模型检查、规划和保存操作。2026-11-05 起，带完整来源绑定的新局部规划统一使用 5 mm 体素的派生表面，并对照原测量表面检查。当前版本要求原参考像素有实测支持，且规划点到同一实测连通表面的三维距离可确认不超过 2 mm；缺少支持或未通过检查的位置仍显示为未确认，不会缩小原选区。该处理减少倾斜或局部起伏表面被轴向深度差误判而产生的路线碎段，不会补出未采到的表面。体素尺寸和检查阈值不代表实物测量精度。治疗头作用宽度、重叠率和行距规则保持。旧方案按原版本回看，未自动升级为新表面；已有方案需要重新生成才能采用新处理。
- 新建局部路线会自动选择内部计算路径，无须按模型大小选择算法。历史方案仍按保存版本核验。若计算达到预算上限，当前模型和选区继续保留，按提示检查待处理项或重试；程序不会为完成计算而自动缩小原选区。
- 保存的便携工程同时保留完整局部原表面、规划派生表面和路线；新重建的两种表面均限于本次选区；旧方案保留其原周边范围。原始 RGB-D 作为来源关联继续保留，未把选区外整场景加入规划模型。打开旧方案不会自动改写它的路线。
- 2026-11-04 起，源码版保存采用更快的无损压缩，文件可能略大；模型精度、路线内容和打开时的核验保持。无需调整选项，旧工程仍可打开，已有文件不会自动重写。
- 没有有效深度、被遮挡或无法可靠映射的目标像素保留为缺失或待处理，不能通过缩小原选区把问题隐藏。
- 黄色路线不等于整体覆盖已经合格。分离区域、未知表面和无法验证的连接继续显示分段；未规划的块间转移由后续设备系统处理。
- 有待处理项的结果按现有规则标记为待复核研发草稿，不能当作已完成治疗覆盖或机械臂可执行轨迹。

## 返回修改或重试

本次采集仍在当前进程中且来源一致时，可以从顶部 **涂抹选区** 返回修改，复用已采集帧与位姿。标记保留，新重建仅使用最终选区并写入新目录，不覆盖原模型和已保存方案。重启后尚未完成建模的原始采集仍保留，但当前界面没有恢复待选区会话的入口。

仅查看不同阶段不会让结果过期。修改选区或影响几何的参数后，受影响的结果需要重新计算。修改路线参数后，旧路线不能继续播放或保存为当前结果。

处理中显示进度和取消入口。点击取消后等待当前处理结束；取消请求不等于已经发布的文件全部撤回，保留产物以最终提示为准。失败后查看页面提示并重试，完整技术原因在详情中。取消或旧请求的迟到结果不会安装为当前模型或路线。

## 历史与视图

规划页和历史回看的三维模型只显示当前确认的工作区域，擦除、内部留空和外部表面不显示；没有选区时不会改为显示整个模型。局部重建后的固定参考图只用于核对，重新涂抹在第 02 步完成；未绑定重建选区的旧导入模型仍提供区域编辑。

历史方案只显示其实际保存的图层。缺少文件时提示缺失类别，不使用当前相机画面补充历史数据。编辑历史方案使用 **基于此版本修改**，保留原版本。

历史页切到模型或参考画面时，图层选择入口仍保留，可继续切回已保存区域或路线。在三维视图勾选 **显示当前选区几何检查色层** 时，会自动转到固定参考图显示对应检查结果。选区重建失败时展开 **失败详情**，原笔画保留以便重试；正常状态不再显示无参数可调的“高级设置”。

便携方案会核验包内参考图、模型和路线，并单独核验能否找到匹配的原采集来源。新建局部模型还记录并核对各接纳帧的图像、深度、位姿及标定文件指纹；旧方案缺少该证据时会说明核验范围。原来源缺失或不一致时，页面直接显示提示，原因和路径放在 **来源详情** 中；仍可回看包内已核验的结果，但不能跳转到其他采集冒充原来源。恢复匹配来源后重新打开可再次核验。这不表示重新检查了当前人体状态。

第 02 步的参考图支持左键涂抹或擦除，右键平移，滚轮缩放。三维模型检查保持固定朝向，可用滚轮缩放或点击 **复位视图**；路线规划时右侧参数和底部主操作持续可见。长路径和来源可在详情或提示中查看。

第 02 步顶部显示“涂抹选区”和已保存帧数，工具栏用滑块或数字框调整圆形笔刷直径（屏幕像素），默认 40。青绿色填充和描边表示选中范围；撤销、重做、清空保留原像素语义，已有方形笔刷留下的边界不会自动变圆。缩放比例位于工具栏右侧，底部保留取消和确认重建；失败详情及笔画保留。

在历史中选择一条采集后，**区域与轨迹** 会同时列出保存在其派生规划目录中的关联方案。采集记录的 **查看** 优先打开此采集最近保存且来源核验一致的方案，恢复选区和路线；尚无保存方案时恢复原重建选区。历史回看仍为只读，暂不支持从历史记录返回第 02 步重新涂抹。

当前输出为研发用几何表面路线。它保存坐标系、单位、点序、法向和分段，但没有完成机器人基座变换、工具姿态、碰撞检查或运动控制验证。源码更新需要重新启动工作台，旧 EXE 不会自动更新。

自动化使用离屏 Qt 和合成 RGB-D 数据，并对 2026-11-03 已采集的真实单帧桌面数据离线复测。该密集样本仍超过十秒目标；结果和范围见[实采复测记录](../技术资料/表面粗分区规划与实采复测_20261103.md)。实际 Windows 缩放、相机现场操作、人体表面、目标 ARM 性能和机械臂联调仍需对应设备验证。

当前源码继续缩短路线生成与核验等待，单帧和多帧使用相同操作，无需增加步骤或调整参数。原选区、孔洞、缺失范围和最终路线支持判据保持；重新选择区域或更改参数后重新准备相应数据。保存与回读仍核对路线和来源，旧方案按原版本打开。实际等待取决于选区、几何复杂度与系统负载，不保证每次都有相同耗时。重新启动源码工作台后生效，当前 EXE 未随源码自动更新。

# 原目标分块续算与缺口处理

适用当前Qt工作台。结果仍为研发几何规划；质量未确认、数值未知与计算预算退出分别保留。

## 继续建立原目标

1. 使用已有选区和路线核验模型覆盖，在覆盖面板选择“目标含未定位范围”。
2. 原因可筛选“目标建账预算未处理”，点击“检查未定位范围”。
3. 在缺口检查窗口点击“继续建立原目标的下一块”。每次只推进下一块，仍受原单块预算、累计资产大小和操作预算约束。
4. 续算完成后，路线不变，原目标增加已处理单元；旧方案与证据保存在提示的新目录下。扩展后的目标需要点击覆盖核验，再核对并保存为新版本。

各块都由同一原目标和完整输入重现。覆盖计算使用完整表面，不在块边界人为切断连通证据。已处理不等于已定位或已覆盖；预算原因减少后可能转为数值未确认、部分定位或真实缺面。对严格、变宽或补充版本，先使用既有恢复入口返回常规路线后再续算，然后按需重建派生版本。候选索引预算退出暂不能按此像素组前沿续算，系统会保留原结果并报告原因。

## 精确核验数值与部分定位范围

在覆盖面板选择“目标含未定位范围”，原因筛选“数值未确认”或“部分定位”（也可选择全部原因），点击“检查未定位范围”。对常规路线，窗口提供“精确核验数值与部分定位范围”。系统保留原始选区、参考深度、网格与路线点，重新分块建立目标；只有能够严格证明完整的像素格才转为已定位。真实缝隙、缺面、重叠和深度冲突保留原有含义。

这会创建新的目标计算修订，并保留旧方案及其目标、覆盖证据。完成后需重新核验模型覆盖、人工核对并保存为新版本；已定位不等于已覆盖。严格、变宽或补充路线先通过既有恢复入口返回常规路线，再进行此项核验。取消、超预算或失败不会安装新结果。已经使用精确分区的版本不重复提供此按钮；真实数据缺口需要按观测原因处理。

## 继续减少覆盖预算未处理

对已经建立分块目标、且已保存固定名义作用模型覆盖证据的方案，使用现有“核验模型覆盖”入口。系统先重新证明原确认集合，再归并同一候选组内完全相同的当前包围盒比较，减少重复计算。旧工程打开仍按其保存版本回读；主动复算才使用新版本。完成后核对统计并另存新版本。

这一步不改变原目标、路线或覆盖判定门限。预算未处理减少可能转为明确的覆盖球外范围，不代表新增覆盖。真实样本本轮190093→181140，原确认集合保持；重复点击同一输入不保证继续推进，也不自动补扫。详见[实施记录](../历史开发记录/分块覆盖重复边界比较优化_20261016.md)。

## 检查缺面与发起重采

缺口检查窗口显示当前定位范围的实测参考深度及有效像素数。“按原参数排查重建缺面”在独立目录重建，逐阶段检查TSDF提取、拓扑清理、两次小分量过滤和实测支持校验。结果说明缺面在哪一步出现，以及下一步应核对观测一致性、三角形实测支持还是孤立分量噪声。它不会自动替换模型或恢复被拒绝的三角形。

确认需要新观测后，可选择“为该任务与部位重新采集”。系统先保存来源方案、准确缺口掩膜和请求摘要，再进入独立采集。选中全部未定位原因时，重采请求仅关联观测原因；预算和数值范围另行处理。没有已确认的任务与部位时不提供该操作。

新采集沿用任务标签并保留缺口请求来源；如果修改部位、侧别、正背面或体位，则清除该关联。新结果仍需核对和确认，在新模型上重新选区、生成路线并核验覆盖。打开新结果时工作台会提醒这些步骤；新方案保存和回读保留来源请求。请求关联不代表旧缺口自动解决，也不自动继承旧目标坐标或旧覆盖结论。

## 当前验收范围

# 固定作用宽度自动排布

当前源码新建方案在路线生成页默认选择“固定作用宽度自动排布”。输入有效作用宽度和期望重叠率，生成时根据选区三维表面安排扫描线。有效作用宽度不因狭窄区域而缩小。

“最大行距”是作用宽度与期望重叠率确定的排布上限；实际切片间距按表面和边界调整，生成后参数摘要显示候选行数和切片间距范围。沿线取点间隔是另一项参数，现有自动取点机制继续使用。

当前新生成采用局部残差排布v2：左右边缘分别根据半作用宽度和已有参考残差确定内缩，实际内缩量随数据变化。这些残差来自参考深度与模型的一致性检查，不代表已知设备定位精度。旧自动v1方案回读保留原排布。

手动指定行距请选择“直接指定行距”。已有方案和草稿保留原模式，打开不会自动改成新路线；修改参数后须重新生成并保存为所需版本。

覆盖带边缘贴边要求路线中心向内偏移，不能把路线中心直接画在边界上。当前全部扫描和连接继续检查固定宽度、局部误差余量及表面支持。狭窄、缺失或无法核验连接处会保留断点；没有连接不等于已证明实际不可达。

不能根据黄色中心线或自动排布行数认定完整覆盖。使用“核验模型覆盖”检查原目标覆盖状态，并用原因筛选和“定位”查看种子未触及、质量待检查、细分到限、预算未处理和未定位范围；这些状态不能统称已经证明漏扫。名义几何覆盖不等同于实际治疗覆盖。实体外壳避让、接触控制和真实执行不由此模式完成，原执行资格标志保持关闭。

自动模式的参考图上可勾选“名义宽度示意”：青色为三维扫描段沿其来源面的横向固定宽度投影，黄色为路线中心线。它不延伸跨越断点，也不假设连接段开启作用。示意不裁掉看似越界的部分，以免掩盖边缘问题；曲面和跨面处可能出现接缝或重叠，不能据此判断真实贴合或完整覆盖。开启“显示模型覆盖”时隐藏青色示意，改用核验证据的状态颜色，并保留黄色中心线。

# 严格重建路径与版本回退

生成常规路线后，可在“生成路线”页点击“严格重建路径”。系统按当前网格重新构造表面点，检查整条边的支持关系，并重新检查作用宽度、参考质量与边界。原常规路线保留；重建失败或取消时，当前路线和覆盖仍保留。

正常操作顺序：

1. 生成路线，检查工作区域、断点和缺失范围。
2. 点击“严格重建路径”，等待完成；可使用原“取消任务”。
3. 查看重建后的路线及未确认原因。系统可能保留断点，不保证路线更长或覆盖更高。
4. 点击“核验模型覆盖”。重建前的覆盖不属于这条新路线，需要重新计算。
5. 有当前覆盖结果后，可点击“严格补充规划”；系统只尝试可用表面上的候选，并重新验收和比较覆盖增益。
6. 进入“核对保存”，重新核对后保存为新版本。历史可回看相同路线及其完整证据。

“严格”指当前数值网格内的路径支持，不表示采集精度、实物精度或治疗覆盖获得保证。缺失、质量待检查和未定位范围仍保留；实际误差未知时不会补成零。

需要退回时，严格基本版本可直接点击“恢复常规路线”；恢复后重新核验覆盖。已经做过严格补充的版本，先点击“恢复补充前路线”，恢复该严格路线与对应覆盖，再按需要恢复常规路线。历史文件保持原样，当前恢复结果另存新版本。

点击之前的流程节点查看已有区域或路线，会保留当前结果。修改工作区域、作用宽度、参考输入或模型后，旧结果会停用，需要重新生成或验证。历史回看为只读；需要修改时从历史进入新版本编辑。

旧版 v3 和 P3 方案仍按保存时的算法回读。缺少原目标台账的旧路线，先按当前流程生成带台账的新路线，再启用严格重建。若提示构造预算、微缝或质量约束无法通过，可检查报告、调整有依据的工作范围或补采；保存成功不会把未确认范围变成已确认。

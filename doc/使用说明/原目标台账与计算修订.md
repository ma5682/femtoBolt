# 原目标台账与计算修订

2026-10-09。本轮完成后续迭代方案的 P0／P1。工作台在生成路线时保留原选区的目标账目，并检查路线是否仍对应当前输入。

## 如何使用

1. 结束当前工作后重新打开工作台，加载本轮代码。本次开发没有重启你正在使用的工作台，也没有操作相机。
2. 按原流程选择记录或采集、检查模型，在“标记区域”涂抹并确认工作区域。
3. 在“生成路线”检查参数并计算。后台先建立原目标台账，再按现有 v3 规则生成路线；可使用“取消任务”。
4. 查看右栏“原目标台账”的未知像素提示。展开“检查与统计”，可以看到已定位面积、其中未进入当前有效域的面积，以及含未定位范围的像素数。
5. 播放检查后进入“核对保存”，阅读完整待核对事项；内容较长时滚动右栏。勾选核对后保存研发草稿或预览。保存包含对应台账、路线和参数，便携工程回读会重新校验。

顶部已开放的流程节点仍可点击返回；仅查看页面不会清除选区、路线或核对状态。实际修改输入后需要重新计算或核对。

## 如何理解提示

| 提示 | 含义与处理 |
| --- | --- |
| 已定位面积 | 原选区中可以定位到当前规范网格的名义面积；不是已覆盖面积 |
| 未进入当前有效域 | 仍属于原目标，但当前质量/区域资格不允许既有路线在此规划；不会从原目标中删除 |
| 像素含未定位范围，面积未知 | 包含完全无法定位及只有部分范围能定位的像素；不能按像素数换算面积 |
| 模型表面覆盖尚未核验 | 本阶段没有覆盖证书，已有路线或采样指标不能证明全部表面被覆盖 |
| 输入或当前模型已变化，旧任务结果未安装 | 后台结果来自此前输入；当前修改保留，请重新计算 |
| 标记刚刚更新，请先确认工作区域 | 启动操作时仍有未结束的笔画；先确认更新后的区域，再执行下一步 |
| 旧记录未进行此项核验 | 原文件没有新台账；可按历史规则查看，需要新账目时重新生成并另存新版本 |

当前参考图的“待检查像素”与原目标的“含未定位范围像素”来自不同检查。前者检查像素上的参考深度/网格一致性；后者还检查整个像素单元与表面的归属，所以两个数字可以不同。

计算达到预算时，未处理的目标继续保留为未知。原目标账目不等于补规划；本轮不会自动填补缺失几何或连接分离工作块。

## 哪些操作影响旧路线

- 修改选区、参考 RGB/Depth、几何、标定/原点/任务体位、质量规则或规划参数后，旧计算不能作为当前结果保存。
- 修改名称、备注或仅切换流程节点，不改变计算修订。
- 参数恢复到与已有路线**完全相同的完整输入**时，可再次使用该路线；人工核对需要重新勾选。
- 取消、换记录或新输入到来后，旧后台任务不得覆盖当前结果。保存失败时按界面提示处理；失败提示会说明已经成功保存的部分。

旧记录不会被自动升级，也不会因新增台账而被改写。重新生成后保存到新版本即可保留原记录。

本版面积、坐标和路线用于研发检查。P2 覆盖证书、P3 补规划以及实物精度验收尚未完成，结果不具备设备执行资格。

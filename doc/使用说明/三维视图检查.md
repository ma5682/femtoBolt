# 工作台三维视图检查

规划页和历史只读回看页上方可在“参考图与标记”和“三维模型检查”之间切换。首次进入三维模式时加载 VTK 视口；任务、选区、参数和保存版本不因切换而改变。

- 参考图用于工作区/禁区标记和路线播放，保留固定相机像素坐标。三维模式下禁用二维画笔；点击播放会返回参考图。
- 三维视图用左键拖动旋转、中键拖动平移、滚轮缩放。“复位三维视角”恢复初始检查方向；改变图层保留视角，切换模型重新适应。
- 绿色显示已确认工作区域，黄色显示当前可用路线或历史保存路线。不同路线段独立绘制，不自动补连断点。三维模式不显示未确认的二维笔画；禁区请在参考图核对。
- 单击网格显示原始三角面编号和世界坐标（米）。拾取只提供研发核对信息，不修改区域、不生成治疗靶点或控制指令。
- 历史中的“参考画面 / 工作区域与禁区”在三维模式对应“三维模型 / 已确认工作区域”。历史回看始终只读，修改须进入新版本。
- 三维显示失败时保留参考图，显示错误和重试入口。VTK 需要原生 Qt 窗口及 OpenGL 3.2；Qt offscreen/minimal 测试平台不会创建三维窗口。

本批迁移覆盖规划和历史回看；采集实时预览和旧独立调试查看器尚未迁移。原始 RGB-D、三维计算、规划算法和归档格式保持原有约定。

# 局部移动补采与区域标记

更新：2026-09-20。固定 RGB 产品页现采用单次区域提交与保存；已加入优化质量摘要、候选稳定帧、独立同源对照及固定RGB/历史交互完善。特征初值、关键帧锚定与同会话有界重定位已作为默认关闭的研发选项接入。真实移动补洞、误恢复率、人体体动影响、尺寸精度和长期运行性能仍需新的现场验证。

## 启动与原功能

关闭旧版程序后，运行同目录的 `start_femto_app.cmd`。默认打开“局部移动补采”页；“固定采集与高级功能”页保留原 RGB-D 拍照、固定关键帧、固定时域融合、旧移动采集、三维查看、3DGS 与报告入口。两页共用一个相机读取线程，不能同时发起任务。

## 操作步骤

1. 将目标保持静止，对准有纹理和几何起伏的局部区域，确认 RGB 与深度显示正常。
2. 点击“建立原点并开始”。首次有效帧建立初始参考坐标系并作为第一个关键帧；失败时不显示伪零位姿。
3. 缓慢、小幅移动或倾斜相机，保持与上一视角重叠。右侧显示相对于初始相机位置的估计 XYZ 和旋转角，原点不会随相机变化。主视图上方若出现黄色“暂不可信”，立即停稳并保持原视野，等待跟踪正常后再补采。
4. 到达新位置后停稳，点击“停稳补采一帧”。系统等待请求之后的有效、低运动帧，并检查与上次关键帧的差异。通过后后台更新“累计预览”，可以与“初始点云”切换比较。绿色表示本次新增的采样体素，可关闭高亮查看原始颜色。至少接纳 3 个不同视角，再结束建模。变化不足或超时需要重新调整。
5. “暂停补采”仅暂停接纳关键帧，仍持续跟踪。返回后按“继续补采”。“取消本次采集”保留原始证据，不生成成功模型。
6. 点击“结束并检查模型”。最终模型在结束后生成；采集中已经可以查看累计的实测点云预览。后台生成结果并读取对比点云后，可切换“初始点云 / 融合点云”；加载期间有状态提示，界面仍可响应。拖动旋转、滚轮缩放，“复位视角”重新适配范围。切换初始、累计和最终点云保持同一显示尺度和视角。对比加载失败时，仍可打开已生成模型或报告。
7. 点击“固定 RGB 画面选区”。初始照片保持固定视角，滚轮缩放、右键平移；按住左键用方形笔刷涂抹工作区域或禁止区域。点击“完成区域选择”后只保留一个当前结果，再次完成会在新结果计算成功后替换旧结果；失败时旧结果保留。点击“保存并导出当前结果 GLB / PLY”会自动应用名称和备注并导出真实三角面边界，孔洞保留。需要自由旋转时进入保留的“高级三维检查”。
8. 同一模型可回读标记。标记绑定模型几何指纹、会话与参考帧，不能直接套到新模型上。

### 固定 RGB 产品页的单次区域模式

- 产品页只保留一个已提交区域。新的工作区/禁止区组合计算成功后替换上一条；底层多区域文件格式和研发兼容能力仍保留。
- “应用名称备注”“删除所选 / 可撤销”“清除当前选中”三个区域管理按钮暂时隐藏。名称和备注在继续操作或保存导出时自动应用。
- “撤销”仍可撤销当前涂抹笔画、未提交草稿或最近一次区域替换。重新涂抹无需先删除旧区域。
- 保存按钮现在显示为“保存并导出当前结果 GLB / PLY”。单次导出最多包含一个区域，并继续输出 GLB、网格 PLY、顶点 PLY、边界 CSV、区域 JSON 和总清单。

## 采集中跟踪不稳定与实验性重定位

出现这种界面不一定是相机断开。2026-09-14 用户截图对应会话已有 3 个接纳视角、92,356 个预览点，但连续配准失败后超过 2 秒没有可信位姿，程序按原有保护结束会话。日志中的新 RGB-D 帧仍在到达，因此这次确认是跟踪丢失。已有累计点云只是预览，不代表最终模型已生成。

本次修复后，请关闭旧窗口，再运行 start_femto_app.cmd 加载新代码。新的连续跟踪在首次匹配失败时，可以用上一次已验证的运动作为初值重新求解一次；只有重新通过全部质量和时效门禁才继续使用同一原点。该改动能避免部分初值不佳导致的连续失跟，不能保证所有移动、遮挡和形变都能恢复。

- **黄色：暂不可信。** 当前帧不会进入融合，XYZ 清空。立即停稳、保持与上一视角重叠并检查深度；系统仍在原会话的短间隔内尝试。恢复“跟踪正常”后可继续补采，不需要重新建立原点。若之前手动暂停，仍需按“继续补采”。
- **黄色：尝试重定位（仅实验开关）。** 启用后，连续失败会在最长 15 秒窗口内对同会话已接纳关键帧重新求解。当前 XYZ 保持为空，不接纳补采。至少两个时间递增、新鲜且一致的帧均通过特征+深度、稠密双向配准和时效门禁才恢复；坏帧会打断确认序列。恢复不改 W0，恢复帧也不立即用于融合，需重新停稳和请求补采。
- **红色：跟踪已中断。** 未启用重定位、没有已接纳关键帧，或在窗口内没有获得可信位姿时会中断。预览上方显示原因，右侧不再把旧读数当作当前位置。原始数据与已有预览保留；失败会话不生成成功模型。
- **处理或相机错误。** 分别提示帧过期、处理超时、无 RGB-D 输入或相机读取异常，不统一写成“采集已结束”。设备异常时检查连接并重启相机；无输入提示本身不能证明某条 USB 线已断开。
- **已经结束的旧会话不能直接恢复。** 重定位只在当前运行会话的有界窗口内对本会话关键帧生效，不跨会话续补，不重设原点，不套用旧位姿。`local_interrupted.py` 只能审核中断前的可信前缀，不是续接。

“暂停补采”仍会持续跟踪；它不能用来停止相机流后任意移动再接回。2 秒帧时效与 15 秒恢复窗口同时生效：窗口并不允许过期帧。特征初值、关键帧锚定和重定位目前默认全部关闭，只能由开发代码向 `LocalCapture(..., tracker_options=...)` 显式传入，正式界面没有开启按钮；已有回放不足以证明现场不会误恢复。研发人员应先做只读回放，例如：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m femto.tracking.local_tracking_replay datasets\<会话目录> --output outputs\<新目录> --variants baseline feature_seed keyframe_anchor relocalize all
```

输出目录必须是新的派生目录。回放会复核当前位姿、工作范围、停稳和视角门禁，记录源文件 SHA-256；离线耗时不是相机实时帧率，也不是实物精度。

右侧“暂停 / 取消”和“实时三维点云 / 查看本次报告”成对排列；中英文 1120×720 窗口已检查按钮的完整尺寸。错误条固定在预览上方，不会再被较大的点云图片挤到窗口之外。

同时修复测试/自定义数据目录误写真实“最近采集”索引的问题；最近会话现在只登记到该会话实际所属的数据目录。本次受旧测试影响的索引已恢复到排查开始时的真实会话，源数据保持不变。

## 最终模型选点坐标与原点距离

日常操作优先使用下方“固定RGB、保存状态与历史操作”。本节原Open3D操作方式适用于保留的高级三维查看器，坐标与保存绑定规则相同。

1. 打开最终模型，在侧栏“名称 / 备注（新建或编辑所选项）”填写信息，选择“表面选点 / Surface point”或“两点测距 / Two-point distance”。勾选“选点模式”后左键点击模型；也可在未勾选时按住 Ctrl 再左键点击。窗口较小时滚动右侧栏可找到编辑和保存按钮。选点模式中的左拖动不旋转模型，查看旋转时可先取消勾选。
2. 只有命中当前网格有效三角面才新增标记。红色球表示当前选中点；侧栏显示名称、X/Y/Z（mm）、距原点的直线距离（mm）、参考坐标系、当前模型来源。鼠标悬停读数区域可查看完整模型路径。
3. “选择已有点 / 区域 / Select a point / region”列表可切换到此前创建或回读的点、区域。选择点时显示原点坐标和距离；选择区域时红色线框标识该区域，显示名称、备注和三角面数，不把上一点 XYZ 当作区域坐标。
4. 连续选择两个点后，下面还会显示“末两标记之间的直线距离”及黄色连线。这是两点之间的距离，与上方“所选点到原点”的距离不同。两点和多边形区域功能均保留。
5. “保存标注及区域 / Save”把全部点、两点距离及区域写入新的 reconstruction/annotations/<时间戳_随机ID>/annotations.json，区域另导出 PLY。每次保存创建独立目录，不覆盖旧标记或模型。先完成待处理选点/圈选，再保存。
6. 重新打开同一模型，点击“回读标注 / Load annotations”，选择已保存的 annotations.json。成功后默认选中末点；只有区域时选中末区域。可通过列表切换。读入时从 XYZ 重算原点和两点距离，区域边界由绑定网格重算；旧标记缺字段可兼容读取，原文件不会自动改写。

编辑、删除与撤销：

- 在列表选择点或区域，输入框会显示该项名称和备注。修改后点“应用修改 / Apply edits”，再点“保存标注及区域 / Save annotations & regions”。未应用的编辑会阻止保存并提示，避免保存的内容与输入框不一致。
- “删除所选项 / Delete selected”只删除当前内存中的所选点或区域，立即清除它的高亮与读数。编辑名称不会改变 XYZ、原点距离、区域几何、标记 ID 或创建时间。
- “撤销更改 / Undo change”按操作先后撤销新增、编辑、删除和清空，最多保留最近 100 步。仍在圈选时优先撤销最后一个屏幕角点。撤销删除后恢复原标记及其选中状态；成功回读或换模型后开启新的撤销历史。
- 新增点使用点击时的名称和备注；圈选使用点击“完成圈选”时的信息。圈选过程中只画选择草稿，最终按可见三角面中心取区域，导出真实三角面边界并保留孔洞，不连接缺失区生成可信表面。
- 新标记保存 annotation_id、created_at 和 updated_at。旧标记缺少 ID 时在内存导入时分配；缺少创建时间时显示未知，不伪造历史时间。磁盘保存始终创建新目录；撤销和清空不会改动以前保存的文件。

坐标含义：

- 初始参考系 W0 是**本次首次有效彩色相机的位置和朝向**，之后保持固定。内部为米制 RDF：X 向右、Y 向下、Z 向前；T_W0_Ct 将当前相机坐标转换到初始参考系。
- 最终模型点已经转换到 W0，选点直接读取模型坐标，不再乘当前相机变换。查看模型时的旋转、平移和缩放不会改变 W0 或已存标记坐标。
- 原点直线距离为 sqrt(X² + Y² + Z²)。例如 (0.3, 0.4, 0) m 显示 (300.0, 400.0, 0.0) mm，距原点 500.0 mm。该距离不是相机累计移动距离，也不是当前相机到该点的距离。
- 已核对局部采集会话、参考帧、跟踪总结和初始派生 Pose 的模型显示“固定初始彩色相机 W0”。缺少这些来源证明的旧/独立模型只显示“模型坐标系 / 初始相机原点来源未知”，距离名称相应改为“距模型坐标原点”。仅有 RDF 字样或单位矩阵不能证明初始原点。
- 读数保留 1 位小数只是显示格式，**不代表具有 0.1 mm 测量精度**。所有数值均为研发估计值，未经实物精度验证，不能直接用于机械臂或治疗设备控制。

无效操作与兼容：

- 背景、孔洞、未显示 Mesh、越界或非法坐标不会新增标记，也不会显示上一点冒充本次结果。忙碌时再次点击会取消上次待完成定位，提示稍后重新点击。
- “清除当前选中项 / Clear current selection”只清除当前红点和读数，已存点仍可在列表选择。“清空标注 / Clear annotations”删除当前内存中的全部标记；磁盘既有保存目录仍保留。
- 撤销新增末点后选中剩余末点；删除当前项后没有当前读数；仅选中区域时不显示单点数值。清除、换模型和回读使旧的后台选点/圈选结果失效。
- 切换模型清除当前选择。回读失败时保留原有内存标记集合，但清除当前读数并提示失败。源模型路径、几何指纹、会话、参考帧、单位、坐标系或原点来源不匹配都会拒绝直接套用；复制到另一路径的同几何模型也不自动继承标记。
- 新 JSON 兼容原 version=1，每点增加 distance_to_origin_m，继续保存 point_world_m；顶层增加 origin_reference，并保留 local_context 与几何 SHA-256。若只复制模型、丢失原始局部采集证明，软件不会从旧标记文件反向“认证”初始相机原点。
- 本次功能针对最终模型；累计预览仍只用于观察新增采样点，不用于选点测量。XYZ 和距离落盘单位为米；mm 只用于显示，保存坐标不按一位小数截断。

## 累计预览的含义

- 初始化后自动进入累计预览。每个通过门禁的补采帧才触发更新，中间跟踪帧不会加入，暂停时也不新增。
- 预览独立后台读取已保存的原始 RGB-D 和同帧位姿；源数据、最终重建与区域标记不依赖预览点云。
- 原始深度最近邻取样、每4像素取样一次，变换至初始坐标系，以5mm体素保留首次观测样本。一个新体素可能来自新表面、采样变化或噪声，因此“新增体素”不等于补洞数量或覆盖率。
- 预览最多保留120000个样本，屏幕最多显示30000个。达到上限会显示提示，最终重建仍使用全部接纳帧。预览不凭空插值填面，采样也可能让画面比最终模型稀疏。
- “预览已更新 n / 已接纳 m 帧”显示后台进度。等待时保留上一版点云；预览错误会单独提示，不停止跟踪或误发布最终模型。
- 绿色只表示最新一帧贡献的新增采样点；初始点云和最终模型不使用这层颜色。未完成的预览不能进入区域标记。

## 状态与限制

- 位姿均为算法估计。XYZ 单位 mm；俯仰 Rx、偏航 Ry、滚转 Rz 单位 °，分解 `R=Rz·Ry·Rx`；底层矩阵和几何单位仍为米制 RDF。
- 超过 2 秒的处理或跟踪间隔、连续 5 次拒绝进入丢失；显示无效，不使用旧数字当当前位置。界面更新年龄过期也会禁用补采。
- 未能在 15 秒内初始化会终止；一次会话最多 5 分钟。补采请求有效期 3 秒。
- 初始停稳判断为相邻跟踪帧平移不超过 3 mm 且旋转不超过 1°；关键帧差异至少 10 mm 或 2°。这些是工程门限，不代表实际定位误差或速度精度。
- 默认配置中跟踪丢失后仍需新建会话。研发配置可启用同会话有界重定位，但无实物误恢复率证据，不跨会话追加旧模型。失败不更新成功模型索引。
- 本版本仅将原始有效深度用于局部几何融合，不把算法补点当实测点。标记网格保留在至少一个原始视角中，三个顶点及中心都有深度一致支持的三角面；10 mm 支持门限不是物理精度保证，也不保证所有小尺度表面特征均被保留。
- 几何标记用于研发可视化，不能直接驱动治疗设备。需另行验证尺寸、位姿误差、人体运动、形变及设备坐标标定。
- 新工作台中的点云对比是轻量显示。完整三维操作、表面选择和区域工具复用原 Open3D 查看器；不需要先训练 3DGS。

## 数据位置

- 原始：`datasets/scene_<时间>_local_<ID>/rgb、depth、pose、calibration、frames.jsonl、manifest.json`。新增局部采集 RGB 使用 PNG，无损保存解码后的彩色图；原始移动 Pose 仍为 null。
- 逐帧派生跟踪：同会话 `derived/live_tracking.jsonl`，包含源帧 ID、相机时间戳、位姿、质量、接纳状态和延迟。
- 累计预览报告：同会话 `derived/live_preview_report.json`，记录源帧、采样参数、点数上限和逐次更新时间。预览本身不作为模型文件发布。
- 跟踪总结：`derived/local_capture_report.json`；失败：`derived/local_failure.json`。
- 新跟踪记录保留首轮及重试的配准指标、失败检查项与 queue_wait/raw_write/pose_processing 分段耗时。总结中的 termination 保存终止原因、末次可信帧、时间间隔及此前拒绝；failure JSON 同时保存接纳帧、参考帧与设备错误。重试成功数表示通过内部检查的帧数，不是精度或成功率验收。
- 可信关键帧：`derived/local_posed`，仅引用原 RGB-D，保存派生 Pose 和质量报告，保持初始原点。
- 最终模型：`outputs/complete_demo_<时间>/reconstruction`；初始对照为 `initial_observed_points_m.ply`，融合点云为 `scene_fused_points_m.ply`。
- 标记支持与会话信息：重建目录 `local_geometry.json`。模型检查页可打开质量报告；完整 JSON 包含在线延迟和丢帧记录。

产品演示：选中区域并生成路径后，点击“路线图演示 / 导出图片”。绿色点是每段起点，红色点是每段终点，黄色箭头为该段方向；下拉框可单独检查某一段，勾选框分别控制区域照片和路线显示。点击“导出路线图 PNG”保存当前显示状态，图片自带参数和说明。该窗口是固定初始照片视角的路线投影，不是机械臂执行动画，区域RGB不能证明所有位置都有实测深度。三维旋转预览继续使用历史导出中的GLB。

历史预览贴图方向修复：如旧版预览出现屏幕区域大片黑色、桌面贴到屏幕上，关闭预览窗口后重新打开即可使用修复。GLB无需重新导出；此次只修正Open3D显示图像的纵向原点，并默认关闭额外光照，不改变坐标和几何。

RGB纹理更新：重新点击“保存并导出区域 GLB / PLY”或“导出区域＋路径 GLB / JSON / CSV”后，新GLB会携带模型已有的RGB纹理。进入历史导出记录，刷新并选择最新记录预览。旧GLB保留原样，不会自动增加纹理。无源纹理的模型继续使用顶点色；PLY不包含这份照片纹理。纹理改善外观，不改变XYZ和路径，也不会修复原模型毛刺或原图集接缝。

新增“历史导出记录 / 预览”按钮：列出**当前模型**下保存过的区域与路径，包含旧导出，无需重新导出。选中记录点击预览或双击，可在独立三维窗口中旋转/缩放查看；“打开导出文件夹”用于取得GLB/PLY/JSON/CSV。新导出后点击刷新即可显示。没有GLB/PLY的旧记录会提示无法预览，但仍可打开目录；记录损坏也会保留错误提示。预览不回读或替换当前标记。查看其他采集的导出，请先打开对应历史模型。

1. 重启固定RGB窗口，单选一个完成的区域，点击“毫米曲面路径（近似）”。
2. 输入路径间距（默认5 mm）和沿路径最大采样间距（默认1 mm）。界面以黄色线显示，状态栏显示参数、段数、点数与长度。
3. 点击“导出区域＋路径 GLB / JSON / CSV”，到状态栏所示文件夹打开`region_with_path.glb`。支持GLB网格的工具可预览；对象`selected_region`为圈选区域，`path_display`为黄色路径，可分别隐藏。文件长度单位为米；导入工具需要正确使用其单位设置。未在所有外部软件中逐一验证。
4. 同文件夹`path.json`与`path.csv`保留W0 XYZ与路径段序；GLB的黄色细管只用于可视化，坐标计算应读JSON/CSV。回读JSON仍需同模型和同区域。

毫米模式以网格边上的最短距离近似曲面距离，每个独立区域从W0 Y最小的边界顶点起步，生成等值线；首条线离起始距离为半个设定间距。它不是精确的全曲面等距覆盖，网格疏密和方向会影响结果，也不保证距全部边界的安全退让。沿路径采样间隔不超过设定值，三角面接缝处可能更密。孔洞与不同路径段之间不自动连接。原“生成区域扫描路径”已更名为“像素扫描路径（预览）”，旧像素文件仍可使用。

像素模式生成时可设置“路径断段阈值”，默认5 mm，范围0.01–100 mm。它只决定相邻采样点距离多大时拆段，不是点间距。毫米模式不使用这个阈值，直接在选中网格面内生成路径。完成后状态栏显示段数、采样点数及段内折线总长（不含段间移动）。

要重新查看导出的路径，先打开同一模型并回读原有区域标记，单选对应区域，再点击“回读并核验路径 JSON”选择`path.json`。模型、原点、区域或路径采样数据不匹配会拒绝加载；区域名称/备注变化也会使旧签名失效，此时应重新生成。导出路径前建议先保存区域，方便下次回读。

1. 在固定RGB选区窗口完成圈选，列表中单选一个区域。
2. 点击“生成区域扫描路径（预览）”，填写扫描行间距，默认10图像像素。黄色线条显示各个独立扫描段。行间距是像素，不是表面毫米；孔洞、无支持位置、非相邻网格面及大于5 mm的单步跳跃会使路径分段。
3. 点击“导出路径 JSON / CSV”。文件存于当前重建目录的`region_paths/path_<唯一编号>/`，状态栏显示具体位置。CSV包含段号、点序、W0坐标XYZ（米）、网格法线、段内累计长度（米）；JSON同时保存原点、源模型及生成参数。
4. 修改区域后重新生成路径；“清除路径预览”只清除黄色线条，不删除标记与模型。区域GLB/PLY仍使用“保存并导出区域”按钮单独保存。

目前这是研发用的离散采样路径，可用于分析扫描顺序。每段独立，没有跨孔洞、跨行的工具移动指令；网格法线也不是工具姿态。不包含机械臂控制、避障或治疗执行。

当前新会话补采范围为距固定 W0 半径 **30 mm**、相对初始朝向**总旋转角 10°**，不是每轴各 10°；后文旧阶段数字只描述当时版本。距原点距离使用 √(X²+Y²+Z²)，与 Z 深度、相机位移分开。

局部状态条增加有效深度比例、清晰度及纹理不足提示。低于20%有效深度拒绝；20%–35%仍提示覆盖偏低。WFOV当前量程250–2210 mm；目标过近、反光、黑色材质和遮挡都可能导致缺失，提示不是这些原因的自动诊断。取景流畅不代表有效位姿帧率足够。

暂不可信时先停稳并保持视野重叠，本帧不接纳、不融合。只有重新通过原双向位姿门禁才恢复，读数不会以旧坐标冒充当前位姿。2秒/5帧连续性限制保持；超过边界后仍须重新采集新会话。背景筛选和反向初值试验没有默认开启。

有至少三个不同已接纳视角的中断会话，可以独立审核并生成“中断前数据建模”结果：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m femto.pipeline.local_interrupted datasets\<中断会话目录> --output outputs\<新的中断前数据建模目录>
```

也可加 `--prepare-only` 仅审核并导出同源派生输入。新目录必须不存在。工具按该会话记录的采集范围审核原证据，只用最后可信帧之前的数据，不恢复跟踪、不重新设原点、不覆盖原会话和业务latest。完整模型在新目录的 `models/complete_demo_*/reconstruction`；可用 `start_fixed_rgb_viewer.cmd <该reconstruction目录>` 打开，质量报告和窗口标明中断前来源。初步数量达标仍可能被来源或建模质量门禁拒绝。

## 2026-09-16 融合与报告更新

- 局部补采仍只融合原始有效深度。每个接纳视角在没有可采用补洞像素时只做一次TSDF积分；补洞分析只写统计JSON，不再保存置信度数组和多份深度副本。少于12个视角时不生成无法进入3DGS训练门禁的Nerfstudio数据，但结果仍按移动局部模型出现在历史与最近来源中。
- 最终局部网格在原有深度支持筛选后，再执行同一条小连通分量规则。真实历史同源对照中，最大主体保持，可选像素下降0.323%；该规则会删除孤立小面，因此细小结构仍需在现场目标上复核。
- “融合点云”表示多视角观测并集，可能含重叠层，供显示与诊断。局部选点、区域标记和尺度测量默认使用经过原始深度支持筛选的TSDF网格。报告会给出点云到网格P50/P90/P95、无网格支持点数和双层比例，这些是内部一致性指标，不是实物误差。

- 候选五帧报告现在能区分“会话没有稳定窗口”和“稳定窗口存在但不包含接纳帧”；精配准显示在线位姿、修正量、同帧采样底与逐帧拒绝原因；`motion_after_capture` 区分本帧触发和沿用旧结论，并显示会话相邻位姿变化中位。

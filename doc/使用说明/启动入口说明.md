# 启动入口说明

适用工作区：`E:\测试3D人体关节坐标-ui`。2026-09-30 将根目录 CMD 从 34 个精简为 16 个，按下表选择入口。整理仅移除快捷脚本，没有删除相机数据、模型、方案、环境或后端能力。

## 日常使用与验收

| 脚本 | 用途 |
|---|---|
| [start_femto_app.cmd](../../start_femto_app.cmd) | 人体局部采集、区域规划和历史回看主工作台。 |
| [start_region_planner.cmd](../../start_region_planner.cmd) | 同一工作台的无自动相机连接入口，适合打开已有模型和区域方案。 |
| [start_real_scene_demo.cmd](../../start_real_scene_demo.cmd) | 通用物品/场景预览，点击开始后采集并重建。 |
| [start_complete_demo_viewer.cmd](../../start_complete_demo_viewer.cmd) | 查看最近完整重建模型。 |
| [检查工作区环境.cmd](../../检查工作区环境.cmd) | 只读检查本工作区运行环境，不启动相机或训练。 |
| [validate_scene_scale.cmd](../../validate_scene_scale.cmd) | 指定实测距离与模型端点后的研发尺度核验。 |
| [生成实拍验收报告.cmd](../../生成实拍验收报告.cmd) | 按指定结果目录和验收规格生成报告。 |

物品实拍后进入区域规划的方法见 [物品采集与工作区域规划](物品采集与工作区域规划.md)。日常只看历史或继续规划时优先使用 `start_region_planner.cmd`，无需另外启动采集。

## 安装与维护

| 脚本 | 用途 |
|---|---|
| [setup_environment.cmd](../../setup_environment.cmd) | 安装本工作区 `.venv` 的采集、几何和 UI 依赖。 |
| [setup_direct_gsplat_environment.cmd](../../setup_direct_gsplat_environment.cmd) | 配置当前工作区专属 gsplat 运行环境。 |
| [setup_spz_environment.cmd](../../setup_spz_environment.cmd) | SPZ 构建和导出所需环境。 |
| [install_lpips_weights.cmd](../../install_lpips_weights.cmd) | 校验并安装离线 LPIPS 权重；运行时错误提示仍指向此入口。 |

这些不是日常启动按钮，已有环境正常时无需重复安装。

## 保留的正式 3DGS 入口

| 脚本 | 用途 |
|---|---|
| [start_direct_gsplat_status.cmd](../../start_direct_gsplat_status.cmd) | 查询工作区专属 gsplat 状态。 |
| [start_direct_gsplat_train.cmd](../../start_direct_gsplat_train.cmd) | 对通过输入检查的数据训练 gsplat。 |
| [start_direct_gsplat_viewer.cmd](../../start_direct_gsplat_viewer.cmd) | 查看对应 gsplat 输出。 |

旧 Nerfstudio/Splatfacto 的安装、状态和查看 CMD 已移除；旧模型不自动转换成 direct gsplat 模型。`start_direct_gsplat_setup.cmd` 只是重复转发，安装统一使用 `setup_direct_gsplat_environment.cmd`。

## 内部辅助脚本

[_resolve_femto_python.cmd](../../_resolve_femto_python.cmd) 和 [_resolve_gsplat_runtime.cmd](../../_resolve_gsplat_runtime.cmd) 被其他脚本调用，用于确保当前分支独立环境和路径归属。它们不属于日常入口，但不能删除。

`prototype/start_prototype.cmd` 保留在原型子目录，不计入根目录 16 个入口；不是正式工作台入口。

## 低频研发功能

下列快捷 CMD 已移除，功能仍可从仓库根目录使用现有 Python 模块。命令中的输入路径应替换为实际记录，不根据“最近结果”猜测来源。

| 功能 | 现有命令 |
|---|---|
| 只保存通用 RGB-D 原始帧 | `.venv\Scripts\python.exe -m femto.capture.scene_capture` |
| 合成完整流程演示 | `.venv\Scripts\python.exe -m femto.pipeline.complete_demo --mode synthetic` |
| 固定场景时域融合采集 | `.venv\Scripts\python.exe -m femto.temporal.scene_temporal_fusion --capture` |
| 旧人体 Pose/Mask 原型 | `.venv\Scripts\python.exe -m femto.capture.top_scan` |
| 查看该旧原型结果 | `.venv\Scripts\python.exe -m femto.viewer.view_latest` |
| 深度诊断查看器 | `.venv\Scripts\python.exe -m femto.viewer.depth_debug_viewer` |
| 数据集校验 | `.venv\Scripts\python.exe -m femto.dataset.scene_dataset_validator <数据集目录>` |
| Nerfstudio 格式转换 | `.venv\Scripts\python.exe -m femto.pipeline.scene_to_nerfstudio <数据集目录>` |
| 历史导出区域的蛇形轨迹 | `.venv\Scripts\python.exe -m femto.planning.mesh_slice_planner <区域导出目录>` |
| 派生表面候选诊断 | `.venv\Scripts\python.exe -m femto.planning.derived_surface_candidates <区域导出目录>` |
| 单帧固定视角 3DGS 建模 | `.venv\Scripts\python.exe -m femto.gsplat.scene_single_gs build <固定视角记录或照片目录>` |

单帧 3DGS 查看仍需专属产品运行环境，可由现有启动函数解析该环境：

```powershell
.venv\Scripts\python.exe -c "from femto.gsplat.scene_single_gs_viewer import open_viewer; open_viewer(r'outputs\single_gs_实际目录')"
```

合规检查保留根目录 `commercial_compliance_check.py`，其主程序会生成/覆盖合规报告，不属于只读环境查询。历史清理保留 `清理历史数据.ps1` 后端，移除了根目录一键清理快捷方式；本次整理没有执行数据清理。

旧开发记录中出现的已移除 CMD 名称仅表示当时的入口，当前以本文和根目录 README 为准。具体删除清单见 [整理记录](../历史开发记录/CMD入口精简_20260930.md)。

# 第二批：圈选校验、边界约束与区域覆盖演示

## 禁止区域与完整路线播放

完成主圈选并单选该区域 → 点击“添加禁止区域（先选主区域）” → 在图像点击禁区轮廓 → 点击“完成圈选”。红色显示禁区，可重复添加。点击“清除所选区域禁区 / 可撤销”清除该区域全部禁区；需要恢复可点撤销。保存标记后禁区随区域JSON保留。每个主区域单独管理禁区。

禁区变化后必须重新生成覆盖规划。系统剔除与禁区相交的完整网格面，再预留模拟扫描半径；可能比手画轮廓略大，目的是避免部分三角面穿越边缘。禁区无深度也保留图像约束，不虚构表面。旧像素/毫米路径入口遇到禁区会提示使用覆盖规划。

运动演示保留完整路线图，显示总起点与总终点，按段序依次播放。段间暂停后切换，不绘制穿过禁区的连接。它是从头到尾的扫描顺序演示，尚不是一条经过连续避障验证的机械臂轨迹。

“导出区域＋路径”生成的GLB包含独立红色禁区对象；JSON保存禁区、允许面和路线顺序；PNG与报告同时说明禁区。缺失表面没有可显示的红色三维面，需结合PNG/JSON查看。单独“保存并导出区域”仍导出完整主区域表面，不把禁区当作被删除的原始数据。

重启软件，完成圈选并在标记列表单选该区域，点击“区域覆盖规划 / 运动演示”。

依次输入模拟扫描宽度、相邻路线重叠率、额外边界余量。默认10 mm、20%、1 mm只是研发演示参数，不是超声治疗参数或安全阈值。

系统生成近似曲面路线，并按扫描半径加额外余量检查选区外沿、孔洞边界及原RGB多边形边界；不满足条件的短线段被删除，余下路线分段保留，不绘制跨孔连接。端点/中点可见性也参与筛选。过窄区域可能没有路线，此时提示调整模拟参数或重新检查选区，不会自动放宽。

演示窗口支持显示区域、路径、覆盖检查、单段选择、播放/暂停/复位、模拟速度和进度。点击“查看覆盖报告”，可查看候选路线筛除数量、有效网格面积、采样覆盖与遗漏、圈内缺失像素。切换速度会暂停，点击播放继续；段间停顿仅用于演示，不是机械臂过渡运动。

颜色含义：绿色为该面3个离散采样点均估计覆盖，橙色存在遗漏，紫色是圈内无有效几何。粉紫轮廓是原始圈选。缺失几何不计入曲面覆盖率分母，不能把网格的100%当成圈内所有皮肤已覆盖。

“导出区域＋路径”保存带纹理表面与静态路线的GLB、有序坐标JSON/CSV、路线图、覆盖图及 coverage_report.txt，并打包ZIP。第一批状态统一后，无有效路径时导出按钮禁用；请先点击“生成覆盖路线”，成功后再导出。仍可显式选择原有像素/毫米近似路径，报告会提示这种路径未执行扫描宽度边界约束。

JSON回读重算路线与边界/覆盖报告；模型、区域或参数不一致时拒绝采用旧结果。部分旧覆盖报告因新增校验无法重现，需重新生成，不静默将其标为合格。

## 限制

边界距离采用保守的欧氏下界，曲面折叠或碎片较多时可能排除更多路线。覆盖率是每面3个采样点面积加权的估计，未证明连续覆盖。边界限制与连续接触、真实治疗头形状/压力、机械臂碰撞或患者运动补偿不同，本批没有实现后者。

为了防止界面长时间失去响应，边界比较设1亿次预算；复杂区域超出时需缩小区域或增大路线间距。生成过程沿用120秒预算及取消机制。

## 验证

新增测试覆盖内部余量、孔洞、窄区域拒绝、投影与遮挡检查、错误参数、取消，以及导出回读和报告篡改拒绝。

真实历史书本区域在10 mm宽度/20%重叠/1 mm余量下生成85段，采样覆盖估计87.57%。边缘遗漏保留，没有为了提高指标把路线扩出选区。该结果不是人体或治疗有效性验证。


## 水平往返路线（2026-09-17）
重新进入“区域覆盖规划 / 运动演示”生成新方案：默认左到右、向下换行、右到左，黄线为扫描，橙线为换行或绕开禁止区域的连接。播放会沿连接连续移动；无法连通的区域明确分成不同链，不会穿过禁区。参数行距是固定图像上的近似间距。
历史方案不会自动重写，请重新生成后保存区域工程或导出“区域+路径”。GLB 包含静态扫描和连接路线，JSON/CSV 保留路线顺序及 motion_kind；动态播放在本系统内进行，普通 GLB 查看器不保证动画播放。

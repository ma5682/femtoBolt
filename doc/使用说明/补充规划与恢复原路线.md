# 补充规划与恢复原路线

在已有路线和模型覆盖核验结果上，可以尝试补充可用表面上的缺口。补充结果仍是研发预览，不能直接作为设备执行轨迹。

1. 打开当前记录，确认工作区域并生成路线。
2. 在路线页点击“核验模型覆盖”，检查原目标几何、模型覆盖和未确认原因。
3. 点击“补充规划”。计算在后台进行，可以取消；原路线保留。
4. 完成后查看尝试轮数、接纳轮数、新增已确认名义面积和增加的路线长度。在详情中查看候选未通过的原因，再打开“显示模型覆盖”定位剩余范围。
5. 重新核对后进入保存。原生路线和可编辑工程同时保存完整补充证据，历史打开时重新验证。

缺失、质量不足、定位不明及尚未完成的计算不会被当作行距问题自动补线。只有已经核验为球形作用范围之外、又有可用表面支持的位置才生成候选；候选仍可能因宽度、边界、质量、长度或连接检查被拒绝。

“接纳 0 轮”表示本次未找到满足当前条件的改善方案，原路线继续保留。它不表示目标已完成，也不证明不存在其他可行路线。“达到限额”后仍显示未确认范围；不要把保留下来的路线理解为完整覆盖。

候选会先检查作用范围是否越出工作区域、参考几何质量是否待确认，再逐边核验真实表面支持。过长的可选连接保留断点；详情会区分可用长度不足、边界或质量未通过，以及未能在预算内重新确认全部原覆盖。候选筛查通过不等于最终采用。只有原确认集合完整保留，并由新增扫描点带来足够的新确认面积，才接纳补充路线。

补充后可点击“恢复补充前路线”，同时恢复原覆盖证据和原目标修订。此操作在当前编辑页面进行；保存为新版本后，历史补充版本仍可查看。已经补充的版本不继续嵌套自动补充；如需重试，先恢复原路线，或修改工作区域／参数后重新生成并核验。

仅返回之前的流程节点会保留方案。实际修改区域、宽度、参考数据或模型后，旧补充结果停止使用，需要重新生成。取消或切换记录后的迟到结果不会替换当前方案；有未保存编辑时继续沿用现有保存、放弃或取消离开的交互。

一个操作例子：在已采集的右肩工作区域生成路线 → 核验覆盖 → 定位橙色缺口 → 点击补充规划 → 比较新增确认面积并检查仍为灰色／紫色的范围 → 核对保存。灰色可能表示尚未处理，紫色可能表示几何待核验；它们不会因为补充成功而自动变成可靠体表。

默认最多尝试两轮，每轮四个面内候选；最多增加 100 mm 的扫描与连接总长度。旧补充记录仍按保存时的策略读取。门槛是研发计算参数，并非治疗参数。现有真实样本包含衣物和环境，不能据此声称已验证患者皮肤或临床效果。详细格式与限制见 [P3 契约](../技术资料/P3_补充规划与覆盖增益契约.md) 与 [候选诊断及性能优化契约](../技术资料/覆盖与回读优化_候选诊断契约.md)。

# 三维表面轨迹使用说明

本功能从已保存区域的实测 Mesh 表面生成研发用蛇形扫描轨迹。所有 XYZ 均为 W0 / RDF / 米；只在绑定区域 PLY 的三角面上生成点。缺面、禁止区域、分离表面和换行均写成 `gap`，不补点、不画跨越线，也不规划自由空间运动。

## 固定 RGB 页面

1. 在固定 RGB 页面完成工作区域/禁止区域并点击“保存并导出当前结果 GLB / PLY”。只有保存成功且区域没有未保存改动时，“生成三维扫描轨迹”才可用。
2. 点击“生成三维扫描轨迹”。任务在后台运行，可通过现有任务取消机制停止；取消或预算超限不会发布部分目录。
3. 完成后可打开三维轨迹文件夹、路线图，或播放轨迹。播放器沿每个扫描段移动，到 gap 必须停止；再次继续只是定位下一段起点，不代表存在从前一点到后一点的已规划运动。
4. “历史区域导出记录”和研发用“区域方案库”都会列出三维表面轨迹；核验 `trajectory_files.json` 后可预览 GLB，方案库还可显示路线图缩略图。

## 命令行与拖放

把包含 `region_N.json` 的区域导出目录拖到根目录 `生成三维蛇形扫描轨迹.cmd`，或从仓库根目录运行：

```powershell
.venv\Scripts\python.exe -m femto.planning.mesh_slice_planner <区域导出目录或region_N.json>
```

可选参数包括 `--output DIR`、`--row-mm 5`、`--step-mm 1`、`--direction auto|w0_x|w0_y|<角度>` 和 `--start-corner top_left|top_right|bottom_left|bottom_right`。v1 冻结默认值及阈值不得为追求结果而放宽。

## 输出

- `trajectory.json`：统一 `femto-surface-trajectory-v1` 模型，扫描段与 gap 严格交替。
- `trajectory.csv`、`gaps.csv`：逐点和逐 gap 表格。
- `region_with_trajectory.glb`：区域网格、扫描段和 gap 端点；gap 没有连接管线。
- `route_diagram.png`：参考 RGB 可找到且哈希一致时生成；不可用不会阻断核心轨迹。
- `depth_diagram.png`、`trajectory_report.txt`：扫描面深度图与中文摘要。
- `trajectory_files.json`：上述已生成文件的 SHA-256 清单，不包含自身。

区域方案库和 `load_trajectory` 会核对文件清单、来源清单、区域 PLY 和逐点三角面支持；Mesh 自动规划结果还会按原参数重算比对。文件缺失、被篡改或来源不一致时拒绝使用。

## 投影式旧方案适配

研发代码可调用 `from_projection_plan(plan, region, store, region_manifest=None)`。显式传 `region_manifest` 时绑定并校验导出 PLY；不传时只从当前 `store.mesh` 重建区域网格，不扫描目录猜测。旧全局 `triangle_index` 会转换为区域 PLY 的局部索引并做 1e-6 m 几何验证；无法映射的点会拒绝整次转换，旧 `path.json`、`plan_binding` 和 CSV 不会被修改。

## 安全边界

轨迹固定 `execution_ready=false`、`physical_accuracy_verified=false`。点法线不是工具姿态；当前没有速度规划、离面抬升、碰撞检测、底座/机械臂运动学、手眼标定或设备接口。行距是平行切片间距，不等于处处相同的曲面测地间距。该结果只能用于研发查看和软件一致性验证，不能直接驱动设备或作为临床/实物精度结论。

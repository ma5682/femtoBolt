# 三维表面轨迹使用说明

本功能从已保存区域的实测 Mesh 表面生成研发用蛇形扫描轨迹。所有 XYZ 均为 W0 / RDF / 米。当前算法 `mesh-slice-serpentine-v4`：工作块按医师在固定 RGB 页涂抹的选择组件划分（一个 4 连通的选中区域 = 一个工作块），块内每一对相邻扫描段都沿真实网格表面连接（相邻行先走边界折返，其余沿该表面网格边最短路绕行），成功的块是一条连续链、块内 `gap_count=0`；块之间只记录 `selection_break` 停止标记，不生成跨块点、连线或运动。Mesh 连通关系只作为块内"碎片"诊断：一个选中区域内的多个网格碎片逐个规划，碎片之间的接缝保留为 `disconnected_surface` gap，块标为"未完成"。缺面、禁止区域或无法连接的位置仍保留 `gap`，并在 `gaps.csv` 的 `link_failure_reason` / `row_turn_failure_reason` 列和报告中给出诊断原因（仅供排查，不参与任何决策）。

旧结果：v1 / v2 / v3 / v3.1 文件仍可查看和播放（播放时只做哈希、来源和网格校验，不重算，窗口会提示当前产品规则为 v4）；要采用 v4 需要区域导出带有"选择意图"记录——2026-09-23 之前保存的导出没有该记录，v4 会明确拒绝并提示"请重新选择并导出"，旧轨迹保留。

## 选择意图与三种"断开"

- 固定 RGB 页保存区域时，最终涂抹掩膜（工作区 − 禁区，或有效范围 − 禁区）作为权威记录写入 `region.selection_intent`：选中组件、内部明确未选的孔洞、涂抹禁区都逐个枚举；三角面只是由掩膜派生的几何绑定。同时写入 `region.selection_support`，把每个选中像素分为：有实测 Mesh 支持、参考帧有深度但 Mesh 缺面（派生表面候选，待用户确认方法后才会使用）、无 Mesh 且无深度、超出深度范围、深度冲突、无源像素。后五类统称"几何待确认 / 需要补采"，它们保留覆盖需求，不会被当成未选。
- 多个分离的选中区域 → 多个工作块，块内各自连续，块间暂停。
- 一个区域内部明确未选（未涂抹或涂为禁区）→ 保存为选择孔洞；面心落在孔内的三角面不进入区域 PLY；路线在已选表面上绕行；涂抹禁区按像素多边形严格避让（连接边整条不得触碰）。无法绕行时该块标"未完成"并报告原因，不强行跨孔连接。
- 选中但 Mesh 有孔洞 / 缺面 / 碎片 → 覆盖需求保留：碎片逐个规划、接缝不桥接；完全没有支持的区域记为"无法规划：需要补采"；不会生成任何伪实测 XYZ。

## 状态与发布策略

- 每块状态：`planned`（单链完成）/ `incomplete`（有链但块内仍有 gap，原因逐条列出）/ `unplannable`（没有任何链）。整体 `continuity_status` 只有全部块单链时才是 complete。
- 覆盖与连续分开检查：`coverage_status` 在存在无法规划块、未覆盖网格碎片或几何待确认像素时为 partial；报告列出每块的未覆盖碎片、面数、面积和几何待确认像素。没有治疗头有效覆盖宽度依据，不宣称完整治疗覆盖。
- 连接段若落在其他已扫描行的名义半行距内会标为"重复经过"（洋红显示、报告与 CSV 记录）；该判定按名义行距，不是治疗头宽度，不得据此推定治疗能量持续开启。
- 存在未完成或无法规划的块时，新结果仍完整生成、校验并可预览，但**不替换、不删除**旧的有效轨迹：历史列表同时显示最新完整结果和更新的未完成结果，后者标注"未完成结果，旧轨迹保留"。全部块单链完成并校验通过后，才删除同一区域的旧轨迹目录。

## 从历史区域生成和预览

1. 在固定 RGB 页面完成工作区域/禁止区域并点击"保存并导出当前结果 GLB / PLY"。状态栏会显示选择组件数、内部孔洞数和几何待确认像素数。当前页面只负责选区和导出。
2. 打开"历史区域导出记录"，选中一个已保存区域，点击"生成三维扫描轨迹"。已有轨迹时按钮变为"重新生成三维扫描轨迹"。任务在后台执行，可取消。
3. 新结果生成并通过完整性校验后，若全部块单链完成，删除同一历史区域的旧轨迹目录（不进入回收站）；生成失败、取消或存在未完成块时保留旧结果。包含额外用户文件的旧目录不会自动删除，界面会报告原因。
4. 选中轨迹可预览 GLB、打开轨迹文件夹、查看路线图或播放。播放使用保存时的区域和来源；块间停止时提示"块间停止（选择分离）"，继续只定位下一块起点；块内 gap（未完成块）停止时提示链接失败原因。播放窗口"块"下拉可切换单块显示并标出状态（单链完成 / 未完成 / 未规划）；路线图与播放画面叠加青色选择组件轮廓、红色明确未选区域、紫色"有深度缺面"、橙色"无可靠几何"。源模型、参考图像或标定不匹配时拒绝播放。
5. 历史列表和生成完成提示会显示工作块数、单链完成数、未完成数、无法规划数与覆盖状态。

## 命令行与拖放

把包含 `region_N.json` 的区域导出目录拖到根目录 `生成三维蛇形扫描轨迹.cmd`，或从仓库根目录运行：

```powershell
.venv\Scripts\python.exe -m femto.planning.mesh_slice_planner <区域导出目录或region_N.json>
```

可选参数包括 `--output DIR`、`--row-mm 5`、`--step-mm 1`、`--direction auto|w0_x|w0_y|<角度>`、`--start-corner top_left|top_right|bottom_left|bottom_right`；`--mesh-blocks-v3` 显式回到 v3.1 的网格连通分块规则（不需要选择意图）。无选择意图的导出在 v4 下写出 `trajectory_blocked.json` 并返回 2。v1 冻结默认值及阈值不得为追求结果而放宽。

## 输出

- `trajectory.json`：统一 `femto-surface-trajectory-v1` 模型，扫描段与 gap 严格交替；v4 每段带 `block_index`，`blocks`（`femto-surface-trajectory-blocks-v2`）记录每块的选择组件、面清单哈希、状态 / 原因、网格碎片、连续 / 覆盖 / 选区 / 重复经过统计、链接规则和选择绑定；`statistics` 含块数、单链完成数、未完成数、块间 gap 数、`continuity_status`、`coverage_status`、几何待确认像素数和重复经过统计；`gap_report` 含链接失败计数、未完成块清单和几何待确认分类。
- `trajectory.csv`（v4 含 `block_index` / `role` / `revisit` 列）、`gaps.csv`（含 `block_from` / `block_to` / `row_turn_failure_reason` / `link_failure_reason`）、`blocks.csv`（含连续 / 覆盖 / 像素 / 重复经过列）。
- `region_with_trajectory.glb`：区域网格、每个有链的块一个管线节点（洋红为重复经过的连接段）、gap 端点标记（青色为 `selection_break`），块间没有管线。
- `route_diagram.png`：参考 RGB 可找到且哈希一致时生成；叠加选择组件轮廓、明确未选区域和几何待确认区域，标注块编号与状态，块间不画线。
- `depth_diagram.png`、`trajectory_report.txt`：扫描面深度图与中文摘要（逐块逐碎片列出状态、原因、覆盖缺口和重复经过）。
- `trajectory_files.json`：上述已生成文件的 SHA-256 清单，不包含自身。

区域方案库和 `load_trajectory` 会核对文件清单、来源清单、区域 PLY 和逐点三角面支持；v4 还按导出的选择意图重算工作块与面归属、碎片连通性、面清单哈希、像素计数，核对意图 / 支持哈希，检查每个 `planned` 块单链无 gap、块间 gap 恰为 `selection_break`、连接边不穿越禁区且不离开参考图像，所有块与全局统计均能从 `ordered_items` 重算，任一不符即拒绝。旧 v1 / v2 / v3 / v3.1 文件按原算法版本读取和重算，不会被重新解释。

## 投影式旧方案适配

研发代码可调用 `from_projection_plan(plan, region, store, region_manifest=None)`。显式传 `region_manifest` 时绑定并校验导出 PLY；不传时只从当前 `store.mesh` 重建区域网格，不扫描目录猜测。旧全局 `triangle_index` 会转换为区域 PLY 的局部索引并做 1e-6 m 几何验证；无法映射的点会拒绝整次转换，旧 `path.json`、`plan_binding` 和 CSV 不会被修改。

## 安全边界

轨迹固定 `execution_ready=false`、`physical_accuracy_verified=false`。点法线不是工具姿态；当前没有速度规划、离面抬升、碰撞检测、底座/机械臂运动学、手眼标定、接触力、治疗能量或设备接口。行距是平行切片间距，不等于处处相同的曲面测地间距。派生工作表面（阶段 C）尚未实现，方法与门限待用户确认。该结果只能用于研发查看和软件一致性验证，不能直接驱动设备或作为临床/实物精度结论。

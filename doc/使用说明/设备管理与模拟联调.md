# 设备管理与模拟联调

在单机工作台运行模拟设备联调，保存事件并在重启后只读查看。需要当前 checkout 的 `.venv`；本功能不需要真实相机、机械臂或超声发生器。

模拟只检验软件请求、反馈与业务状态，不代表机械臂动力学、治疗、声学、物理精度或执行资格。页面持续显示“模拟联调，无真实运动及超声输出”，所有执行资格保持不可执行。

## 完成一条模拟任务

从仓库根目录启动预览工作台：

```powershell
.venv\Scripts\python.exe -m femto.app.qt_main --ui-preview
```

1. 在方案回看页点击 **用此方案模拟联调**，直接带入该保存版本。也可点击顶部 **设备与模拟**，选择 `.region.zip` 或 `trajectory.json`。打开页面不自动连接设备、不创建运行数据库。
2. 等待 **核验方案摘要** 完成，核对任务、来源及版本。缺失字段显示未知，不能按名称或当前设备补造。没有方案时，明确选择 **显式合成软件测试**。需要更换设备组合或故障场景时，先通过 **配置与场景** 读取，再核验和冻结任务。
3. 点击 **核验并冻结模拟任务**。候选核验沿用原来源、摘要、目标和覆盖完整核验；立即冻结时复核引用摘要并复用同次核验结果。从回看页带入后，再次核验同一来源仍须匹配该保存版本与路线摘要；发现变化会拒绝，重新打开回看或明确改选来源后再核对。未保存草稿需先保存。加载失败保留失败状态，不改用合成方案。冻结之后当前任务与其他草稿分离。
4. 点击 **连接模拟设备**，查看中文来源、能力和物理状态；连接代次、协议、原字段等放在 **工程详情**。默认场景含软件模拟机械臂与治疗头；真实相机继续由采集页原所有者管理。
5. 全部参与设备连接后，**模拟前置检查** 才可点击。点击后等待准备确认；未连接时的点击不会把冻结任务变成失败或要求重新建任务。真实厂家协议、标定与执行资格仍显示未知；这不阻断纯步骤模拟。
6. 点击 **开始模拟**。进度仅是已确认的软件步骤计数。断点、未确认范围、连接角色、无工具姿态和未验证治疗头参数继续保留。
7. 可点击 **暂停**，等待“暂停已确认”后点击 **继续**。不支持暂停的场景禁用按钮；暂停不通过取消或停止代替。
8. 点击 **请求停止** 后等待全体参与设备反馈；机械臂静止与输出关闭分别确认。收到请求、超时或取消不是已停止。正常完成也先核验全体停止状态。
9. 结束后点击固定栏中的 **查看本次结果**，自动打开并选中本次记录，再点击 **导出所选记录** 保存独立模拟事件 JSON。即使此前选中过其他历史任务，也会导出本次打开的结果。其他记录仍可在 **模拟记录 · 只读回看** 刷新并选择。关闭并重启软件后，旧未结束任务显示中断/待核对，不自动重新执行。

页面固定显示“选择方案 → 冻结 → 连接 → 检查 → 运行”步骤条。每阶段突出一个可操作的下一步；正常结束后突出 **查看本次结果**，有新候选方案时突出冻结。步骤位置不表示真实执行或几何质量已经通过。**当前模拟**、确认步骤进度、暂停/继续和 **请求停止** 位于标签页外，切到历史或配置、滚动内容后仍可见。

监控页显示设备中文状态、模拟检查和真实执行待接条件、最近 400 条关键事件。机械臂的输出关闭、输出设备的机械停止、固定底座的运动确认显示“不适用”；相关字段缺少证据时才显示“未知”。回看主视图显示方案名称、结果、步骤、来源核对及异常原因。空列表说明如何建立与刷新记录；原字段、连接代次和最近事件放进 **工程详情**，完整路线与所有事件仍保留在导出。模拟完成不改写原报告结论。

监控状态条显示当前模拟任务标识，悬停可查看完整 ID。底部提示随冻结、连接、检查、运行、暂停和停止阶段更新；完成后的导出通知不会被普通心跳覆盖。设备详情的心跳只更新变化的字段，保留滚动位置和已选文字；切换设备绑定时重新显示对应设备信息。

在历史页显式选择新方案、连接设备或冻结新任务，会返回 **设备、检查与事件** 页顶部，展示当前任务。仅打开历史记录仍然只读；旧回看任务不能在新连接完成后抢回页面。历史下拉框的选择继续用于导出该条历史记录。

| 当前状态 | 下一步操作 | 阻塞原因与恢复方式 |
| --- | --- | --- |
| 尚未建立任务 | 选择方案或显式合成测试，核验并冻结 | 加载失败保留具体错误，修正来源后重试 |
| 已冻结且能证明未下发请求 | 撤销冻结，或连接/检查 | 撤销经业务和数据库核验，记录“已放弃、未运行”，保留设备实例并允许改选 |
| 已冻结，设备未全部连接 | 连接模拟设备 | 检查按钮禁用并提示先连接；原冻结任务保留 |
| 已冻结，设备已连接 | 模拟前置检查 | 检查实际来源、能力、状态与记录条件 |
| 检查通过 | 开始模拟 | 仍不具备真实执行资格 |
| 正在运行或暂停已确认 | 暂停、继续或请求停止，按能力启用 | 不能直接关闭实例；先请求停止并等待结果 |
| 正在请求停止 | 等待参与设备分别确认 | 未收到全部确认时不显示已停止，不允许关闭实例绕过等待 |
| 已停止或模拟步骤完成 | 查看本次结果、导出，或建立后续任务 | 结果入口绑定当前任务；关闭实例前确认，原结果保持 |
| 停止结果未知 | 在 **实例与记录恢复** 中关闭旧模拟实例，再建立独立实例 | 关闭需要确认；原结果继续为未知，不改成已停止 |
| 记录存在持久化缺口 | 恢复可写后重试记录并标记缺口 | 停止与反馈处理继续，缺失事件不补造 |

## 处理故障与未知结果

失败、停止未知和记录缺口在醒目的异常区分别显示“发生了什么、影响、下一步”，就近提供异常详情、重试方案核验、记录恢复或关闭旧模拟实例。方案核验失败才显示核验重试；配置、回看及导出失败须按该操作修正后重试，不会触发方案冻结。普通导出通知与异常区分开；错误仍保留在完整事件中。

设备断线、状态过期、当前引用文件改变或配置替换时，停止下发后续步骤并请求停止。旧代次、重复、乱序和迟到反馈会记录拒绝原因。正常结束后，同代次的新故障或矛盾物理状态仍会报警；较新反馈将机械静止或输出关闭改为未知时，也会撤销原确认并显示结果未知。

“停止结果未知”保留相关模拟资源占用，不允许直接在同一实例开始新任务。在 **实例与记录恢复** 中点击 **关闭旧模拟实例**，阅读后果并确认后销毁软件实例，旧结果保持未知，再建立独立实例。选择“否”保留当前实例与资源。检查、就绪、运行、暂停及等待停止期间禁用该操作，应先使用 **请求停止**。该按钮仅用于模拟，不是未来真实设备的强制停止确认。

选错方案且尚未检查时，使用 **撤销冻结**。协调器要求未准备、零步骤、零请求尝试、无在途请求与无记录缺口；数据库在同一事务核对冻结事件、当前序号和不存在请求意图后，追加 `abandoned_unrun`。记录成功后释放任务所有者及冻结数据，保留已连接实例；可以直接改选方案。已经准备或下发请求的任务禁用撤销，必须请求停止。写入失败不释放原任务，也不假装撤销成功。

关闭实例或正常退出时，能证明未下发请求的冻结任务同样记为“已放弃、未运行”；无法证明时继续按停止/未知流程处理。已发生的检查失败不靠连接操作改为成功，修正输入后建立新任务。

事件写入失败时，页面显示持久化缺口并禁止新步骤；仍处理停止与反馈。恢复可写后，使用 **重试记录并标记缺口** 追加缺失序号范围，不能恢复未收到的状态。历史查看和其他离线页面仍可用。

最终停止确认期间发生故障或事件缺口，也不会显示正常完成。全体静止与输出关闭已确认但事件不完整时显示失败；先确认的设备随后报告活动或未知时，显示停止结果未知并保留相关资源。暂停期间状态失效会禁用继续并请求停止。

设备状态时间会随心跳更新，心跳不增加确认步骤或关键事件。下一任务需重新完成前置检查，上一任务的通过结论不沿用。

更换项目或退出会核对模拟页状态。关窗请求结束后台所有者并有期限等待；期限结束保存未知结果，不假装停止。关键队列溢出同样阻止新步骤并记录缺口。

读取方案时可点击 **取消读取 / 导出**；关闭工作台也会取消文件核验与历史导出。更换方案、配置或关闭实例会撤销旧候选结果，迟到读取不能覆盖新选择。原生路线只绑定清单登记的文件；编辑未登记的邻近草稿用于后续任务。替换当前登记的文件会阻止继续。

## 使用无界面入口

以下命令在同一套业务实现中完成显式合成运行、暂停/继续及独立几何间隙：

```powershell
.venv\Scripts\python.exe tools\simulate_devices.py --outputs outputs --synthetic --pause --gap-demo
```

使用已保存方案只读核验后模拟：

```powershell
.venv\Scripts\python.exe tools\simulate_devices.py --outputs outputs --plan "SAVED_PLAN.region.zip"
```

将 `SAVED_PLAN.region.zip` 替换为当前 worktree 的合法方案。成功输出 `state="succeeded"`、`source="simulation"` 和 `execution_ready=false`。不要把该结果理解为原选区已完整覆盖。

查看已记录任务及只读回放：

```powershell
.venv\Scripts\python.exe tools\simulate_devices.py --outputs outputs --list
.venv\Scripts\python.exe tools\simulate_devices.py --outputs outputs --replay RUN_ID
```

将 `RUN_ID` 替换为运行输出的 ID。`--export NEW_FILE.json` 导出记录，不覆盖现有文件。空记录列表不创建数据库。

故障测试可使用 `--fault reject|no_response|stop_unconfirmed|duplicate|old_epoch|disconnect|base_move`，一次选择一种；失败或未知以退出码 2 返回。`--scenario FILE.json` 加载版本化场景；配置可从页面保存到 `outputs/hardware_configuration/`，模拟能力及时间预算只用于软件测试。

**配置与场景** 可读取版本化 JSON 或保存当前修订。设备保存到 `<device_id>/<revision>.json`，场景保存到 `simulation_scenarios/<scenario_id>/<revision>.json`，相同修订不可覆盖。读取不自动连接；真实、回放、未配置适配器尚未实现，连接会明确失败。固定底座不提供运动接口；只有固定底座时不能开始步骤模拟。

## 查看安装记录与间隙

**配置、标定与间隙** 显示真实标定缺失。导入 `femto-installation-transform-v1` 记录只验证结构与来源，独立按版本保存，不产生真实测距资格。安装 ID、设备绑定、单位、轴与矩阵方向必须完整；米平移不能仅改标签冒充毫米换算。

来源摘要核对通过只表示证据文件与记录一致。页面显示“导入安装记录（实测资格未验证）”；文件缺失或被改写会显示对应状态。底座移动、解锁、未知或安装关系未知后，合成空间上下文撤销，必须开新会话，旧模型和任务不被改坐标。

**独立合成间隙演示** 使用已知合成平面显示 0.2 m。无实测手眼/工具安装、同步位姿或有效当前表面时，实时间隙始终不可用。原始视角支持不足、confidence 为修复 .3/未知 0、背面、遮挡、无交点或过期输入均不输出当前距离。

## 保留运行记录

模拟任务和事件位于 `outputs/history_metadata/execution.sqlite3`，历史索引位于 `history.sqlite3`，各自管理版本。两库联合备份与恢复见 [SQLite 历史记录与备份](SQLite历史记录与备份.md)。方案、模型、原始 RGB-D 及证明资产继续按原路径独立保存，模拟不会更新采集 latest marker 或治疗完成状态。

事件库当前写版本为 v2，新版本可只读 v1；首次写入在事务中升级，原任务和事件不改写。旧版软件会拒绝 v2 事件库，降级前须保留旧备份。历史索引库仍为 v1，独立于事件库升级。具体实现与验证见[六项交互完善记录](../历史开发记录/模拟联调六项交互完善_20261022.md)。

厂家接入资料与尚未验证范围见 [模拟联调契约](../技术资料/模拟联调与坐标准备契约_20261021.md) 和 [实施记录](../历史开发记录/单机硬件预备开发_20261021.md)。

# 保存区域，再独立规划

路线按钮现集中在独立规划工作台，普通采集结果窗口不再显示长串路线按钮。进入“历史记录 / 打开规划”，选择“区域”或“区域工程 / 方案”，点击“打开规划工作台”。旧区域记录会先转换成新的独立工程，需要原模型及参考图仍存在；原记录不变。新工作台内提供覆盖参数、禁区、播放、路径导出等完整操作。

历史入口：保存工程后，当前模型的“历史记录 / 打开规划”会自动列出“区域工程 / 方案”。选中后点击“打开规划工作台”，或双击该记录，在独立窗口继续编辑。历史窗口新增“导入已有区域工程”，可将之前保存或移动后的 `.region.zip` 加入当前模型的列表；同一路径不会重复登记。文件已移动/删除时明确标为不可用。导入只登记位置，真正打开时仍执行完整工程校验。GLB/PLY展示文件与路径分享ZIP不是可编辑区域工程。

1. 在采集结果固定RGB窗口完成圈选，在列表单选主区域。
2. 点击“保存方案”，保存为 `区域方案.region.zip`。有当前有效路径时同时保存；没有时保存基础区域即可。
3. 双击项目目录 `start_region_planner.cmd`，选择工程包；也可在原窗口点击“打开已有方案…”。无需连接相机。
4. 在独立工作台添加/清除禁止区域，生成区域覆盖路线，播放检查。
5. 点击“保存方案”更新当前工程；“方案另存为…”保留另一版本。对外展示用“导出分享包（模型＋路线）”。

一个工程只包含一个可编辑主区域，可有多个禁区；需要保存多个区域时分别保存。打开后工作副本存放在 `outputs/region_workspaces/`；关闭前用工程保存按钮将最新编辑写回一个ZIP，否则工作台未保存的修改不会自动更新原工程包。

工程包包含完整参考图片和参考网格，目的是正确判断被遮挡表面，不仅仅是圈内局部截图。共享工程时应知晓它含有圈外参考上下文。只向别人展示局部结果时用区域GLB/路径分享包。

包内保存参考深度、有效像素、内参、RGB、网格、可用UV/纹理、来源坐标说明、区域/禁区以及当前有效路线。原始采集路径作为历史文字保留，打开与规划无需该路径存在。它不是完整原始RGB-D序列备份，原始采集仍应另行保留。

迁移工程需另一台电脑安装兼容版本软件及其运行依赖；不是任意ZIP或GLB查看器都能编辑工程。GLB/PNG用于展示，`.region.zip`用于继续编辑。

导入核验文件与几何指纹并重新计算投影；保存的路径重算验证，损坏或不一致会拒绝打开。禁区变化后旧路径失效，需重新生成。边界/覆盖仍为研发模拟，不表示接触安全或治疗定位已验收。

## 第一批：统一状态与方案版本（2026-09-17）

4. 修改名称/备注后点“应用修改”，路径保持有效，保存状态变为未保存。点“保存方案”保存名称、区域、禁区、当前参数和有效路径；“另存为”保留独立历史版本。分享导出不清除未保存状态。
5. 无有效路径时播放和分享导出按钮禁用，请根据状态栏原因先生成路线。此行为替代旧版“点击播放/导出后自动进入规划”的流程。
6. 保存工程只写入当前有效路径；如果路径失效或尚未生成，则保存区域与当前参数，重开后显示未生成路径，不恢复过期报告。任务运行/失败消息属于本次会话，不作为有效结果保存。工程仍只包含一个主区域，其他区域的缓存不会混入。

新路径含 `femto-plan-binding-v1`：区域ID、区域几何/禁区指纹、网格指纹、规划参数、算法版本和路径/报告结果指纹。名称、备注和文件迁移路径不参与几何指纹。工程增加 `femto-planning-state-v1` 参数记录，保持原工程/路径外层格式和W0/RDF/米制约定。

旧工程和旧JSON先核验原始区域关联，再完整重算路径和报告。可验证时提示“旧版本缺少算法关联，已重算，请保存新版”；无法验证则明确拒绝，不重写原文件。未知算法版本、新版关联不符或报告被改动均拒绝采用。分享包增加 `plan_binding.json`，`path.json` 中的 `files` 将CSV、GLB、PNG、报告等文件的SHA-256绑定到本份方案；请整体保留分享包。

工程打不开时，提示缺失的资产/字段、损坏文件名或来源不匹配。不要用展示GLB、补洞或其他模型替代缺失几何；应恢复正确工程资产或从可信历史方案重新开始。本批没有改变W0/RDF/米、几何规划算法或原始采集证据。


## 第三批：路线配置与运动演示（2026-09-17）

本节替代前文仅水平蛇形和自动段间切换的操作说明。

1. 在区域列表单选已完成区域，点击生成覆盖路线。先选择**水平往返/垂直往返**及**左上/右上/左下/右下**起点偏好，再设置模拟扫描宽度、重叠率和边界余量。方向及角点均以固定初始 RGB 画面为准，不是机械臂轴方向。全部参数确认后才提交；中途取消不修改当前方案参数。
2. 起点偏好不保证精确落在角点，也不保证最近。按所选扫掠顺序取首条有效扫描端点。路线图和报告显示实际像素、W0/RDF XYZ（米）及调整原因，包括无可信可见几何、禁区剔除/选区外、区域掩膜、扫描半径/边界预留或扫掠端点限制。
3. 扫描为黄线，换行/绕行为橙线；每条链标记起终点，断链不画连接。有效表面图无法连接时，保留多条链；报告列出断点两端 XYZ 和原因。原因表示有效图被约束阻断，不声称已确定真实遮挡/孔洞的唯一成因。
4. 播放窗口支持**播放、暂停、继续、复位**，下方进度条可拖动，段选择框用于逐链查看。拖动或选链会暂停并定位，定位不代表已规划运动。到达断点自动停止；再次点击播放/继续仅定位下一链起点，然后演示该链，跨链没有插值、没有已知移动时间。关闭窗口停止定时任务，方案失效仍会关闭旧演示与报告。
5. 窗口显示当前 W0/RDF XYZ（米）、链序号、扫描/连接阶段及沿当前边的三维单位方向向量。选择 5/10/20/40 mm/s 会暂停并按新恒速更新模拟时间，当前位置保持。进度按所有链内已规划长度累计，跨链距离不参与；显示的“对应恒速时间”是当前选定速度下该进度对应的理论时间，不是用户实际观看的墙钟时间。
6. 统计分别列出扫描长度、连接长度、总长度、连续链数和恒速模拟时间。模拟时间只含链内扫描和连接的采样弦长，排除暂停、加减速和未规划的跨链运动。多链完整运动总耗时未知；不能将显示的已规划部分时间当作完整设备运动耗时。
7. 保存/另存工程保留方向、起点及同一份有效路径；分享包 PNG、JSON、CSV 和 GLB 使用同一链与点序。CSV 的 motion_kind 表示到达该点的边类型；每链首点没有入边，chain_start=True。新增 route_distance_m 和 known_time_s_at_20mm_s 仅累计链内运动。分享报告采用固定 20 mm/s；窗口临时改变演示速度不会改写工程规划参数。
8. 普通 GLB 是静态路线展示，含静态链顺序元数据，不包含动画，不保证外部查看器支持本软件播放控制。请整体保留分享包以追溯方案关联；单独的 PNG 是显示快照。

新配置标识 serpentine_v2 / 算法 serpentine-v2。历史 serpentine_v1 保留原顺序重算，不静默转成新规划；旧工程打开后若重新生成覆盖路线，则使用新配置。W0/RDF/米、可信几何门禁、原始采集及历史资产不变。本功能仅研发规划与运动演示，不验证实物精度、接触或机械臂可执行性。


## 第四批：覆盖解释与遗漏定位（2026-09-18）

本节适用于新生成的 `serpentine_v3` 覆盖路线；旧 v1/v2 工程保留原算法回读和播放，不自动改写。旧报告没有新版采样明细时会提示重新生成，新报告不能静默套用在旧路径上。

1. 单选区域，生成覆盖路线（方向、起点、宽度、重叠率及边界预留沿用第三批配置）。本版在原允许表面网格约束之后，再检查整个弦段的模拟半径包络、边界/禁区及端点/中点可见性。检查可能剔除连接并产生更多链；不自动放宽约束。失败/取消不提交新结果，已有有效方案按原状态规则保留。
2. 在路线窗口点击**查看覆盖报告**，进入“图层与遗漏定位”。可分别开关圈选范围、有效几何、禁区剔除、边界预留、无几何支持、选区离散限制、采样覆盖和采样未覆盖。绿/橙仅表示采样点，圆点大小是显示标记，不是扫描半径，也不代表整块三角面已覆盖。
3. 左侧列表包含“允许表面的采样遗漏”及“分母外排除范围”，两者不能直接相加为面积。点击条目会自动裁剪放大并白色高亮，显示像素范围及代表采样点 XYZ；点击“返回总览”恢复全图。无几何条目仅有像素位置，XYZ和三维面积未知。
4. “方法、分母与版本”页给出完整文本报告。分母是**每面面积/3赋予的允许、圈内且可信可见采样点代表面积之和**，不是精确裁剪曲面面积。禁区、无支持及未纳入选区的几何不参与分母；边界预留内仍有效的采样点参与分母，并可能列为遗漏。圈选范围的未知表面面积不编造、不加入分母。
5. 原因按可验证证据报告：禁区来自用户轮廓及整面剔除；边界预留/包络约束表示采样点或该位置作为扫描中心受约束；断连表示共边连通分量无路线种子；路线间距/布局表示到已有路线的距离下界超过半径。算法未证实覆盖表示欧氏邻近路线节点、但图距离上界未到达，真实遗漏原因仍未知。其余标为未知。不能仅凭断链数推断该区域遗漏，也不能保证减小间距就能补齐。
6. 每面固定3个重心采样点，按面积加权；网格大时单位面积采样较稀。估计采用保守图距离，跨面边只以端点提供覆盖种子，可能高估遗漏。报告中的采样覆盖比例不是完整曲面覆盖保证。
7. 保存方案后重开会按来源、参数、算法和报告指纹重新核验；改禁区/几何/参数使播放、报告和导出一同失效。分享包新增 `coverage_inspection.json`（全部明细和方案绑定）、`coverage_omissions.csv`（遗漏索引/像素范围/代表XYZ/证据），并输出新版 `coverage_diagram.png`。分享包的 `path.json` 记录这些文件的哈希，请整体保存；独立PNG只作展示快照。

边界图层显示像素预留带，定量遗漏以三维采样点为准。完整包络检查是保守模拟：可见性只在端点和中点检查，不是连续接触或真实工具碰撞验证。历史书本样例新增检查后从一条链分为234条链，明确保留未知跨链运动，而不是声称原来连接仍有效。没有新增实物精度、临床精度或机械臂执行验证。


## 第五批：绕行、重复路径与急转角（2026-09-18）

新生成覆盖路线使用 `serpentine_v4`；旧 v1/v2/v3 工程仍按原版本回读。参数入口和坐标约定保持不变。

- 生成时先按第四批算法建立通过检查的基线，再在**每条原连续链自己的认证边图**上尝试三种确定性候选：原扫描顺序的米制最短连接、最近扫描端点排序、最近端点排序并恢复原覆盖支持边。恢复支持边会明确生成往返连接，不会假装成曲线捷径；代价不合适就不用。
- 保留每条链起终点、第一扫描段方向及全部扫描边，允许重排和反向后续扫描段。每条新连接只经过基线已认证边，不跨原断链；不会为缩短路径穿越禁区、孔洞或未知几何。
- 只采用扫描长度/链数不变、连接和精确重复长度不增加、总长度确实下降的候选；再复核整个模拟包络，以及**每一个**原已覆盖采样点。覆盖分母必须相同，不能用新覆盖弥补旧位置的退化。没有满足全部条件的改善，保留原折线并报告原因。
- 点击路线窗口的**路线质量/急转角**，查看前后扫描/连接/总长、精确边重复长度、断链、急转点和采样覆盖对照。粉色菱形为相邻三维弦方向变化≥60°的急转点，可用“急转点”开关隐藏；在质量窗口点击列表条目，会暂停并定位对应坐标。定位本身不是已规划运动。
- “重复长度”只计精确相同无向XYZ边的额外经过，不估算相近路线的扫描带重叠面积。急转点阈值用于研发可视化，不是机械臂角速度、加速度或接触姿态限制。本批**没有增加平滑**；保持已检查折线，不存在未经验证曲线投入播放/导出的情况。
- 搜索最多三种候选、累计200万节点展开、每链512扫描段、候选最多20万点，并保留原120秒任务预算与60MB方案大小限制。搜索预算耗尽会停止，并保留已核验方案；取消/整项任务失败沿用原状态保护。改变参数后旧缓存不会被当作当前新参数结果。
- 保存/重开仍核验来源和算法版本；导出分享包新增 `route_quality.json`、`route_quality.txt`、`sharp_turns.csv`，全部关联同一结果指纹。质量窗口和文本报告写明未改善、覆盖退化拒绝、约束失败或预算超限；临时演示速度不影响算法对照。

已测禁区样例连接1737→1053mm、精确重复1121→437mm，采样覆盖和链数不变。矩形、断连和历史书本样例未获得满足所有门禁的改善，保留基线；不要预期所有区域都会缩短。优化会增加计算时间，详见同源对照记录。模拟运动时间仍只包含已规划链内运动，未知跨链动作不计时；未接入机械臂。


## 第六批：独立三维表面间距模式（2026-09-18）

工作台现在并列提供“固定RGB蛇形覆盖”和“三维表面间距规划”。前者保留水平/垂直、四角起点、换行和绕行；其目标毫米间距按参考深度换算为像素，不保证倾斜或弯曲表面等距。后者适合检查可信网格上的毫米层间距，使用网格边距离场等值线；它也不是精确连续测地等距算法，不能把目标间距当成实际测量结果。

1. 在历史记录中打开规划工作台，单选已完成区域。点击“三维表面间距规划”，依次填写目标层间距、沿线最大采样步长、模拟宽度、边界预留、报告容差，单位均为毫米。默认分别为5、1、4、1、1。取消参数对话框不改变原请求。
2. 种子固定为每个可信连通分量的最小W0 Y边界顶点，首层为目标间距的一半。此模式不使用RGB水平/垂直或四角偏好；改变网格/禁区/可信面集合可能改变种子及整组路线。
3. 禁区整面剔除后，顶点和面心均可见的面才参与距离场；孔洞和不连通分量保留。之后再执行整个弦段模拟包络与端点/中点可见性检查。检查可裁掉路线并产生缺层。无可用路线或预算超限明确失败，不回退RGB模式，也不放宽约束。
4. 输出由**独立扫描链**组成，本版没有生成跨链连接；连接长度为0。播放到链尾停下，继续到下一链属于显式光标定位，不是已规划运动。时间只计已有链内扫描；跨链移动耗时未知。暂停、复位、拖动和逐链查看沿用现有播放窗口。
5. 点击“表面间距报告”，查看保留路线到**紧邻前一目标层**的网格距离上界分布（最小、P05、中位、P95、最大、均值、偏差和RMSE），以及上下界判断。每链最多32个索引采样，首层不参与。点击条目暂停并定位对应链、点和XYZ。前一层缺失/不可达显示未知，不跳过缺层冒称目标等距。
6. “采样界内”表示该样本距离的上下界均落入目标±容差；“超差”有上下界证据；“无法证实”表示界不够紧；“无可达前层”没有可测支持。距离上界是沿网格边及面内端点连接的可行长度，可能高于真实最短表面距离。欧氏下界只是数学界，不能当成跨洞运动。整体出现任何非界内样本，状态栏、图及报告明确显示未完全满足或无法证实；“路径有效”仅指版本与路线关联有效。
7. “查看覆盖报告”继续显示采样遗漏。间距合格与采样覆盖率是不同检查；两种模式的可信面筛选可不同，不可只比较百分比就声称效果改善。
8. 保存方案/另存为后重开会重算核验。改几何、禁区或任一模式参数使原结果失效；只改名保留路径。草稿只恢复参数与区域，仍需重生成。分享包新增surface_spacing_report.json/txt、surface_spacing_samples.csv；JSON报告含方案绑定、模式参数与版本，CSV按结果哈希关联。path.json仍是完整回读入口，请保留整包。GLB含静态路线、模式和限制元数据，不含通用动态播放或机械臂指令。

已验证的4mm对照中，平面/倾斜平面的指定横截面间距为4mm；曲面在可信面及包络裁剪后出现约9.226mm间隙，未满足目标。该横截面结果不代表整张曲面。历史实采书本回放能保存重开，但间距报告也未完全通过。详情见《第六批三维表面间距规划交付记录.md》。新模式是可检查的研发规划模式，尚不保证任意曲面等距，更无实物治疗覆盖精度验证。

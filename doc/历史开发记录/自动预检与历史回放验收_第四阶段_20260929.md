目标工作区：`E:\测试3D人体关节坐标-ui`；分支：`ui/workstation-redesign`。遵循当前 `body-surface-planning` Skill，本轮不修改 Skill。用户明确要求“暂时不能配合，先完成自动预检与历史回放验收”，因此仅枚举设备和检查现有历史，不启动相机流或新采集。

## 交付内容

新增 `tools/check_body_surface_replay.py`：复用工作区环境诊断、SDK 适配器、实际历史加载器、现有选区质量检查与 VTK 视口。设备、回放和原生渲染使用当前 `.venv` 隔离子进程，清理外部 Python 路径；设备枚举超时 20 秒，回放/原生渲染各 180 秒。异常、超时与无效结果记录失败，不用模拟成功替代。

工具接受明确的重建目录或便携方案，可重复指定。报告使用独立新目录，拒绝覆盖旧报告或写入输入记录目录。检查前后核对源文件 SHA-256；历史 ZIP 按既有加载器解包到派生缓存，原包不改。模型未保存区域时不代替医师选区；保存方案只读恢复原区域/路线并计算当前诊断，不回写质量结论或缺失部位。

新增 `tests/test_body_surface_replay_check.py` 六项测试，覆盖已声明派生数据集引用原始帧、文件变化检测及越界拒绝、回放与现场结论分离、空记录/环境/设备/渲染失败、子进程错误和超时、报告路径保护、仅枚举且不构造采集 Pipeline。

未改变采集、重建、坐标、W0/RDF、几何映射、路径算法、历史格式、部位支持范围、依赖或治疗执行标志。保留本轮前已有的 235 项 Git 工作区条目，不重置、不提交，不执行会覆盖合规报告的主程序。

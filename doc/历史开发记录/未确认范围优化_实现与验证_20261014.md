# 未确认范围优化：实现与验证

日期：2026-10-14；最终软件验收：2026-10-15。当前 UI 工作区；真实保存工程的计算回放。本轮优化、验证与文档同步已完成。

## 已接入的优化

- 覆盖候选按源面缓存，小数组有界保存，密集面绕过；复用单元坐标归约结果。数值判据、顺序和工作限额保持。
- 未定位任务按实际像素原因给出建议：观测缺失、深度冲突与计算预算分别处理；已有参考图定位入口保留。
- 选区质量检查直接读取像素分类，省去生成记录、编码、摘要和解码；保存记录仍沿用原格式，碎片数量与深度范围校验保持。
- 配准验证批量计算已匹配点的颜色差；最近邻查询、距离判据、误差统计和接纳门限保持。提高评估效率，不把被拒配准改成通过。
- 2026-10-15补齐按原因定位：覆盖面板可单独选择原台账中缺深度、缺面、冲突、数值、预算或部分定位。二维着色与定位使用相同筛选；历史查看只读支持。新增的reference_status只是有界只读显示副本，不写入证书或工程格式。

## 精确邻接索引试验

新增 `indexed-anchor-ball-subedge-coverage-v3`。AVL 区间树用精确有理数上下界排除无关比较，按原插入顺序返回正长度交集，保持同球锚点证明。旧 v2 保存证据仍使用旧引擎独立回读。新版本写入策略与算法摘要。

首个真实样本的100万次原邻接检查中，898511次不相交。这是索引优化的依据。第二个独立采集样本未达到邻接限额，索引反而略慢，因此保留为显式试验，不改工作台默认。

## 剩余原因

- 原目标139148像素中：已定位43488、无网格24、数值未确认10530、目标建账预算未处理66817、部分定位18289。后三类不能统一解释为缺失实测数据。
- 独立精细选区质量检查：139096像素参考深度一致，52像素有深度但无网格；其统计对象与原目标像素定位不同，不能直接相减。
- 原目标建账上限、细分边界与物理缺失仍可产生未知；本轮没有重写原目标台账、放宽门限或补造点云。
- 历史配准拒绝包含修正超过5毫米/1度、尾部误差退化、留出误差缺少改善。其中部分已接近同帧噪声水平；本轮保留拒绝结果。
- 索引试验尚未推广默认；工作台仍使用已有原集合优先复算与补线流程。进一步推广需要更多工程的时间前沿与保留集合验证。

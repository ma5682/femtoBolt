# 部位选择与工作区域

运行当前工作区 `start_femto_app.cmd`；无相机预览可运行 `start_femto_app.cmd --ui-preview`。

1. 在新建采集右侧点击“选择人体部位…”。通过人体分区或列表选择第一阶段支持的部位、患者侧别、正背面和体位，核对后确认。新建局部采集必须完成此确认；未选择、暂不支持或仅手工填写部位文本时不能开始。示意图只用于导航；正面图左边是患者右侧，背面图左边是患者左侧。确认后留在实时采集页；历史记录可另点“查看部位记录 / 同任务采集”。
2. 在实时 RGB 画面点击“在 RGB 画面框选扫描范围”，拖出覆盖目标及必要周边的矩形。右侧显示当前画面框内深度有效比例；不足一半时调整相机距离、取景或重选范围。扫描框只规定本次采集意图，原始 RGB-D 不按框裁剪；框内有效深度比例不等于完整三维覆盖。
3. 点击“确认范围并开始局部采集”。按钮触发时的完整对齐 RGB-D 成为首帧候选；其位姿/质量通过后建立本次扫描参考。随后在允许的局部运动范围内停稳补采，至少接纳三个不同视角才能建模。首帧不合格时重新取景，不把旧框套在另一帧上。本次采集仅描述当前可见体表；翻身或明显变更体位后新建采集。
4. 完成建模后，点击“查看扫描范围缺口图”，看首帧参考图中的绿色可靠几何、紫色待检查及橙色缺失/冲突；右侧列出框内支持与缺失像素。缺失影响目标时点“重新采集该部位”回到取景，它保留任务与部位，但创建独立采集，不自动合并旧模型。历史采集没有扫描框记录时显示未知。
5. 模型检查通过后进入工作区域页，在这条记录的真实参考影像上用“涂抹工作区域”选入，用“擦除”排除。可以选多个分离区域，也可在内部留空，不需要再画独立禁区。扫描范围与工作区域分别记录，后者才是路线规划的选择意图。
6. 修改标记后检查三维几何，再计算路线、核对覆盖提示并保存。几何待确认像素仍需查看；选区不代表缺失表面已被测量。扫描范围检查的像素比例不代表表面积或治疗覆盖。

路线出现多段时，先看“候选路线原有断点”和“质量与宽度约束排除边”的数量。前者通常是工作块分离或模型表面不连通；后者表示候选路线经过缺失、边界余量不足或无法核验的网格连接。当前约束处理会截断候选路线，不会自动在有效表面域内重新绕行，也不会用直线跨越缺口。可定位待检查范围、补采并核对模型，或把工作区域限制在单个连续且有实测支持的表面后重新规划。

已有方案的红色禁区保留，仍从工作区域中扣除；涂抹、擦除与清空工作区域不会移除旧禁区。部位信息随工程保存；旧记录缺少体位等信息时显示“待确认”，不从图像自动猜测。采集期间及历史记录中的部位信息不能直接修改；新建采集重新选择。

手工编辑部位文本会撤销之前的结构化部位确认，须重新打开选择器确认支持部位才能新建采集。当前任务标签未绑定病例，人体示意图不是患者模型，表面路线仍是研发规划预览。

## 第二阶段：按部位查看真实记录

入口为工作台顶部“部位记录”或采集页“查看部位记录 / 同任务采集”；新建采集确认部位后保留在实时取景页。

先核对“采集任务”的名称与标识，再用“选择 / 更换部位…”确认患者侧别、正背面和体位。匹配使用任务 ID、部位、侧别、正背面、体位和当前覆盖范围，名称相同不会合并。若当前页面没有任务归属，须先显式选择任务；系统不会默认选中另一条任务。

| 当前显示 | 操作与含义 |
|---|---|
| 已采集 · 待检查 | 选择记录并打开，核对真实参考影像、模型和覆盖情况；不表示几何质量已合格。 |
| 已保存 · 待复核 | 打开对应保存版本只读回看工作区域与路线；需要修改时使用“基于此版本修改”。 |
| 文件或来源待检查 / 方案文件待检查 | 查看来源提示，检查文件并刷新；不能打开的记录不会当作可用模型。 |
| 当前条件下无已关联记录 | 可在此任务下新建该部位采集；此结论仅覆盖当前可检索的记录。 |
| 归属待核对 | 旧记录缺少可核验的任务或结构化部位信息，从原“历史记录”入口查看；不会按名称、目录或图像猜测归属。 |
| 记录读取失败 | 刷新重试或从历史查看；读取失败不代表尚未采集。 |

选择记录后会显示完整来源路径和任务标识。打开时在后台复核实际加载数据的任务、部位、体位和版本；成功后关闭弹窗并进入只读回看。文件变化、归属不一致或读取失败时保留原模型，弹窗可重试。关闭弹窗取消加载后，迟到结果不会覆盖原记录。更换筛选条件会清除已选记录，需重新选择。

“在此任务下采集该部位”保留任务归属，创建独立采集状态并应用刚确认的部位。它只准备采集页，仍需有效相机数据和人工开始；不复用旧采集的参考坐标、模型、工作区域或路线。原有“新建采集”入口则建立新的任务 ID。两者都保留原始采集文件和历史方案。

例如，打开任务 A 的“患者左侧 / 大腿 / 背面 / 俯卧”记录并只读检查；需要换成仰卧时，在“部位记录”中确认新的正背面与体位，再点击“在此任务下采集该部位”，完成独立采集与区域规划。原俯卧记录继续保留，仅在原筛选条件下匹配。

当前索引读取本工作区现有采集历史和已登记的便携方案目录，不遍历任意外部文件。未产生可关联结果的原始会话、缺少标签的旧记录仍需从历史入口核对。记录列表中的“待检查”是操作状态；选区检查见第三阶段说明。当前不提供患者身份绑定、跨体位配准或自动部位识别。

## 第三阶段：检查工作区域的几何支持

工作区域页侧栏上方显示“当前选区几何检查”。涂抹、擦除、撤销、重做或恢复草稿后，后台按当前记录和最新选区重新计算；检查期间清除旧统计与色层。查看结果时可勾选“显示选区几何检查色层”，或点击“定位待检查范围”切回参考图并缩放到问题范围。

| 颜色 | 含义 |
|---|---|
| 蓝底 | 医师的涂抹意图，不表示几何合格；擦除后的留空不计入选区。 |
| 绿色 | 当前像素有网格支持，且与参考帧有效深度一致。 |
| 紫色 | 有参考深度但没有网格，或有网格而参考深度缺失/超范围；证据待检查。 |
| 橙色 | 无网格且无有效参考深度、网格超深度范围、深度冲突或无源图像像素。 |
| 红色 | 历史禁区，继续从工作区域扣除，不计入选区质量统计。 |

“网格与参考深度一致”比例为绿色像素数除以扣除历史禁区后的选区像素数，**不是表面积比例或治疗覆盖率**。手动擦除的内部留空不计入分母。“检查详情”提供各原因的像素数和当前来源。参考帧没有深度、但多视角网格仍有表面的位置单独列为待检查，不据此断言网格是假数据，也不把它当作参考帧深度已证实。

整个选区无法核验或没有任何网格与参考深度一致的位置时，不能确认新区域、生成新路线或通过保存路线绕过检查。部分缺失的选区保留医师意图；当前主工作台新生成路线必须通过下述质量与覆盖宽度约束，缺失位置及其必要邻域不进入保留路线。缺失提示持续显示，保存时按“待复核研发草稿”提示核对。系统不会为了提升比例补造表面，也不会按自定百分比宣称临床合格。

需要补扫时，点击“在此任务与部位下重新采集”。有已确认的支持部位时，系统保留当前任务、患者侧别、正背面和体位，准备一条独立采集；仍需在采集页人工开始。旧记录、工作区域和路线保留，新采集重新建立参考位置并重新标记规划。体位已改变时，先通过“部位记录”确认新体位；缺少归属或部位不支持的旧记录不能直接使用此补扫入口。

只读回看页同样提供当前选区检查与色层开关，旧方案中的原字段保持不变。当前检查由打开的真实参考影像与网格重新计算；保存路线原有报告与本次参考影像检查分开显示。切换来源会清除旧检查，加载失败保留原模型并重新检查原选区；取消后的迟到结果不覆盖新来源。

标定、来源、固定参考坐标及帧位姿的准入沿用现有加载器。该像素检查不能判断每处缺失究竟由跟踪失败、配准失败、遮挡还是未观察造成；需要结合原质量报告与实际采集检查。绿色也不代表已验证患者身份、组织类别、全身体表覆盖或实物精度。

## 当前路线补充：几何质量与覆盖宽度约束（2026-09-30）

在“路线”页核对有效作用宽度，再点击“重新计算路线”。即使选择直接指定行距，有效作用宽度仍参与覆盖带边界检查；外壳直径、外壳避让余量与治疗深度继续只记录。初始宽度是占位值，不能当作已核验设备能力。

系统先构建质量合格网格面子集，保留原三角面索引和选区意图，再生成网格候选路线并检查每段扫描边和贴面连接边：整个线段须有真实网格支持，其覆盖半宽加局部参考残差余量必须远离边界，覆盖带投影包络内只能有选中的绿色支持像素。缺深度但有网格的位置也不能放行。保守包络可能排除实际可行的窄区或折面，不会补面或用直线连接断点。

路线摘要显示保留和排除的边数、待检查像素；报告保存排除范围及原因。原选区完整保留，未规划部分不会变成“未选择”，完整目标保持未完成或未验证。保存得到的是待复核研发草稿。修改宽度后须重算；保存前重新核对质量证据，证据已变化时拒绝沿用旧路线。

旧方案仍按原规则回看，界面提示未经过当前联合约束；只有主动重新计算才生成新版本。补扫仍建立独立记录并重新核验、重新规划，不自动把旧路线迁移到新模型。局部参考残差不是实物误差上界，配准与标定不确定性尚未定量建模；该功能不能证明人体实物精度或治疗覆盖。

详细规则和本轮验证见 [交付记录](../历史开发记录/几何质量与覆盖宽度联合约束_交付记录_20260930.md)。

当前新路线版本为 `quality-constrained-surface-v2`。摘要增加合格面数与缺失范围数；缺失按质量原因和空间连通分组，保存参考图像素范围、待检查/补扫动作，不伪造缺失 XYZ。有效中心域为隐式宽度/残差约束，不是完整预内缩网格。无合格面、候选生成失败、全部路线被约束排除时，错误提示给出 `planning_inputs` 下本次 `planning_assessment.json` 路径；原选区和历史路线不被覆盖。成功导出同时包含 `effective_domain.json`。v1 历史仍可按原版本回放和重现。详见 [本轮交付记录](../历史开发记录/有效表面域与缺失处理闭环_交付记录_20260930.md)。

## 第一阶段支持范围（2026-09-29 边界修正）

正式可选：肩部、胸部、腹部、腰部、上背部 / 腰背部、臀部 / 髋部、上臂、肘部、前臂、腕部、手背、手掌、大腿、膝部、小腿。

列表沿用正背面切换：正面显示胸部、腹部、髋部；切到背面，对应显示上背部、腰背部、臀部。腰部保持独立选项。患者左右和体位仍需人工核对，不从示意图推断实际患者朝向。

点击手部后，在二级按钮中选择“腕部 / 手背 / 手掌”；也可直接从部位列表选择。单根手指、指尖、指缝和单指关节精细规划不属于第一阶段稳定能力，不提供逐指入口。

头部、面部、颅颈精细区域、足部和脚趾暂不支持。图上的头、颈和双足轮廓保留并置灰；点击只显示暂不支持提示，不形成已确认选择。列表中的相应项禁用。

旧记录中的原部位值和确认字段保持原样，只读回放显示“当前版本暂不支持新建”，不重写历史文件。旧笼统“手部”“骨盆部”标签仍可读取；新建时分别选用腕部 / 手背 / 手掌或臀部 / 髋部，不静默替换旧标签。没有结构化信息的旧记录仍显示待确认。

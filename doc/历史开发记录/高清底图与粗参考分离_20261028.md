# 高清底图与粗规划参考分离（2026-10-28）

用户要求图片清晰，同时保持粗参考规划速度。本轮把高清RGB显示与规划RGB/深度/选区格分开，未改变TSDF、完整三维网格、选区取样或沿线自动取点。

## 实现

新建粗参考时保留原先已校正的完整RGB数组，只读保存为显示副本；`model.rgb`、深度、内参和`view_reference`保持原粗格值。界面底图使用高清QImage，所有鼠标映射、笔刷、缩放定位、撤销、禁区、质量/覆盖格和路线仍采用粗参考坐标。

高清图按整数格来源关系映射：原像素中心`u_source=stride*u_derived+offset`，绘制矩形另补偿Qt像素边界与中心的半像素差；裁剪在原粗参考画布内。未整除的图像尺寸也不拉伸错配。区域及质量覆盖格使用最近邻显示，避免平滑颜色制造精细边界假象。

显示RGB必须同时匹配派生记录中的原RGB数组SHA、原图尺寸、stride/offset，并逐像素验证整数抽样结果等于当前粗RGB；拒绝不匹配底图。显示副本不进入规划修订、目标台账或路线参数。

便携工程新增可选资产`display_rgb.png`，RGB无损PNG低压缩编码，纳入原资产清单、SHA及ZIP完整性检查；回读再与原RGB记录和粗RGB核对。旧工程无该资产仍可打开；在原始采集数据可用时后台按原标定重建原图，仅完全匹配才用于显示，来源丢失或不一致则保留粗底图，不伪造高清细节。带有高清资产的新工程可以在无原始数据的环境下重开。旧R7程序不识别这个新可选资产，打开此类新工程需使用本轮更新后的程序；旧方案由新程序继续兼容。

完整高清图多占约6.2MB RGB内存（1920×1080×3），Qt显示另有图像副本；便携文件增加一张压缩高清图片。没有把高清照片重新用作高密度计算参考，也没有提升三维物理精度或机械臂执行资格。

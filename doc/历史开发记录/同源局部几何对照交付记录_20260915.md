### 坐标及门禁

- W0 为已证明的首次有效彩色相机参考：RDF，X 右 / Y 下 / Z 前，内部单位米。
- `T_W0_Ct` 只用于将源观测放入 W0。最终模型顶点已经处于 W0，评估和显示不再变换它们。
- 原点直线距离使用 `sqrt(X² + Y² + Z²)`；显示毫米时乘 1000。对照页本身不新增测量坐标或机械臂输出。
- A 必须来自原始在线局部会话，禁止把已有精配准、已有筛选或改写深度伪作 A；合成来源只能显式 `--allow-synthetic`。
- 校验会话、参考证明、6 个标定文件指纹、首帧单位位姿、接纳帧 ID 和顺序、在线记录与 Pose 相同、有限位姿、时间戳、同步、有效质量与记录的工作空间半径。
- 原图/原深度字节必须与对应 raw 源一致。Mask 核验同帧/同会话/同参考、源文件 SHA、五帧来源、窗口复算、报告绑定、Mask 路径/哈希/形状/二值值及现有 `filtered_depth()` 门禁。
- 历史会话没有记录 20 mm 工作空间策略时，如实记录未知，不替它补写已经通过该策略。

### 资源及取消

默认最多 20 个接纳视角，按顺序执行 6 个阶段；每阶段最多 300 秒、3072 MiB 提交内存，阶段工作进程并发数为 1。一次任务的默认阶段时间上限之和为 1800 秒。日志流式落盘，报告仅写真实阶段状态和已用资源，没有伪造百分比。

Windows `.venv` 的 `python.exe` 是启动器，实际解释器可能为后代进程。本实现使用 Windows Job Object，挂接挂起启动的根进程后再恢复，使启动器及后代均受内存硬限额和退出清理约束。`peak_job_committed_mb` 是进程组峰值**提交内存**，不是物理内存 RSS。超时或取消会终止整个任务进程组，避免后代迟到写出结果。

失败、取消和未采用均保留自己的诊断目录；对照工具从不更新 `datasets/latest_scene.txt`、`outputs/latest_complete_demo.txt` 或 `outputs/latest_moving_reconstruction.txt`。运行前后校验这些索引，不恢复外部工具的合法更新。

页面保留首帧照片和首帧原始点云投影。各版本均生成：

- `comparison_surface.png`、`comparison_reference_rgb.png`、`comparison_initial_raw.png`：离线渲染，非真实相机精度证据。
- `comparison_view.json`：相同观察参数、图像源哈希。
- `comparison_metrics.json`：下面分项指标。
- `variant.json`、`reconstruction_report.json`：实际输入与结果来源。

指标分开报告，不把一种数值替代另一种：

| 指标 | 定义与限制 |
| --- | --- |
| 内部几何残差 | 每个视角最多 4096 个确定性原始有效深度采样点到网格的距离；采样序号在 A/B/C 固定 |
| 深度一致性 | 相同源像素射线的最前网格命中深度与原深度之差；缺失命中单列，并另报缺失按 0 深度计算的残差，不能悄悄删除缺失样本 |
| 有效像素比例 | 原始有效深度与实际二值 Mask 后的有效深度分别统计，不产生补造深度 |
| 点 / 顶点 / 面数、边界边数 | 几何诊断；边界边不等于真实缺孔数量，点增长不等于覆盖率 |
| AABB 范围、三角面积 | 模型坐标几何量，不是独立测量的人体尺寸，也不是物理精度验收 |
| 噪声、重影、ROI 补洞 | 没有预先指定区域和独立依据时为 `not_evaluated`，不以外观或总点数推断 |
| 合成真值距离 | 仅当合成来源、真值 SHA 和 W0 证明均匹配时生成，明确 `physical_accuracy_verified=false` |

缺失字段显示“未记录 / Not recorded”。优化候选指标与实际采用结果分别保留；候选单帧通过不表示整次优化采用。

## 导航规则

| 步骤 | 切换条件与行为 |
| --- | --- |
| 部位与范围、局部采集 | 有可关联的已结束采集时提供回看，标题与说明明确为“回看”。前者优先显示已有范围检查，后者优先显示已有初始点云；缺少对应显示数据时回看最终模型。不会重新启动相机或修改采集范围。 |
| 检查模型 | 从规划页返回其关联采集的检查视图；历史只读页也可直接查看本记录自带的模型。关联采集缺失的规划不会显示另一份采集。 |
| 标记区域 | 已加载规划模型时可返回原标记页；历史版本只回看已有区域。首次从采集进入规划仍需原模型确认。 |
| 生成路线 | 当前区域已经确认，且没有待确认的标记修改；使用原区域与参数检查。历史版本只回看已保存路线。 |
| 核对保存 | 路线与当前区域、参数和几何来源一致，满足原 `usable()` 条件；确认与保存仍沿用原限制。历史版本只回看，不进行保存。 |

采集（含暂停）、建模、采集预览或方案读取、区域确认、路线计算及保存期间，步骤栏暂时禁用。任务完成或取消结束后重新计算可用步骤；禁用项的悬停提示说明原因。可用步骤采用手型光标，Tab 可定位，空格可切换。当前位置与按钮可用性不表示质量检查通过，没有增加完成对勾。

## 内容与来源保留

在标记、路线和核对页之间查看时，继续使用同一页面实例和已加载模型，保留标记、参数、路线、草稿 journal 及核对状态。实际修改区域或参数继续触发原失效规则，不能把过期路线当作当前结果保存。

从规划或历史进入采集回看时，记录原页面、模型对象及关联采集结果目录。返回时同时检查这些绑定；新建采集、不同结果或模型替换不会把旧方案作为新记录继续使用。点击步骤栏返回原页面不重载来源。采集页底部按钮返回时也保留原便携 ZIP 草稿，避免被同源 reconstruction 工程替代。

关联采集预览读取失败后，读取成功前的采集视图仍不可进入，但可点击返回原来已经加载的规划草稿。没有把读取失败当作成功，也没有改变首次进入规划的确认条件。

历史记录始终保留 `editable=False`。切换标记、路线和模型只调整显示层及当前位置；“基于此版本修改”仍为独立编辑入口，历史版本不会被步骤点击覆盖。

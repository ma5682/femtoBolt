# P5 名义变宽作用模型验收

本轮完成 V1.0 方案中 P5 的名义模型软件链条：逐段半宽上下界、所有扫描与连接边的上界复检、独立覆盖、保存回读、模型失效及两级恢复。真实偏移上界仍未知，不把名义模型包装为设备标定结果。用户已明确暂时没有 P6 配对验证数据，先完成 P5；跨会话仍保持独立模式。

## 实现与边界

工作台先生成并严格重建路线，再显式应用变宽模型。模型采用每条连续链的归一化累计弦长，包含连接边；各 float64 弦长转为精确二进制有理数累计，断点后重新从 0 开始。2–128 个节点覆盖 0 和 1，满足 `0 ≤ 半宽下界 ≤ 半宽上界 ≤ 0.05 m`。逐边极值检查包含全部段内节点，下界向内、上界向外舍入；仅有离散样本没有插值依据时保持未核验，不安装新路线。

模型上界不得超过原固定生成半宽，以保留原连接搜索的保守包络。所有已有扫描和连接边按各自上界重新执行参考质量、边界余量及 P4 严格支持检查，任一边未通过则整次应用拒绝，保留原路线和缓存，独立保存失败原因。此入口不增加连接，不改变原点、锚点、角色和断点。当前只接收未补充的 P4 路线；需要 P3 补线时先恢复原工作流。

覆盖使用每条已接纳扫描边的整段下界形成端点内包球，连接不计覆盖，零内包半径不确认面积；外包最小全宽仍为原 0.5 mm，内包不抬高。沿用原整单元包含、正长度公共子边证明和预算。相同固定半宽的退化模型已在合成回归中复现旧固定球的全部证明数组。

来源名称、版本、插值规则及 UTC 生效／截止日期参与摘要。修改模型清除旧覆盖和人工核对资格，保留原目标身份与所有目标数组。保存开始与最终发布、覆盖完成与界面安装前检查日期；过期历史可读，但当前使用、核验及发布拒绝。上游输入变化时不能借恢复安装旧结果；取消、代次与整方案变化均拦截迟到结果。

原生新增 `variable_footprint.json`、`variable_width_report.json`，保留 P4 支持报告及 CSV 锚点。原生／便携发布与独立回读完整重建目标、重放逐段界、逐边检查及覆盖，原生完整回读仍重建原 v3。同一次 Qt 双格式保存仅复用原生完整验证并发布后签发的进程内凭据，独立读取不复用；外来凭据和重新封装哈希的假诊断拒绝。

当前模型为 `mode=nominal`，名义中心偏移假设为 0，物理中心偏移、配准及标定不确定性为 null。确定性上界与统计区间分字段保存为未知，不把深度残差当作设备误差。W0／RDF／米、完整场景 RGB-D、原 Mesh 保持，`execution_ready=false`、`physical_accuracy_verified=false`。详细格式见 [P5 契约](../技术资料/P5_名义变宽模型与回读契约.md)，操作见 [使用说明](../使用说明/名义变宽模型与恢复.md)。

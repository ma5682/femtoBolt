# 工作台文案与交互整理

本轮针对 PySide6 产品入口，隐藏重复操作说明，恢复必要的折叠入口。

## 修改

- 采集：普通阶段检查说明放入按钮悬停提示；计算中、失败、停止补采和已有检查结果仍显示。
- 采集：恢复任务与设备详情折叠按钮，连接展开动作，刷新保持展开状态。任务名称仍受采集中、历史回看只读约束。
- 规划：无选区及已有正常检查色层时，隐藏画面下方重复说明；有选区但尚无检查色层时保留原因提示。
- 规划：无工作区域时禁用清空和适应选区，并提供原因；撤销恢复选区后恢复可用状态。
- 画布：常驻文字仅保留缩放比例，鼠标操作说明移到悬停帮助。
- 三维：常驻长段说明缩短为图例；保留覆盖显示近似提示、三维加载失败及坐标拾取反馈。

## 验证范围

- 新增回归覆盖详情展开后刷新、折叠，以及空选区、清空和撤销后的按钮状态。
- 离线渲染检查采集页及合成模型规划页，1280×800 下无明显遮挡。截图位于 `outputs/ui_cleanup_20261020/`。
- 本轮未连接相机，不构成实采、物理精度或设备执行验证。
- 工作区已有大量未提交修改，本轮沿用现有实现，没有提交或回退这些改动。

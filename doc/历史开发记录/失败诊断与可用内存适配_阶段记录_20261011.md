# 失败诊断与可用内存适配：阶段记录

日期：2026-10-11。当前目标仍在执行，本记录不表示全部验收完成。

## 已实施

- 后台 `OperationRecord` 提供不可变摘要、最内层失败阶段和显式已发布资产记录；原异常仍原样传播。失败日志写入失败时仍可展示内存中的阶段与原因。异常被捕获后成功、后续独立异常及显式异常链分别处理，不把旧失败阶段借给新任务。
- `TaskRunner` 只交付当前代次的诊断，下一任务清空；规划失败展示阶段、原因、当前保留内容及重试/返回/草稿恢复操作。原生保存完成而便携保存失败时，明确展示已保留的三维路线包。直接参数检查不用后台旧诊断。详情保留原始路径，主界面长路径可以换行；后续状态会清除旧错误提示。
- 采集失败直接展示已有报告中的失败阶段、原因、数据目录与日志位置，连接到“查看本次报告”“状态详情”和既有重新采集操作。报告不含阶段时明确未知；发布残留不能变成本次完整成功。取消、旧输入结果未安装继续区分。
- 新增 `available-memory-preparation-v1`：Windows 使用当前 `GlobalMemoryStatusEx` 可用物理内存，其他系统可读取 `/proc/meminfo`；查询失败保守回退。预留至少 2 GiB 或总量的 1/8（取较大者），仅用剩余量的 1/32、最多 128 MiB 决定单任务候选缓存容量。该预留是分配策略，不是操作系统硬性保留。
- 只读候选输入缓存按任务规模限额，最多 16,384 项，每项最多 128 个候选；不足预留量时关闭缓存，稠密面继续直接计算。未知资源上限保留 4,096。策略冻结于任务创建，不缓存接纳、排除或覆盖资格。
- 文件 SHA-256 缓冲按文件大小与可用内存配置，低余量为最多 64 KiB，其他条件最多 1 MiB；仍摘要全部字节，保留取消检查。原几何算法、数值运算、工作计数、证明版本及硬预算不变。
- 本阶段公开资源/诊断数据接口、装饰器泛型及 Qt 工作接口补齐类型，不提前加载 Torch/OpenCV，不增加第三方依赖。后台诊断与失败展示分模块维护。

## 验证与实测

80 项定向测试已通过：资源策略 5、诊断 13、Qt 失败展示 7、候选准备 8、分块摘要 5、输入修订 12、Qt 采集 19、Qt 规划 11。最后新增的提示清理由 Qt 失败展示专项覆盖；完整六项仓库验证运行中，结果以本阶段 `validation_final/result.json` 完成输出为准，不能沿用前序 1520 项作为当前全部通过的证明。

模拟低/高可用内存仅用于验证配置。缓存为 0、64、16,384 时，两种当前复算算法的完整/预算中断数组、元数据与工作计数逐项相同；低/高内存摘要一致、取消保留源文件。注入磁盘失败的正式主题布局在 1280×850 offscreen 检查，能看到原因、保留内容、诊断与下一步；这不证明设备或 GPU 实机验收。

三份已有真实采集来源工程各运行一次完整 Qt 保存和原生/便携独立完整回读，全部通过：

| 工程 | 路线点数 | 保存秒 | 保存进程 RSS 采样峰值 MiB | 便携回读秒 | 原生回读秒 |

“小/中/复杂”按本次选中工程的路线与证明规模描述，不是通用规模标准。小、中工程分别是 `mesh-slice-serpentine-v4.4` 和 `quality-constrained-surface-v2` 历史版本，没有名义目标覆盖证书；按各自原版本完整回放，不补造证书，也不将它们当作当前 P2/P3 证明规模测试。复杂工程保存原目标、覆盖证书及所有资产摘要，原未知、断点和预算未完成范围保留。源 ZIP SHA-256 均保持，原始 RGB-D/标定/位姿未改。

观测条件：RSS 每 20 ms，系统可用内存每秒；峰值/最低值是采样值。机器可用内存曾低于 0.5 GiB，复杂工程回读期间低至约 1 MiB 采样值，不能据此归因所有耗时。三种规模来源、算法、资产与每阶段内存/CPU/耗时见 `outputs/resource_diagnostics_iteration_20261011/stage_evidence.json` 和各工程目录。没有升级前后同负载对照，不宣称这些时间是代码提速。测量后只增加了规划状态清除旧错误 tooltip 的 UI 修复，几何、保存及回读代码未变；当前完整回归继续覆盖最终源码。

单独的合成 64 MiB 摘要测量中，原 1 MiB 缓冲 Python 临时分配峰值约 1.01 MiB，当前低内存缓冲约 84～85 KiB，全部摘要相同；耗时约 0.048～0.057 秒与 0.081～0.169 秒，低内存模式在此测试更慢。该专项测量曾与复杂工程的回读短时重叠，仅说明局部分配与摘要一致，不能用于同负载整体性能比较。原始数据、证明资产和现有工程均保留。

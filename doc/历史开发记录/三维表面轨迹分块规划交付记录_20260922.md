> 日期：2026-09-22

## 交付内容

- 新增 `mesh-slice-serpentine-v3`（`block_planning=true`，隐含 `connect_rows=true`）：区域 PLY 按三角面共边连通关系分块（`surface_trajectory.face_components`，纯拓扑，不焊接顶点、不按距离或外观合并），每块单独做 PCA / 回退、切片、行序、gap 判定和贴面折返，再按访问顺序拼成唯一 `ordered_items`。块内逐行折返完成后才进入下一块，块间只放一个 `disconnected_surface` gap，没有跨块插值点、管线或连线。
- 块编号 = 访问顺序（0 起）。访问顺序确定：把每块顶点投到参考图像，按 `start_corner` 取阅读顺序（`top`：v_min 升序 / `bottom`：v_max 降序，再 `left`：u_min 升序 / `right`：u_max 降序），无法投影的块排最后，同值按分量 id（按最小面索引编号）升序。记录在 `blocks.order_rule`。
- 自动方向按块计算；`w0_x` / `w0_y` / 角度对每块含义相同（在该块法线垂面内的投影或旋转）。`planner.sweep_frame` 保留整体网格帧仅供俯视图展示，标 `role=display_only_whole_mesh_frame`；每块自己的帧在 `blocks.items[].sweep_frame`。
- 不可规划的块（`insufficient_extent`、`no_positive_area`、`axis_perpendicular`、`narrower_than_row_spacing`、`no_supported_segment`）不静默丢弃：`blocks.items[]` 记 `status=unplannable` 与原因，`gap_report.unplannable_blocks` 汇总，`statistics.coverage_status` 为 `complete` / `partial`，并计未规划面数与面积。全部不可规划时抛 `Unplannable(all_blocks_unplannable)`，历史重新生成保留旧结果，CLI 写 `trajectory_blocked.json`（含逐块原因）。没有为让小块通过放宽任何冻结阈值、行距或步长。
- 预算：全部块共用 200,000 点预算和表面间距测量的展开 / 距离对预算，不按块各开一份。
- 数据：`ScanSegment.block_index`，`trajectory.json` 新增 `blocks`（schema `femto-surface-trajectory-blocks-v1`，含每块 `component_id`、面数、面索引范围、面索引列表 SHA-256、状态、段 / 点 / 行区间、扫描与折返长度）；统计新增 `block_count`、`plannable_block_count`、`unplannable_block_count`、`inter_block_gap_count`、`coverage_status`。校验时核对块与网格连通分量、每块面清单哈希、每个点所在面属于其块、只有块间 gap 才是 `disconnected_surface`、块统计与 `ordered_items` 一致。`trajectory.csv` 增加 `block_index` 列、`gaps.csv` 增加 `block_from` / `block_to`，新增 `blocks.csv`；既有键、文件名与单位不变。v1 / v2 文件没有这些字段，仍按原语义读取和重算；带 `blocks` 的 v1/v2 或缺 `blocks` 的 v3 都拒绝。
- 展示：GLB 每个已规划块一个管线节点 `surface_trajectory_block_NNN`，元数据带块摘要；路线图与俯视图标块编号和覆盖状态，块间不画线；报告逐块列出状态和原因。播放窗口新增"块"下拉（全部块 / 单块，含未规划块状态），只做显示过滤并定位到该块首链，不修改保存的轨迹；块间停止提示"块间停止…不播放跨块运动"，继续仅定位下一块起点。历史列表状态栏附块覆盖摘要，重新生成完成提示报告块数和未规划块。
- 入口不变：历史区域"生成 / 重新生成三维扫描轨迹"、`生成三维蛇形扫描轨迹.cmd` 和 CLI 均启用分块；一个历史区域仍只有一份当前轨迹，新结果校验通过后才清理旧目录。

## 限制

- 分块只按网格拓扑；TSDF 缺面把同一物理表面切成多块时会按多块扫描，块间不桥接，需上游改善采集或网格。
- 块访问顺序是参考图像阅读顺序，不是最短路径，也不含任何跨块运动定义。
- 仍是 XYZ 研发预览：`execution_ready=false`、`physical_accuracy_verified=false`，无姿态、速度、避障或设备接口；没有实物验证。

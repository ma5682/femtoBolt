# 分块覆盖重复边界比较优化（2026-10-16）

本轮继续处理覆盖计算预算未处理范围。源工程为 `outputs/exact_target_coverage_followup_20261015/recalculated.region.zip`，原工程和原始采集证据保持。

## 问题与实现

旧版当前证书停止于 `outside_pixel_recheck / comparisons_budget`：100万比较已经用完，尚未进入剩余原单元扫描。邻接只使用91886次，故本轮未改邻接索引。

新增 `paged-target-retained-first-grouped-coverage-v2`，由 `coverage_grouped.py` 实现。在同一候选分组内，对当前完整包围盒上下界逐字节相同的根单元，只计算一次完整的球排除关系，再将该关系用于各成员。相邻但不同的坐标、正负零字节不同的边界不会归并；没有坐标容差。所有候选比较完成前不安装该批结果，每个成员安装都检查预算/取消。前面的原确认集合重新证明、质量门禁及后面的正长度公共子边证明保持原实现。

新算法有独立名称、策略摘要和确定性步骤计数；历史分块v1及未分块算法继续按原版回放。工作台对已有固定名义作用模型覆盖的分块目标复算选择新版本，初次覆盖仍沿用原算法。复算引导只有一层，不保存递归历史，覆盖资产与引导合计256 MiB上限保持。原比较、邻接、证明、细分及30秒求解预算保持；产品操作另有120秒限额。

预算未处理减少8953个（约4.71%），本次遍历合并64042个重复包围盒。共同细分比较中的确认集合摘要相同，损失与新增权重均为0。确认名义面积仍为0.005623710357319244平方米。该结果代表更多单元获得明确排除判断，不代表新增覆盖面积；当前状态仍为 `calculation_incomplete`，总原目标面积未知，物理精度未验证、不可直接执行。

停止原因仍是像素排除阶段的比较预算。后续若继续减少剩余181140个单元，应检查候选集合规模及像素/叶单元排除调度；重复点击同一输入不保证继续推进。剩余80个未定位像素由缺面24、真实部分定位56组成，本轮不改变几何目标。

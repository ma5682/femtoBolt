# 工作区域几何质量反馈：第三阶段

目标：`E:\测试3D人体关节坐标-ui`，分支 `ui/workstation-redesign`。遵循本项目 `body-surface-planning` Skill，使用本工作区 `.venv`（Python 3.12.10 / PySide6 6.11.2）。保留既有未提交和未跟踪文件，不修改其他工作区或共享环境。

## 实际证据与范围

- `FixedProjection.reasons` 已区分支持、无表面、超深度范围、深度冲突和无源像素；现有 `build_selection_support()` 区分无网格时参考深度有无。来源为绑定网格的最近交点和参考帧深度，不是人体语义识别。
- 既有 `selection_support` 的 `measured_mesh` 类别含 `projection.new_support=True`：网格可由其他视角支持，但参考帧深度缺失。因此本轮不能直接将该类别计作“参考深度已证实”。
- 实际记录加载继续复用标定、来源、固定 W0 及帧位姿门禁；便携方案沿用已有资产哈希和绑定校验。当前逐像素数据不能指出跟踪失败、配准失败或遮挡的具体原因，不伪造这些分类。

## 实现

1. `region_quality.py` 复用原选区支持分类，按 `work & ~forbidden` 计算；没有工作区域时不隐式选择整幅图。仅显示层拆出“有网格支持，但参考深度缺失或超范围”，其他原始分类和历史 schema 保持不变。
2. 规划与只读回看增加异步 `RegionQualityPanel`：选区像素数、一致比例、待检查数、原因详情、色层与定位问题范围。涂抹意图蓝底，绿色为网格与参考深度一致，紫色为单侧证据待检查，橙色为缺失/冲突，红色保留历史禁区。比例不代表表面积或治疗覆盖。
3. 编辑开始立即清除旧色层和统计；笔画结束、擦除、撤销/重做、无变化笔画、草稿恢复和模型切换均更新检查。后台任务用代次与模型身份过滤结果，取消或旧任务迟到不安装；窗口关闭会取消诊断任务。NumPy 计算在后台执行。
4. 新区域确认、生成路线和带路线保存均检查当前证据。完全无法核验或一致支持为零时阻断；部分缺失可保留选区意图，沿用原网格规划和待复核提示。没有新增百分比合格阈值、补点、插值或跨缺口几何。
5. 打开规划工程时将当前选区检查并入后台加载；来源、模型与检查结论一起就绪。修复原先分开完成可能使新版本编辑过早确认保存的时序；核对控件在检查未完成时禁用。
6. 规划与只读页增加“在此任务与部位下重新采集”。只接受明确任务和已确认支持部位，保留任务、患者侧别、正背面和体位，建立独立采集。旧模型、区域和路线继续保留；需要变更体位时使用第二阶段部位选择流程。
7. 旧记录仍只读打开，即使缺少历史 `selection_support`，当前可用投影也可生成独立诊断显示。检查不写回历史字段，不把当前统计替换为历史结论；原路线报告与当前参考影像检查分开显示。

修改集中在新增 `femto/app/region_quality.py`、`qt_region_quality.py`，以及 `qt_planning_canvas.py`、`qt_planning.py`、`qt_review.py`、`qt_main.py`。采集、标定、W0/RDF、配准、重建、网格映射、路径算法和持久化格式不变。

## 验证

专项 `tests/test_region_quality.py` 覆盖真实射线投影的深度缺失、孔洞、深度冲突、范围外与无源像素，掩膜/标定异常关闭准入，历史禁区与内部留空，取消与迟到结果，编辑/撤销/重做，无支持选区阻断，历史字段只读，以及同任务重新采集。另验证带路线“另存”不能绕过缺失证据检查。

相关回归覆盖 Qt 规划、第二阶段部位记录、GUI 交互、只读版本往返、主窗口导航、第一阶段部位交互与边界。测试均使用临时合成夹具，未把其统计当作真实患者质量。

本轮共 73 项相关测试通过：质量专项 14、Qt 规划 11、部位记录 10、GUI 交互 9、只读版本工作流 6、主窗口 7、部位交互 7、部位边界 9。最终“另存”修改后额外重跑 Qt 规划的 2 项另存测试通过（不重复计入 73 项）。分层检查为 `upward edges: 0`，本轮 7 个 Python 文件语法检查通过。

界面验证输出位于 `outputs/body_surface_phase3/`：`planning_quality.png`、`planning_quality_compact.png`、`review_quality.png`，使用明确标注的测试数据检查色层、内部留空、历史禁区、统计与补扫入口；规划页检查 1280×940 和最小 1120×740 布局，质量面板在侧栏上方，工具可滚动访问。没有相机实采或原生 GPU 验收；完整设备闭环和实物尺度精度仍需单独验证。

本轮不提交 Git，不运行会覆盖合规报告的检查主程序；没有新增依赖、自动人体识别、跨体位配准或治疗执行能力。第一阶段支持范围及 Skill 文件保持不变。

## 医师操作示例

打开当前任务与部位的真实记录 → 在参考图涂抹区域 → 查看一致比例与待检查数 → 定位紫/橙范围并检查具体原因 → 擦除不需要的部分，或在同任务、部位与体位下重新采集 → 新模型重新建立选区并规划 → 核对缺口与路线 → 保存研发预览或待复核草稿。

操作定义见 [部位选择与工作区域](../使用说明/部位选择与工作区域.md)。

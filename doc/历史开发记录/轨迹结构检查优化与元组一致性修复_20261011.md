# 轨迹结构检查优化与元组一致性修复

状态：46 项定向测试、JSON 对照及真实 Qt 保存与两种独立完整回读均通过。

## 改动

`surface_trajectory._forbidden_orientation_keys` 复用同一不可变禁用字段集合，只有字典、列表、元组子容器继续递归，数值、字符串等不再逐个调用检查函数。没有缓存轨迹接纳结论；每次调用仍完整检查当前载荷中的字典键，大小写规则与错误提示保持。

同时修复已复现的元组包装漏检：此前 `{'extra': ({'normal': [0,0,1]},)}` 保存前可通过字段检查，JSON 将元组转换为列表后，独立回读又会拒绝。现在元组与其序列化后的列表采用同一拒绝规则，禁止字段在发布前被拒绝；合法元组仍能正常保存并按 JSON 形式回读。此变化没有增加工具姿态或设备执行能力，`execution_ready=false` / `physical_accuracy_verified=false`。

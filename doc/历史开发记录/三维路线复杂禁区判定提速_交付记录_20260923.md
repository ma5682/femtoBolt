## 实现

- 新增 `femto/planning/surface_polygon_index.py`：每个路由/校验上下文对已验证的多边形建立独立快照，提前生成边端点和每边包围盒。
- 点内判断向量化原来的射线奇偶判断，保留严格 `>` / `<` 及相同乘、减、除、加顺序。不是换用另一个几何库的边界定义。
- 线段相交先批量执行原包围盒排除公式，剩余候选仍按原顺序执行相同的标量叉积谓词。原 `1e-9` 包围盒容差与 `1e-12` 乘积比较不变。
- `SurfaceLinks`、`BoundaryTurns` 使用预处理结果；`BoundaryTurns.diagnose` 临时将禁区替换为空列表、再恢复时都会重建索引，不能沿用错误禁区状态。缓存不跨规划调用，也不跨校验读取。
- `SurfaceLinks._state` 复用已经算过的两个投影，再执行原逐像素 `segment_pixels` 超覆盖检查，避免再次投影。未选像素、图像外与禁区状态的判定优先级不变。
- `selection_blocks._check_selection_binding` 每次回读验证创建独立索引，每条 connector 边照常验证。没有删减结构、哈希、来源、三角面支持、统计或投影校验。

本次是等价判定加速，不改变算法版本（仍为 v4.2）、A* 搜索、候选点、扫描 XYZ、行距、步长、所有门限、schema、固定 JSON 键、CSV 列或文件名。120 秒任务预算、20 万采样及各类面内搜索预算原样保留；不靠少采样、跨禁区、跳验证或延长超时提速。无新增依赖。

W0/RDF/米、原始采集/网格/选区不可变，`execution_ready=false`、`physical_accuracy_verified=false`、`orientation_fields=null`、旧结果完成/清理规则均不变。

# 覆盖预算遗留优化 v4 与复算集合保留

本轮继续落实 V1.0 方案的 P2 覆盖核验、P3 补充规划及 P4 性能约束：减少补线后尚未重新分类的预算遗留，并补齐同一输入的 P2 复算接纳检查。原目标、已确认集合和各项计算预算仍分别核对。

最终产品全流程、三次新旧策略对照、十二份数值停止边界回放和正式六项检查均通过；最终源码与资产核对记录在 `final_audit.json`。

## 实现与约束

- 默认固定模型 P3 使用 `residual-partition-anchor-ball-coverage-v4`，报告为 `femto-coverage-refinement-v4`。旧 `retained-partition-anchor-ball-coverage-v3` 源文件保留原字节，旧保存包仍按其原策略回放。P2 算法仍为 `layered-anchor-ball-subedge-coverage-v2`。
- 前一轮只提供完整分区和候选证明路径。每轮重新绑定当前种子、构造当前根、核验原确认叶的球包含和正长度公共子边；先检查新锚点前缀，再分类当前源面、像素组、根与子叶，继续搜索新增扫描邻域。
- 含已确认叶的根中，其余未知子叶也参与重新分类。只有当前组／根的候选球检查完整结束后，排除结果才能用于子叶。子叶遇到可能相交的球可以停止范围外搜索，但仍保持未知；只有全部必要球都排除后才标为球外。
- 当前精确根顶点区间通过逐运算向外舍入的四叉系数生成子叶区间；模糊包含仍构造精确叶回退。新扫描使用齐次整数几何；同源面的公共顶点及严格共线同向边只作为正长度公共子边的充分判据，其余执行原精确检查。新增根顶点缓存最多 4,096 项，以弱引用避免循环。
- 组／根／子叶的实际分类比较计入原累计预算，批量中断不安装未完成的分类。新增 `coverage.residual_recheck` 诊断阶段。普通 v3／v4 路线的已验证摘要直接用于标签，界面刷新不再重复路线反序列化和几何核验。
- 同一方案重新核验 P2 时，安装前比较完整原确认集合。候选只要有任何丢失权重就拒绝安装，保留原覆盖及显示；原证据不拼入新候选。核对原目标、路线、种子及作用模型绑定，缺失资产或取消不能绕过。诊断阶段为 `coverage.recalculation_admission`。
- 基准保留每个 P2 原始候选，并单列接纳状态和实际选定结果。P3 三次固定使用第一次接纳后选定的证据；候选被拒绝时使用原已验证证据，不能把较小的候选集当作新基线。固定引导独立保存。

预算继续为完整操作 120 秒、工作台 P2 核心 30 秒、P3 每轮覆盖 4 秒；P3 两轮、每轮四候选、累计比较／邻接／证明各 1,000,000、新增边检查和输出点各 200,000、总新增长度 0.1 m、新增扫描见证门槛 0.1 mm²。缓存与批量计算没有扩大原几何和资产限额。完整实现见 [复算与诊断契约](../技术资料/覆盖复算调度与持久诊断契约.md)，操作见 [重复验收与失败诊断](../使用说明/覆盖性能重复验收与失败诊断.md)。

## 开发过程与不足结果

上一轮 P3 遗留的 585.217 mm² 中，有 457.693 mm² 原先在 P2 已分类为球外，补线后因未及时重新核验而回到预算未知。含原确认叶的根内还遗留 52,519 叶、203.920 mm²。这些仅用于定位调度问题，不能直接把旧球外分类装成新结论；分析保存在 `residual_analysis.json`。

`probe_01`、`probe_02`、`profile_01`、`fixed_probe_02` 至 `fixed_probe_05` 及 `numerical_probe` 保留开发对照；四叉层级分类试验的开销更高，撤回该实现并保留结果。`repeat_final`、`paired_legacy_final` 和 `numerical_replay_final` 使用摘要显示修复前的代码，不作为最终源码验收。

`product_final`、`repeat_verified`、`paired_legacy_verified` 是随后一轮结果。审计发现 `repeat_verified` 的三次独立 P2 候选相对原已保存 P2 集合分别少了 10,445,824／7,512,064／15,433,728 权重，即 17.221626／12.359422／24.333447 mm²。旧工具虽然返回 `all_checks_passed=true`，但只检查了 P3 接纳，没有据此拒绝更小的 P2 候选。该缺口触发本轮安装检查和基准接纳语义修正；上述原始结果继续保留，不能作为“原集合全保留”的最终验收。

新增复算测试的第一次运行有 1 项 Qt 检查失败：测试在初次质量检查完成前设置人工核对，随后正常质量回调清除了核对状态。测试改为等待实际质量检查完成后再设置核对，8 项均通过；没有修改生产质量门禁或既有测试断言。

## 检查结论与修改

- 已实现：方向与起点、禁区/孔洞/可信几何约束、整个模拟包络复核、分链播放、版本和覆盖报告关联。
- 部分实现：已有扫描/连接长度和时间，但缺少精确重复经过、急转点及优化前后对照。
- 此前未实现：通过覆盖逐点非退化门禁的扫描顺序/连接优化、可定位急转点、候选超限或拒绝的质量说明。
- 新增 route_optimization.py：先构建已验证v3基线，在每条原链的认证边图上运行三种确定性候选。原扫描顺序的米制连接、最近扫描端点重排、重排后保留原覆盖支持边。仅使用原边，不添加空间捷径，不合并断链，保留起终点和全部扫描边重数。
- 候选总长必须下降，扫描长度/链数不变，连接和精确重复长度不得增加；再次完整包络复核不得剔除任何边，分母/样本身份保持相同，每一个原已覆盖点必须仍覆盖。没有合格改善则保留基线，不掩盖失败或退化。
- 新增 route_quality.py：精确无向边额外经过长度/次数、急转点阈值≥60°、before/after及候选结果。路线窗口支持急转点开关、质量报告和点击急转点暂停定位。总览超过12条链时省略拥挤文字，保留起终点标记，编号可逐链查看；小图适度放大供查看。
- 界面新生成使用 serpentine_v4 / serpentine-v4；旧v1/v2/v3回读保留。route_quality纳入版本结果指纹，工程、播放、覆盖、JSON/CSV/PNG和静态GLB使用同一方案。分享新增route_quality.json/txt、sharp_turns.csv并记录文件哈希。
- 本批没有增加平滑，只检测和标注急转角；smoothing.applied=false，保持经过验证的折线，不引入未经验证的曲线、加速度或接触姿态。

## 操作、预算与限制

单选区域 → 生成覆盖路线 → 保持/选择参数 → 路线窗口“路线质量/急转角” → 查看前后指标及候选拒绝原因 → 点击急转点定位 → 保存方案或导出分享包。没有改善时也会生成新版质量报告，明确保留原折线；旧版工程不静默改写。

搜索最多3种候选、累计200万展开（包括支持边恢复）、每链512扫描段、候选20万点；沿用120秒任务及60MB方案明细上限。搜索超限停止并保留已核验结果；取消/外层任务超时不提交新结果。候选可能比基线耗时更多，本批没有承诺最优路径或全场景加速。

精确重复只计完全相同无向XYZ边的额外经过，不是附近扫描带重叠。覆盖仍是每面3点面积加权估计；包络检查保守、可见性为端点/中点检查，不是连续接触或机械臂执行验证。急转阈值是弦段方向变化，不是动力学安全阈值。无新增实物精度或临床验证。原RGB/Depth、标定、Pose、模型、历史方案、W0/RDF/米和测量/展示分离保留。

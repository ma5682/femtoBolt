# 精确像素分区核验：实现与验证

本轮用户选择继续减少未确认范围。代码实现、真实工程分区重算与覆盖复算、原生及便携保存/回读、最终联合回归和交付核对均已完成。

## 问题与实现

完整分块台账的139148个选区像素中，数值未确认26589，部分定位40311，缺面24。逐像素阶段探针发现26589个数值未确认均在最终投影面积求和超界判断出现；各抽查200个数值和部分定位像素，精确分区面积均为1。证据：`outputs/target_uncertainty_diagnosis_20261015/`。抽查不是全量证明。

保留原 `reference-pixel-clipping-v1` 的浮点裁剪和完整回放，显式新增 `reference-pixel-exact-partition-v2`。新版本对实际可见源面的规范二进制顶点、内参做精确投影，在正有理数像素格边界裁剪；严格证明投影内部不相交后，精确面积为1才认定整格已定位，介于0和1则保留部分定位，不能证明则保持数值未确认。重叠加缺口即使面积相抵为1也不认定完整；深度范围、10毫米参考一致性、原遮挡检查、质量排除和物理精度状态保持。

为减少有理数裁剪重复，添加等价快捷证明：可见源面组合的边界不与像素格开内部相交，且格中心严格位于该组合内时，内部成员关系恒定，完整格可获证。所有边界排除与中心包含均是精确有理数比较，不能排除则回退逐面裁剪面积。源投影/分离关系与最多16面组合的缓存各4096项，密集组合绕过缓存；逐像素原配对预算仍计数，检查取消，不缓存判定结果跨请求复用。累计资产按与普通续算相同的规则，在每一块完成后立即检查512 MiB上限，不等所有块结束才检查。

工作台在未定位范围检查中提供显式入口。后台冻结输入，按原每块20万单元/45秒限额计算，累计资产与操作限额保持。完成才安装新计划并清除旧覆盖显示；失败/取消保留原方案。新计算修订仅改变目标算法，因此产生新目标ID；所有采集和选择依赖、路线点与参数保持。旧方案、旧目标及旧覆盖资产在新结果`previous/`保存，新台账须重新核验覆盖。严格、变宽和补充版本生成时显式沿用基底目标算法；原历史算法仍独立回放。

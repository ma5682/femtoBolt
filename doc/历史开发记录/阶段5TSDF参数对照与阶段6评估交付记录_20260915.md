## 2. 预算、状态与数据格式

| 项目 | 实际实现 |
|---|---|
| 参数组数量 | 最多 8 组，参数有限值检查，不接受重复组合 |
| 只读汇总总时限 | 默认 300 s，文件/分块边界检查取消与超时 |
| 新研究总时限 | 默认 1800 s；剩余时间传入最终汇总 |
| 新比较子阶段 | 默认 300 s / 3072 MiB；复用已有进程组限制；一次最多 1 个子阶段 |
| JSON | 每文件最多 32 MiB；累计读取最多 64 MiB |
| 哈希读取 | 累计最多 16 GiB；1 MiB 分块；单来源指纹最多 50,000 文件 |
| 图片 | 每张最多 16 MiB；必须符合记录的 PNG 尺寸；固定投影最多 8,388,608 像素 |
| 保存 | 新任务目录内更新任务状态；原报告不修改；输入预检失败不创建任务结果目录 |
| 取消 | CLI `--cancel-file` 或后台回调；已启动任务保存取消状态，后续候选不启动；不发布 latest |

没有虚构百分比。原子更新的新任务 JSON 只包含当前任务 ID、实际阶段和完成数量。新研究中已有子阶段进程的退出由原比较器负责，汇总只做有界文件操作。

新增格式 `femto-local-parameter-study-v1`：

- 顶层记录 `coordinate_frame=world_rdf`、`unit=metre`、`transform_direction=T_W0_Ct`、源帧/采用帧、W0 证明、源文件/实现指纹；汇总器及来源分类模块另存 `summarizer_sha256`。
- 每个版本 `geometry_input_sha256` 来自帧 ID、RGB/Depth SHA、米制 `T_W0_Ct` 矩阵及实际 Mask SHA 的规范化列表；它不是模型几何指纹的替代品。
- `comparison_elapsed_s` 为原任务报告耗时，包含校验、优化尝试、重建/复用和评估。`audit_elapsed_s` 为本次只读汇总耗时。外层 CLI wall time 保留在原试验运行清单中，三者不混用。
- `peak_job_committed_mb` 取各串行子阶段峰值的最大值，不相加，也不把 RSS 当作提交内存。缺少完整测量记录时为 null。
- 几何 RMS 用各帧样本数加权合并。只合并 RMS，不从分帧 P95 伪造总体 P95。
- 深度指标分别保存“有命中的 RMS”和“缺失命中按零深度计的 RMS”；缺失命中仍计入后者分母。有效像素比例独立保存。
- `extent_change_vs_5mm.absolute_mm` 是同一 W0 轴对齐包围盒的毫米差值，不是物体真实尺寸误差；零基线尺度的百分比为 null。
- `noise`、`ghosting`、`roi_hole_filling` 和 `physical_accuracy` 本批均为未评估；没有参考时不填 PASS 或 0 误差。
- 完整度不足的研究返回 `incomplete`，CLI 退出码为 2；这是对未完成候选的真实表达，不计作全部试验成功。单元测试是独立的软件测试统计。

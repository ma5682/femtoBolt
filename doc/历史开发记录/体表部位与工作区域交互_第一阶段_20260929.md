## 检查结论

已证实：

- 本工作区拥有独立 `.venv`，实际运行 Python 3.12.10、PySide6 / Qt 6.11.2。分层检查 `upward edges: 0`。
- 正式入口为 `femto.app.qt_main`。`CapturePage` 负责采集和历史模型回放，`PlanningPage` 使用固定 RGB 图像上的像素掩膜，调用已有区域映射与表面路线后端；三维检查通过 `ScenePanel`。
- 原部位选择仅为可选自由文本。任务标签通过 `task_context.json` 和区域工程传递，不是患者身份绑定；没有已实现的全身解剖定位或患者部位到历史记录的自动索引。
- 已有区域意图支持多个组件和内部未选孔洞，因此新标记可以只使用工作区域涂抹与擦除。
- 原 Qt 页面允许只画禁区进入下一步，`extract_region()` 随后采用 `full_minus_forbidden`，可能把其余整幅画面选入；修改笔画后原区域统计仍被展示。两者都容易让医师误解当前选择。
- 现有后台任务、几何绑定、草稿与历史恢复链继续复用，不替换采集、配准、融合和路径算法。

待验证：当前设备实采、跟踪丢失后的实机行为、患者运动对刚性配准的影响、原生 VTK/GPU 渲染。本轮离屏与合成数据测试不证明这些行为或临床精度。

## 本次实现

1. 新建采集增加“选择人体部位”对话框。可点击人体分区或使用列表，选择部位、患者左/右/双侧/中部、正背面和体位，并显式确认。正面示意图左侧对应患者右侧，背面则对应患者左侧。切换任何字段都会撤销本次确认。背面躯干显示上背部、腰背部、骶臀部。
2. 示意图只用于导航，采集范围明确为当前可见体表，不冒充患者实测几何。体位变化提示新建采集、重新标记。
3. `femto-ui-task-v1` 可选新增 `body_selection` 字段，旧任务没有该字段时保持原格式并显示待确认。校验枚举、确认状态和部位文本一致性；手工修改部位文本后撤销结构化确认。信息随现有采集派生标签和 `.region.zip` 保存恢复；历史记录不能直接改部位。原始 RGB-D 不变。
4. 根据用户本轮明确要求取消独立禁区工具。新建区域仅有“涂抹工作区域 / 擦除”，可在内部留空，亦可选择多个分离区域。必须存在显式工作区域才能进入规划；不通过 GUI 隐式选择整幅画面。既有后端格式和旧工程兼容能力保留。
5. 历史禁区继续红色显示并参与扣除，界面说明其来源。“清空工作区域”、涂抹与擦除均不移除历史禁区；清空可撤销。历史方案不会因取消按钮而扩大范围。
6. 规划页与只读回看显示任务部位、体位和来源。规划页保留未绑定病例及 W0 / RDF / m；空数据有操作提示，修改选区后显示“三维支持待检查”，不继续展示旧统计。加载中或失败时，新增部位状态提示显示读取中或待核验，不沿用上一条记录的已确认部位。

没有新增运行时依赖。没有修改跟踪阈值、几何映射、路径算法、源模型、设备参数、`execution_ready=false` 或 `physical_accuracy_verified=false`。

## 医师操作示例与后续建议

新建采集 → 选择“患者左侧 / 大腿 / 背面 / 俯卧”并确认 → 采集该部位真实 RGB-D → 检查模型 → 在参考图上涂抹工作范围，用擦除留出不处理部分 → 检查几何支持 → 计算并核对路线 → 保存研发规划 → 从历史恢复相同部位与体位信息。

后续建议：建立病例/采集与部位的显式索引后，再做全身覆盖导航和按部位打开历史真实影像；姿态模型候选应允许人工修正。当前版本没有自动人体部位识别、跨体位配准、全身覆盖保证或治疗执行能力。

## 本轮产品边界修正（2026-09-29）

检查实际 `REGIONS`、`BodyNavigator.cells()` 和列表构建，证实原实现头、颈、足可被确认；手部仅有 `hand`，缺少肩、肘、腕、膝。采集页原来不要求已确认部位，单独禁用图示按钮不能阻断旧值或手工文本绕过。

本轮只修正部位导航与新建准入：

- 增加肩部、腰部、髋部、肘部、腕部、手背、手掌、膝部；新建白名单包含肩部、胸部、腹部、腰部、上背部 / 腰背部、臀部 / 髋部、上臂、肘部、前臂、腕部、手背、手掌、大腿、膝部、小腿。沿用既有正背面显示规则，胸部 / 腹部在背面显示上背部 / 腰背部，髋部在背面显示臀部。
- 头、颈和双足轮廓保留置灰；对应列表项禁用。点击不会形成确认，明确说明头部、面部、颅颈精细区域、足部、脚趾暂不支持。
- 点击手部提供腕部 / 手背 / 手掌三个二级按钮，也可直接从列表选择。没有新增手指、指尖、指缝或单指关节选项。
- 新建局部采集须确认支持部位；开始按钮与直接开始回调都检查。手工改文本须重新确认，不从自由文本推定支持能力。相机、RGB-D 帧准入、跟踪、重建等后台采集逻辑未改动。

- W0、RDF、单位、坐标、几何映射、路径算法、重建、历史 schema 与键结构保持不变。未增加自动识别、VTK 接入、机械臂或治疗执行功能。

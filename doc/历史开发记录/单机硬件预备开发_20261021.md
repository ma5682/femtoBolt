| 确实缺少 | 配置、适配协议、模拟设备、运行状态机、协调器、事件库、产品入口 | 新增 hardware/simulation 与 execution，Qt 页面接入当前窗口 |

依赖为 app → execution → hardware / capture / planning / geometry / dataset；execution 登记在 capture 之后、app 之前。硬件层不理解规划任务，根级存储不导入 execution。模拟协议只代表软件调度，所有新产物固定 `execution_ready=false`、`physical_accuracy_verified=false`。

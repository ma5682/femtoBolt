准备缓存按当前可用内存和任务规模有界配置，预留至少 2 GiB 或总量的 1/8，候选输入缓存最多 16,384 项、每项最多 128 个候选；低余量关闭缓存，未知资源保守保持原上限。文件摘要缓冲按文件规模及可用内存为最多 64 KiB 或 1 MiB。原生/便携资产清单同时考虑进程 CPU affinity、资产数量/总字节和内存余量，最多两个独立摘要工作线程，低余量/小任务/未知条件单线程。预算/取消回调只在调用方运行，失败会停止并等待工作线程，不交付部分摘要。系统预留是策略，不是操作系统硬性保留。

Windows 查询使用静态 ctypes 类型和一项惰性 API 绑定，保持实时读取，40 次重复查询不再增长类型缓存；成功父阶段释放已处理预算异常引用，避免继续保留旧计算对象。构造用例的缓存项数与弱引用回收不换算成完整应用 RAM 节省。资源与诊断公共接口、只读摘要结果和保存回调补齐类型；资源查询和清单摘要从维护热点中分离。未新增第三方依赖和顶层 Torch/OpenCV 导入。

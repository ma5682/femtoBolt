# 实时补采预览开发交付记录

2026-09-14，第二轮开发。用户明确优先“边补采边更新三维预览”。

## 已交付

- 开始本次采集后默认显示累计预览。首个有效参考帧出现后，每次通过门禁的停稳补采都会更新累计点云。
- 可切换当前RGB、深度、初始点云、累计预览与最终融合点云。拖动支持水平及垂直旋转，滚轮缩放，“复位视角”适配整体范围。
- 可打开/关闭最新补采帧新增采样体素的绿色高亮。界面显示预览已处理/已接纳帧数和点数，不将其称作目标覆盖率或补洞率。
- 预览后台只读取已经保存并接纳的RGB-D与同帧位姿；与SDK读取、位姿跟踪、最终模型和标记相互独立。失败单独提示，不伪造有效模型。
- 参数：原始深度最近邻、像素步长4、5mm采样体素、最多120000点、屏幕最多30000点。上限只作用于预览，不减少最终重建输入。
- 新增 `derived/live_preview_report.json`，记录坐标约定、源帧、更新时延和预算状态。
- 修复短提示被连续位姿事件覆盖、正常重建时误报跟踪过期，以及新会话预览构图残留。

## 试用

重启 `start_femto_app.cmd` → 建立原点 → 小幅移动并停稳 → 补采一帧 → 在累计预览中检查新采样点 → 至少3个有效不同视角后结束重建 → 打开最终模型进行标记。

预览为稀疏采样，不是最终TSDF网格。新增采样体素可能来自视角变化、噪声或原先未见表面，不能保证它们全部是正确补洞。当前仍没有自动重定位、实时TSDF网格和跨会话续补。

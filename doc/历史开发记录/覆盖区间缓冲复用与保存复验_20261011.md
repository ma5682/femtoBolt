# 覆盖区间缓冲复用与保存复验

日期：2026-10-11。对应固定真实方案性能复验后的首项计算优化。证据独立保存在 `outputs/save_optimization_20261011/`，原输入和历史失败记录保留。

## 实现

生产改动仅 `femto/geometry/exact_surface.py` 的 `_ball_intervals`：平方下/上界复用本次新分配的绝对距离缓冲，三个轴的累加继续按原顺序执行，每次加法后立即执行原方向的 `nextafter`，低界仍逐次截到零。半径平方计算一次，分别生成内/外舍入结果。

只对本次私有临时数组使用 NumPy `out=`；源三角形界、种子中心界、半径和只读/共享视图不修改，没有跨叶、跨请求缓存，也不保存任何确认结果。精确有理数回退、算法/证书版本、访问顺序、计数与停止点、120 秒操作预算和 P2 核心预算均保持。

另一个外包距离缓冲复用尝试在小批次微测中变慢，已撤回，最终该函数恢复原实现。不能把所有减少分配的改法都视为有效加速。

## 实际 Qt 保存

同一真实源工程完整打开耗时 88.670 秒。三次 Qt 保存分别为：118.942 秒成功、119.287 秒成功、121.761 秒预算退出。前两份便携工程的方案及全部登记资产摘要核对通过；第三次已发布原生包，便携工程未完成。三次均直接核对当前方案对象/内容、原目标数组及覆盖摘要保留。

两次成功都距原 120 秒预算边界不足约 1.1 秒，因此三次成功的稳定保存验收仍未通过。不能将历史三次失败与本轮两次成功解释为已消除超时，也不能将失败结束时间计算为成功保存中位数。系统资源没有匹配控制，打开阶段系统可用内存采样曾记录为零，保存期间最低不足 1 MiB；只作为资源观察，未关闭用户程序或调整系统配置。

成功保存的阶段诊断包含原生保存约 75 秒、便携保存约 24 秒，完整证明评估/回放仍是主要计算工作；便携压缩约 1.2 秒。阶段有包含关系，不能相加当作总耗时，也不能据单一阶段推断独占原因。

两份成功便携包独立完整回读分别 90.764、108.427 秒，三份原生包完整重现分别 108.932、106.675、101.667 秒，全部通过。回读核对完整路线、原目标数组、最终覆盖及历史证明，第三次预算退出后的原生包同样完整核验。失败记录与已发布资产保留，临时便携资产按原保存流程清理。

成功保存两次中位 119.114 秒；便携读取只有两次，不记为“三次读取验收完成”。整个三次保存/便携回读验收状态为失败，两类包的有效性验证结果单独记录。没有将本轮读取时间与不同资源条件的历史读取时间计算加速比。

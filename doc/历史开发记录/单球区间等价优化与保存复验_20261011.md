# 单球区间等价优化与保存复验

当前状态：数值与真实证明重放对照通过；三次完整 Qt 保存均在原 120 秒预算处退出，三份已发布原生包的独立完整回读均通过，定向回归已完成。本轮不宣称保存稳定性问题已解决。

## 实现范围

仅优化 `femto/geometry/exact_surface.py` 的单球/三角形区间判定。普通 float64 数组、一个球、三个顶点且输入及中间值有限时，采用 Python float 与 `math.nextafter`，保持三个轴逐次加法、每步定向舍入和低界截零。避免为极小批次分配多组 NumPy 临时数组；不修改来源数组，不缓存几何接纳结论。

其他形状、批次、dtype、数组子类和异常/溢出数据保留原 NumPy 路径。模糊包含仍由原有精确有理数判定处理，版本、拓扑、预算扣减、取消检查和保存 frontier 保持。

## 已验证

- 独立原型 240 组对照通过，40 组极端值回到向量路径。

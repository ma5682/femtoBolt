# 局部补采下一阶段：五帧稳定性筛选

已实现并接入 local_capture.py 的结束处理，执行顺序为在线Pose导出 → 保守精配准 → 五帧稳定性筛选 → 现有重建。没有新增相机SDK读取线程，也没有改变在线跟踪/接纳节奏；复用已落盘的完整跟踪帧，计算在结束后的工作线程执行。

## 功能与边界

local_temporal_support.py 查找包含选中关键帧的连续五帧窗口。需全部跟踪可信、同参考系，时间递增且相邻不超过1秒、总跨度不超过4秒，双时间戳同步不超过5ms；与选中帧相比位移≤1mm、旋转≤0.2°。然后复用 scene_temporal_fusion.audit_temporal_motion，要求可靠固定背景流≤1px；RGB差超过35的局部区域扩张1像素后拒绝。

在通过审核的窗口内，每个选中帧有效深度像素必须至少获得4/5个观测在10mm内支持；不平均、不取另一帧的中值、不创建新深度。其余像素通过独立二值Mask排除。视角保留不足80%则本轮不应用Mask，沿用原观测并记录原因。这个回退是未实施筛选，不表示原数据已通过稳定性验证。

无稳定窗口或图像运动审核失败也不应用筛选。精配准失败接纳和五帧筛选失败分别记录；两者均不是物理精度门禁。人体呼吸/变形、低纹理、反光表面可能没有足够稳定证据。

TSDF在原彩色相机对齐网格上应用Mask再去畸变；local_geometry.py以同一Mask限制网格支持证据。初始对照点云仍保留原始参考帧。保留像素数值、相机Pose与W0不变；最终几何如有变化仍生成新结果，旧标记不能跨模型直接迁移。

本轮未接入深度均值/中值替换，未引入连续confidence的TSDF加权，未做位姿图、自动补洞或3DGS训练。二值拒绝不等于重复积分五次，多帧不会因为提供支持而增加该视角权重。

## 来源与产物

派生路径：本次会话 derived/temporal_support_<ID>/。报告为 temporal_support_report.json，成功应用的视角有 support_<frame>.png；应用至少一帧后输出独立 dataset/。RGB/Depth继续指向原始文件，Pose/标定复制不改值，frames.jsonl追加Mask路径/哈希/来源帧。既有参考来源、模型哈希与标记回读检查保留。

源校验包括读取过的原始索引/跟踪记录、标定与图像哈希，双时间戳对照，以及选中RGB-D与对应原始记录内容一致。Mask加载时核对SHA-256、尺寸、uint8与0/255取值。篡改或尺寸错误阻断，不能静默取消Mask继续融合。

## 操作

重启主程序，每次补采前后停稳约3秒，结束时自动审核。3秒仅为操作建议，不保证五帧或审核通过。可从历史记录打开原始会话目录，在 derived/temporal_support_* 中查看报告。

独立回放命令（输出必须为全新目录）：

    .venv\Scripts\python.exe -X utf8 local_temporal_support.py <局部派生数据集> <全新输出目录>

回放只生成筛选报告与派生输入，不自动更新最新模型索引。

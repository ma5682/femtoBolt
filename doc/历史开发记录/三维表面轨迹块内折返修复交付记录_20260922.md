# 三维表面轨迹块内换行折返修复交付记录

> 日期：2026-09-22
>
> 基线：分块规划提交 `2fda79a`

## 问题

用户在真实区域 `20260921_152402_8415cde6` 上生成分块结果：139 行、14 个可规划块，块内应连接换行 125 处，实际贴面折返 48 处，77 处仍是 `row_turn` gap。对 77 处逐个复跑折返路由后分类：64 处两行在块 e2 轴上不相邻（行序按参考图像 `mean_v` 排，切片顺序被打乱，根本没进入折返尝试），13 处边界带内无路径。

## 改动（只针对同块 `row_turn`，不改其他 gap 语义）

1. **块内排序改为块自身扫描坐标**（`mesh_slice_planner._order_rows_by_frame`）：行按切片位置（e2 投影）排序，同值按 `slice_index`；行内扫描段按 e1 投影均值排序，同值按最小 `triangle_index`；奇偶行蛇形反向；段内点按 e1 方向定向。参考图像只在块原点处判定 e1/e2 与像素 u/v 的符号，用来解释 `start_corner` 的"上/下、左/右"，不再参与任何排序或 tie-break。v1/v2 路径保留原 `_order_rows`，输出逐字节不变。
2. **换行失败诊断字段**：块模式下未连接的 `row_turn` gap 在 `detail.row_turn_failure_reason` 记录 `non_adjacent_slice` / `endpoint_not_on_boundary` / `forbidden_blocked` / `ambiguous_boundary` / `no_boundary_path_in_band`（`BoundaryTurns.diagnose` 依次放宽禁区、歧义顶点重试判定）。`decision_use` 仍为 `none`，字段只在块模式 `row_turn` 上允许，其他情况校验拒绝。`gap_report.row_turn_failure_counts`、每块 `row_turn_failure_counts`、`gaps.csv` 新列 `row_turn_failure_reason`、报告逐块列出。
3. **表面行距报告口径**：保留 `distribution`（原始）并新增 `raw_spacing_statistics`、`effective_spacing_statistics`（排除 > 2× 名义行距的样本）、`spacing_outlier_threshold_mm`、`spacing_outlier_count`、`spacing_outlier_ratio`；报告分两行写明异常样本是跨孔洞/缺面的图最短路上界，不是排行间距。
4. 附带修正一处数值容差：切片端点落在共享边界顶点时，两三角面的交点相差约 2e-8 m，原 1e-8 m 的边界吸附容差会把它判为"不在边界上"。块模式把吸附容差设为 1e-7 m（与拼链量化 1e-7 一致）；v2 `connect_row_turns` 保持 1e-8，旧 v2 文件重算不变。这是浮点识别容差，不是折返几何门限。
5. 算法版本 `mesh-slice-serpentine-v3` → `mesh-slice-serpentine-v3.1`。旧 v3 文件仍可读取、核验哈希和播放（`reproduce=False`），但 `load_trajectory` 重算时明确报"旧算法版本，请重新生成"，不会被重新解释。

未改：分块规则、`surface_gap` / `disconnected_surface` / `forbidden_region` 判定、PCA 与冻结阈值、采样步长、折返几何门限（只走真实边界边、禁区整边检查、歧义顶点拒绝、e2 带状限制）、Mesh、W0、trajectory schema 主结构。未加第二层"边缘附近表面折返"。

# 模拟联调五项交互修复（2026-10-22）

依据[硬件预备开发提示词](../技术资料/单机上位机硬件预备开发提示词_20261021.md)及本轮 Qt 操作复现，修复五处模拟页面交互问题。当前状态与记录语义保持，新增行为在界面层和其串行所有者中实现。

## 已实施的变化

| 问题 | 修复后行为 |
| --- | --- |
| 运行中一键关闭实例，把正常任务变成停止未知 | 检查、就绪、运行、暂停和停止等待期间禁用关闭，后台也拒绝在途关闭。实例关闭放在“实例与记录恢复”，关联任务时确认后果；取消保留实例，确认不修改旧结果 |
| 只读历史页创建了新任务，却继续显示旧记录 | 显式选择方案、连接或冻结切回监控顶部；状态条显示当前任务 ID，完整 ID 可悬停查看。新连接使迟到回看失效，旧记录继续只读 |
| 未连接就检查，失败后必须重建任务 | 页面仅在已冻结且全部参与设备已连接时允许检查，后台也检查连接顺序。被阻止的提前检查不写失败任务；连接后仍用原任务检查 |
| 心跳使设备详情滚回顶部并丢失文字选择 | 设备绑定保持时只更新变化的文本字段，保留滚动和选择；Qt 游标跟随前方文本长度变化。新绑定重新建立显示上下文 |
| 已就绪或正在运行时，底部仍要求连接设备 | 根据当前快照更新冻结、连接、检查、运行、暂停、继续和停止提示。首个方案读取失败保留具体错误，普通心跳不覆盖完成后的导出通知 |

普通停止继续等待参与设备分别确认静止与输出关闭。异常实例关闭不构成停止确认：未知结果保持未知，正常停止结果保持已停止。已有失败任务不重新解释为成功，修正原因后建立新任务。

## 实际文件与范围

- `femto/app/qt_execution.py`：设备详情增量显示、按钮与命令入口保护、关闭确认、历史/当前视图切换、任务身份与阶段提示。
- `femto/app/qt_main.py`：切换项目时直接提示“请求停止并等待结果”，不要求先暂停。
- `tests/test_qt_execution_workflow.py`：八项新增行为回归。
- 操作说明、原提示词补充验收、技术基线、文档索引及当月记录同步更新。

工作区同时存在主题、SVG 图标和滚动容器的并行修改，本轮保留这些修改；返回当前监控时同时复位外层滚动位置，设备详情内部的阅读位置仍保留。本轮没有修改模拟适配协议、`execution` 状态迁移、数据库格式、几何算法、来源核验或原始采集文件。

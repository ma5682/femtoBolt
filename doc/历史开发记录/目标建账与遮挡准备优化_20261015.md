# 目标建账与遮挡准备优化

日期：2026-10-15。

## 实现

- `_candidate_groups()`：稳定排序后直接识别分组边界，省去 `np.unique(return_index=True)` 的再次排序，保持像素和源面顺序。
- `_clip_pixel_polygons()`：同一像素复用四个裁剪平面。
- `clip_triangle_planes()`：先执行原误差检查及有理数回退；完全在内侧时复用顶点，完全在外侧时返回空结果。
- `_source_separation()`：单次构造缓存最多4,096个只读源面投影，供不同面对应复用。原4,096对分离缓存、逐像素成对计数和遮挡检查保持。

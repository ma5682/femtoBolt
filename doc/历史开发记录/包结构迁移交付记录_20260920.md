## 阶段 B：拆循环依赖

由 `tools/_restructure_layers.py` 自动完成（支持 `--dry` 预检）。迁移前按同一分层口径统计为 7 个强连通簇、21 条"下层 import 上层"的边（全部是函数内延迟 import）。处理办法是把放错层的纯函数搬到它真正所属的下层，源文本逐字保留，调用点通过 `from 新模块 import 名字 as 旧名字` 保持不变：

| 符号 | 原位置 | 新位置 | 理由 |
|---|---|---|---|
| `depth_cloud` | `capture.scene_segmented_capture` | `geometry.depth_cloud` | K6 反投影是几何原语，被 geometry / temporal / app 共用 |
| `distortion_maps` / `prepare_rgbd` / `load_poses` | `geometry.scene_reconstruction`（原带下划线） | `geometry.rgbd_frames` | tracking / local / annotation 只需要这三个原语，不需要整个 TSDF 编排 |
| `pose_diversity` | `pipeline.scene_to_nerfstudio` | `tracking.moving_quality` | 纯位姿跨度数学，tracking / local / capture 都在用 |
| `load_temporal_confidence` / `prepared_depth` | `temporal.temporal_keyframe` | `depth.temporal_depth_layer` | 只读时域置信度，属深度中间层；路径安全改用 `femto.paths.child_path` |
| `LOCAL_RADIUS_M` / `LOCAL_ROTATION_DEG` / `local_workspace` | `capture.local_capture` | `tracking.local_frame_selection` | 采集包络是视角接纳策略 |
| `write_calibration` | `capture.scene_capture` | `dataset.calibration_files` | 标定文件集属数据集 schema，与 `local_reference.CALIBRATION_FILES` 同层 |
| `validate_exclusions` | `planning.region_exclusions` | `annotation.scene_annotations` | 禁区多边形校验是标注契约的一部分 |
| `resolve_source` | `gsplat.scene_single_gs` | `dataset.single_frame_source` | 只做 schema 校验，`reconstruction_sources` 不应依赖 gsplat |
| `ActiveScan`、`save_scan_frame`、`finalize_scan`、`save_rgbd_photo`、`copy_frame`、`unique_timestamp_dir`、`wait_for_aligned_frame`、运动提示状态机与 4 个常量 | `app.femto_control_app` | `capture.scan_session` | 采集工作线程不能 import 应用；主界面由 2007 行减到约 1700 行 |

模块归层调整：`scene_reconstruction`（TSDF 编排，依赖 depth / dataset / geometry / temporal / local）、`local_comparison*`、`local_parameter_study`、`local_history` 移入 `femto.pipeline`；`local_geometry`、`local_processing` 移入 `femto.local`。层顺序把 `annotation` 提到 `tracking` 之前、`capture` 放到 `gsplat` 之后（采集线程在结束时启动离线 Job，本来就是最上层的调用者）。

兼容性：`femto_control_app` 与 `temporal_keyframe`、`scene_single_gs`、`scene_capture`、`scene_segmented_capture`、`local_capture` 继续以 re-export 的形式提供旧名字，旧写法的 `from femto.app.femto_control_app import save_scan_frame` 仍可用；但 **mock 目标必须指向实际定义处**（`femto.capture.scan_session.save_scan_frame`、`femto.dataset.single_frame_source.resolve_source`、`femto.geometry.rgbd_frames.distortion_maps`），相应 6 处测试已改。

结果：`tools/check_layering.py` 报告 0 条向上依赖；`.venv` 132 个包内模块与 gsplat 运行时 16 个模块 import 通过。

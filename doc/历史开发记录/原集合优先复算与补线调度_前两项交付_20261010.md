# 原集合优先复算与补线调度：前两项交付

第 1、2 项已完成：正常 P2 复算实际接纳，默认 P3 v5 已接入，固定起点新旧重复对照、双格式保存与回读、正式六项检查均通过。最终源码与资产核对见本轮 `final_audit.json`。

本轮按“先做第 1、2 项”完成同输入 P2 的有效复算，以及 P3 的搜索顺序和预算分配。P5 保持原能力与验证边界；P6 跨会话继承仍等待配对实物数据。本轮没有启动相机、重启用户工作台、安装依赖、修改外部 V1.0 方案、提交或推送。

## 实现与接纳规则

P2 固定模型已有同源覆盖时，改用 `retained-first-anchor-ball-coverage-v1`。旧输出只提供分区和待重验父路径，先重新证明原确认集合，再重新分类球外区域，给本轮已复证单元建立边索引后搜索剩余目标。每条索引边计入原邻接预算。复证与新增搜索使用交付 v4 的整单元包含、精确锚点和正长度子边判据；旧状态不能直接安装。首次覆盖及 P5 变宽仍走原 B2。

同输入绑定包含完整 domain、route、顺序扫描种子与固定名义模型。安装前仍用完整共同分区比较，任何原确认整数权重丢失都拒绝，保留原方案、覆盖、显示、人工核对和归档状态。单层 `recalculation_hint_coverage_certificate.{json,npz}` 保存上一份输出，连续复算不递归携带更早提示。当前结果与提示数组合计沿用 256 MiB，原生／便携／P3 历史／发布凭据均核对实际提示数组。提示不是旧覆盖权威；独立回读从当前输入完整复算新结果。

P3 默认报告改为 `femto-coverage-refinement-v5`，覆盖算法为 `interleaved-partition-anchor-ball-coverage-v5`。完整复证原集合后，新扫描叶按最近新种子分组，组间每次取 8 叶，锚点前缀至多 128 叶。当前源面／像素组／根排除后，每 32 个新扫描叶交替执行至多 8 批遗留分类；每批至多 128 叶、根批至多 128。像素组和遗留根优先处理当前未确认面积较大的部分，候选组内按叶面积降序处理。每批分类前检查当前状态，不能覆盖刚确认或已细分的叶。面积和近邻只安排工作，不赋予覆盖资格。

候选仍为 `quality-screened-symmetric-face-slices-v2`，原常规／严格路线、逐边验收及两轮四候选上限保持。旧 v3／v4 引擎、B2 调度与精确几何文件字节未改；显式旧策略和 `coverage_policy=None` 保持各自原行为，旧保存包按原版本重放。

整个操作 120 秒、P2 核心 30 秒、P3 每轮覆盖 4 秒，累计比较／邻接／证明各 1,000,000，原目标和路线预算保持。任何实际选定结果的原确认集合损失必须为 0；被拒绝的原始候选损失单独如实记录。全部面积为原目标权重下的名义面积，坐标仍为 W0／RDF／米，`execution_ready=false`、`physical_accuracy_verified=false`。

便携回读原先在检查原方案和加载路径时，对同一路线执行两次完整几何验证。现在先核对未重定位的原始绑定与区域签名，由路径加载完成一次完整几何、播放器投影、目标及覆盖回放。来源路径的重定位不修改数值路线和覆盖输入，不引入跳过验证标志，也不放宽预算。新增测试核对一次完整几何验证及证据回放，并验证重新封装、重新计算合法绑定的错误播放器坐标仍被拒绝。

## 开发诊断与取舍

全部开发记录保留在 `outputs/iteration_coverage_scheduling_20261010/`，不作为最终验收替代。

- `p2_probe_01`：仅优先复证、尚未建立已复证边索引，新增确认 0；后续增加索引。
- `p2_probe_02`：旧 P2 候选遗漏原确认 17.419225 mm²，未接纳；新 P2 新增 6.883493 mm²、损失 0，并完整回放。
- `p3_probe_01`／`p3_probe_02`：交替频率为 8，分别从原 P2 和新 P2 起步。新增确认更多，但部分重复的预算遗留更大。
- `p3_probe_03`：尝试频率 32，出现遗留增大及无接纳。阶段诊断显示多轮在进入交替前就在原集合复证或前置分类中耗尽时间，不能只归因为频率，也没有据此声称环境问题已定位。
- `p3_probe_04`：恢复频率 8，加入当前未确认面积排序。三次 v5 新增确认 66.710／77.727／102.141 mm²，v4 为 3.220／3.525／14.505 mm²；全部原集合损失为 0。v5 遗留面积三次较少，但前两次遗留叶数和整数权重较多，第三次耗时较长。因此选择该配置后仍进行独立正式验收，不宣称所有指标均改善。
- 首次正式 `product_final`：正常 P2 接纳、P3 两轮接纳、双格式保存成功；保存用时 119.726 秒，随后便携独立打开超过原 120 秒限制。该次失败及已发布包完整保留，不计作完整验收通过。回读超时堆栈位于原 P2 的几何重建，不能据此认定证明损坏。
- `readback_probe_01`：同一新保存包在独立诊断进程完整打开用时 86.896 秒，仍使用原 120 秒限制。调用链与采样确认两次完整路线几何验证的重复，后续据此进行上述修复；采样存在 GIL 偏差，不将样本占比当作精确阶段秒数，也不把单次成功当作稳定性证明。

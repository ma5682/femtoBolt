## 已实施的第一阶段优化

第一阶段限定为“当前页面与任务来源一致”，不将 Skill 的完整产品路线图一次性接入。

| 操作或状态 | 调整后的行为 |
| --- | --- |
| 修改采集任务名、部位 | 顶部即时同步，保留未绑定病例提示 |
| 进入历史结果或返回关联采集 | 明确标为只读回看/历史采集，不把历史数据描述为实时设备数据 |
| 打开另一条记录 | 核验期间显示待加载的来源，避免继续用上一条任务名描述新请求 |
| 新记录读取失败或取消 | 依据页面实际保留的模型恢复原来源；页面保留读取失败/取消说明 |
| 从规划或已保存方案返回采集 | 清除旧方案标题，恢复当前采集任务与部位 |
| 隐藏页面完成加载或保存 | 不覆盖当前可见页面的上下文 |
| 复用已加载规划来源 | 同步完成后清除待加载标记，不在随后计算路线时误报正在读取记录 |
| 任务名包含类似 HTML 的文字 | 按原始文本显示，不解释成富文本 |

`qt_main.py` 只处理显示与页面信号；数据读取、来源核验、相机采集、几何、路线生成、保存格式和质量门禁保持原逻辑。成功加载后才以已安装模型为上下文来源。任务标签不被当作病例身份，也不新增患者坐标、临床治疗或执行能力。

原有顶部/工作流测试全部保留；本任务共新增六项测试：任务编辑及返回、隐藏页面通知、历史采集失败语义、复用来源标记、纯文本标签、异步读取失败恢复原来源。其中前四项于 9 月开始编写，另两项在 10 月收尾中加入。

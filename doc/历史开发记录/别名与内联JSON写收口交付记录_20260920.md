## 为什么这样改

- 模块直接使用公共 API 后，测试、调用点和实现名称一致，避免兼容别名继续扩散。
- 普通 JSON 写入统一经过共享实现，减少父目录创建、编码和临时发布逻辑的重复；任务书列出的事务、索引、偏好和诊断特殊写入保持原位。
- 兼容参数用于逐字节保留历史产物格式，不改变 JSON 键、键顺序、文件名或数据格式。

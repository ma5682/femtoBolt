## 分母与证据

分母为允许、圈内、可信可见的重心采样点代表面积之和，每点取所属面面积/3。它是离散估计，不是精确裁剪曲面面积。禁区、无几何支持和未纳入选区面集合的几何排除；有效的边界预留点仍计入。没有可信几何的范围只记录像素，三维面积和XYZ为null，不编造数值。

遗漏按证据分为额外预留、模拟中心包络边界约束、共边分量无路线种子、距路线距离下界超半径、算法上界未证实及未知；另外单列禁区、无几何和选区离散限制。包络受限不等于证明不能由其他中心覆盖；欧氏邻近但图上界超半径只说明算法未证实，真实原因仍未知。不能把所有断链附近的遗漏归因于断连。

每条采样遗漏保存距离阈值与种子分量证据；像素条目存行程编码和bbox，定量面积与像素不相加。方法、3点重心权重、非均匀密度、算法/报告版本及限制写入报告。

## 操作与限制

单选区域 → 生成覆盖路线 → 路线窗口“查看覆盖报告” → 选择图层或点击遗漏条目 → 查看放大位置/原因 → “返回总览”或切换方法版本页 → 保存方案/导出分享包。旧方案没有新诊断时会明确提示，需重新生成才能获得新版报告。

模拟边界方法保守，可能产生更多链和遗漏；可见性只检查端点/中点，不声称连续接触或真实碰撞已验证。每面3点密度随网格改变，图距离上界可能高估遗漏；像素层是显示证据，不是三维面积或测量几何。细密网格的点和列表可能拥挤，可关闭图层并逐项放大。超过60万样本、1亿边界检查组合、2万遗漏分量、60MB格式化方案或任务时间预算会明确失败，原有效方案保留。

本批未接入机械臂，也未新增实物精度、临床或接触验证。没有删除或覆盖原RGB/Depth、标定、Pose、源模型及历史方案，W0/RDF/米制和测量/展示分离保持。

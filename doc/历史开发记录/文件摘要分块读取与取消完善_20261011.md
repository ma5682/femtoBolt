# 文件摘要分块读取与取消完善

状态：88 项定向测试、真实资产摘要对照、完整真实保存与两种独立完整回读均通过。

## 实现

`io_utils.sha256_file` 使用一个可复用的 1 MiB 缓冲读取全部文件字节，按原 SHA-256 输出摘要，不用文件大小/时间戳代替内容核验，也不缓存接纳结论。读取前、每个块前和完整读取后检查取消/预算；异常继续向上传递，文件句柄在退出时关闭。

原生路线资产与来源校验、便携工程校验、区域导出与旧固定视角分享包校验，以及方案库与网格来源摘要接到共用实现。原生和便携保存/读取传入现有任务检查；既有网格规划来源接口使用默认完整内容检查。清单字段、摘要字节、算法版本、输入范围和预算保持，不修改原始 RGB-D 或已有工程。

## 初步验证

- Unicode 路径、空文件和 1 MiB 边界附近文件，五个公开/兼容入口的摘要与原完整字节 SHA-256 一致。
- 新增专项覆盖 32 MiB 文件的 Python 分配上界、开始前/读取中取消与句柄关闭、原生文件摘要验证取消/篡改拒绝、摘要阶段取消不发布原生结果目录。
- 独立 64 MiB 文件对照，原整文件读取的 Python 临时峰值约 64 MiB，新实现约 1.01 MiB，摘要相同。该数值仅描述摘要计算的临时 Python 分配，不是整个进程内存或整体保存提速保证。
- 26 个既有真实保存资产逐字节摘要对照全部一致，源资产保持。

证据位于 `outputs/streaming_checksums_20261011/`。真实完整 Qt 保存与原生/便携独立完整回读保留原 120 秒预算，进程 RSS 20 毫秒、系统可用内存每秒采样；执行与实物精度标志保持 false。

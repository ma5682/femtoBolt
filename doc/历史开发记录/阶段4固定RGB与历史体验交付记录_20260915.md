## 1. 本阶段实现

### 选中项与无效点击

- 当前点及区域边界使用明显的粉红色和更大半径/线宽；普通点为橙色、普通区域边界为绿色。列表切换、清除当前选中、删除和撤销立即同步读数与高亮。
- 图像外、无网格表面、超出深度范围、参考深度不一致、去畸变后无源像素分别提示；不新增点，不把上一点坐标当作本次结果。
- XYZ 与原点距离继续以 mm、1 位小数显示；保存仍是米制 RDF。距离为 `sqrt(X² + Y² + Z²)`。模型已经位于 W0，不再次应用相机变换。读数精细度不代表实际测量精度。
- 所有新增面向操作的提示同时提供中文和英文。名称/备注尚未应用时，切换选择可选择应用、放弃字段编辑或取消；圈选草稿在切换模式时需要明确放弃。

### 遮挡与区域支持

- 修复旧叠加使用 10 mm 深度一致性门限判定遮挡的问题。前后表面仅相差 5 mm 时，旧版本会显示被遮挡的后方标记。现在显示可见性使用连续投影射线首次命中，`1e-5 m` 只容忍射线数值舍入；10 mm 仍仅用于原始深度与网格的一致性检查。
- 修复边界只检查两端可见、却画穿中间遮挡的问题。沿真实三维边界在固定参考图像上以不超过 1 像素的间隔审核可见性，只画连续有效段。裁剪仅改变显示副本，不移动 XYZ，不重写原始边界，不连接网格孔洞。
- 圈选仍采用原有“多边形内、可见三角面中心”规则，不改为精确曲面裁切，不生成补造表面。
- 区域显示圈内图像像素数、有效几何支持像素数、比例及首帧缺深度处的支持像素数。明确这些是固定图像中的像素支持统计，不是曲面面积、整体覆盖率或补洞验收结论。
- 回读时从绑定的网格、参考深度和图像轮廓重算支持统计。旧高级三维区域没有固定图像轮廓时显示“未记录”，不默认 0 或成功。

### 保存、草稿与关闭

- `AnnotationStore` 使用当前点/区域实际内容的 SHA-256 作为保存基准；不以“有保存文件”或撤销栈非空代替未保存状态。
- 成功保存或完整回读才更新基准；写入失败保持未保存状态；撤销回到已保存内容后恢复干净状态。
- 分别显示未保存标记、未应用名称/备注、未完成圈选。关闭或回读时明确提示；取消操作保留内容。
- 回读在独立候选 Store 完成模型、会话、参考图像、坐标单位及派生数据检查，全部通过后一次替换。失败/取消保留当前内存标记、草稿、字段、撤销历史及保存基准。
- 每次保存仍创建独立目录，区域 PLY 与 JSON 分开写入，JSON 最后写入；不覆盖已有标记、旧模型、RGB-D、标定或 Pose。

## 2. JSON 兼容扩展

顶层标记版本继续为 `version=1`，原 `point_world_m`、`distance_to_origin_m`、`view_reference`、模型几何指纹和坐标系绑定保持。

| 字段 | 来源与单位 |
|---|---|
| `screen_polygon_unit` | `pixel`，固定参考 RGB 图像角点的单位 |
| `screen_polygon_frame` | `undistorted_reference_rgb`，同源去畸变图像坐标 |
| `geometry_support.schema` | `femto-fixed-rgb-region-support-v1` |
| `geometry_support.source` | `bound_mesh_first_hit_and_reference_raw_depth`；继承区域的 `view_reference` |
| `requested_pixels` | 图像内、多边形覆盖的整数像素中心数，pixel |
| `source_pixels` | 其中存在有效原始图像来源的像素数，pixel |
| `geometry_supported_pixels` | 通过最近表面/深度一致性检查的像素数，pixel |
| `unsupported_pixels` | 圈内总像素数减有效几何支持像素数，pixel |
| `reference_depth_missing_supported_pixels` | 首帧缺深度、当前绑定网格有支持的像素数，pixel |
| `support_ratio` | 有效支持像素/圈内总像素，无量纲；没有分母时为 null |

`interpretation=image_pixel_support_not_surface_area` 明确统计口径。回读不信任过期派生统计；旧标记缺少新增字段可兼容。

## 3. 历史与独立对照入口

- 刷新历史保留当前记录的稳定 key；扫描失败保留当前列表，不用空结果覆盖。
- 固定 RGB 入口复用 `AnnotationStore.source_origin_reference()` 的同一来源验证，不只检查几张文件是否存在。缺 manifest、tracking、参考 RGB-D、Pose、K6 标定或初始原点证明时禁用固定 RGB；仍可检查存在的旧 Mesh。
- 打开前检查来源文件是否消失或发生大小/修改时间变化。实际查看器继续执行完整来源和几何绑定，不将历史列表预检当作物理验收。
- 配合主流程新的 `publication.json`：新结果只有匹配模型路径和会话、且 `status=published` 才作为已发布模型。pending/cancelled/failed、缺必需发布证明或证明不匹配的结果显示具体原因，禁用固定 RGB 和同源对照；已有高级几何检查和报告入口保留，原会话记录不被隐藏。旧结果没有 publication 字段时兼容保留，不伪造一份发布证明。
- 新增“同源对照 / A/B/C comparison”，仅有完整来源的已发布模型可进入，点击后由 `app_local_comparison.ComparisonWindow` 后台解析原在线输入。分派回归通过；实际 A/B/C 对照流程由阶段3交付，本阶段未重复执行它。
- 五个按钮分两行；历史列表请求高度调整为 6 行，较大窗口继续自动扩展，最小 760×520 窗口可访问全部按钮。阶段1的质量摘要、报告入口及滚动能力保留。

## 4. 后台预算与退出

- 固定 RGB 窗口每次最多 1 个任务、结果队列容量 1；任务有代次标识和独立取消事件。换模型、关闭后丢弃迟到回调；过期任务不能覆盖新模型状态。
- 单次几何/保存任务预算 120 s，历史扫描预算 30 s。耗时映射、区域统计、遮挡分段、回读及保存位于工作线程；不增加相机读取者。
- 固定查看器预检：PLY 文件不超过 512 MiB、文件头不超过 64 KiB，顶点/三角面数不超过 400 万；图像不超过 8,388,608 像素；标记不超过 2000 项；回读 JSON 不超过 64 MiB；圈选不超过 512 个角点；每区域轮廓最多 30 万显示采样点；叠加缓存不超过 64 MiB。超出时说明原因，不通过减少支持门禁或改动坐标继续。
- 取消在分块计算和文件操作间检查；不能抢占一次正在执行的原生函数或文件写入。关闭后读任务可以退出，保存线程允许当前新文件写入安全返回，未完成的新保存目录可能保留；原文件不回写。

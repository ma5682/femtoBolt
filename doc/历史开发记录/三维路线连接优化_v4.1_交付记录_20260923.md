# 三维路线连接优化 v4.1 交付记录

日期：2026-09-23。基线：`dbac4e3`。范围：从已导出的实测区域 Mesh 生成研发路线，改善同一工作块内不必要的网格绕行；不接入机械臂。

## 本轮实现

- 新 `femto.planning.surface_link_optimization`，仅作用于 v4 原有 `SurfaceLinks` 的网格边回退路径。成功的相邻行边界带折返保持原样。
- 连续同一支持面的折线，在整条替代弦线满足参考图像、选中像素及禁区约束时压缩。三角形凸性及两端面支持检查保证线段仍在原面内。
- 相邻支持面恰共享一条全网格流形边时，交点仅沿该边移动。邻点沿共享边的投影参数为 t0、t1，到边直线距离为 h0、h1，则局部长度最小参数为 `(h1*t0+h0*t1)/(h0+h1)` 并限制到边端点内；两距离均为零时保持原点。固定四轮双向坐标更新属于计算上限，不是临床或几何准入门限。
- 每个候选必须严格缩短局部长度，并复核两侧整边选区/禁区和各自的单面支持。最终逐边重查且全长不得增加。不共享边、非流形、退化支持、约束不满足时保留已存在路径，不用空间直弦穿过折叠面或孔洞。
- 仍按冻结的 1 mm 步长重采样，每条 connector 边的两个端点都属于其目标 `triangle_index`。不移动原扫描行/扫描 XYZ、连接端点、工作块顺序和碎片顺序。
- 缩短的连接以现有 `fragments[].link_methods` 方法计数字典内新增的 `surface_corridor_shortened` 分类记录；TXT 显示版本与缩短数量。文件名、固定 JSON 字段、CSV 列、schema、坐标系、全部门限不变，没有增加依赖。

此方法是局部路径长度优化，不是 Heat Method、BCD 或 NURBS 的完整实现，不保证全局最短、最大转角减小、平顺性、完整治疗覆盖或机械臂执行安全。

## 版本与入口

- 历史“生成/重新生成三维扫描轨迹”和 CLI 默认 `mesh-slice-serpentine-v4.1`。
- 旧常量及 Python API 默认仍为冻结 v4；`selection_algorithm='mesh-slice-serpentine-v4.1'` 显式选择新版。版本只保存到既有 `planner.algorithm_version`，不新增 JSON 参数键。
- CLI `--selection-v4` 使用原版，`--mesh-blocks-v3` 使用 v3.1；两旧版开关互斥。
- v4 和 v4.1 均可根据保存版本重算并逐字典比对；查看和播放显式只读校验、不重规划、不自动升级。新旧结果完成与旧文件清理规则不变。
- `execution_ready=false`、`physical_accuracy_verified=false`、`orientation_fields=null` 保持。阶段 C 八项待决仍未选择；不将候选面准入规划，不放宽补面或几何门限。

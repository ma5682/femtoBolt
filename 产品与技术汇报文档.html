2产品操作流程

1采集与建模建立初始相机坐标 W0，采集可信局部视角并生成完整场景 TSDF 网格。
2打开固定 RGB使用初始彩色画面作为稳定参考，画面缩放和平移不改变涂抹坐标。
3方形涂抹选择工作区域或禁止区域，按住左键连续涂抹；可调整方块大小、擦除和撤销。
4提交单次结果系统把二维涂抹映射到有真实三维支持的表面；计算成功后替换上一条区域。
5保存并导出自动应用名称备注并导出 GLB / PLY / CSV / JSON；历史窗口只显示实际导出结果。
操作原则：用户只需要决定“哪里要保留”和“哪里要排除”。系统根据已有标记自动判断保存方式，不再要求用户额外选择“保留涂抹区域”或“排除涂抹区域”。

4技术实现与数据保护

原始 RGB-D完整画面、深度、标定和时间戳不可变
局部跟踪T_W0_Ct、30 mm 工作半径、10°总旋转范围
TSDF 网格仅积分实测深度；测量默认使用网格
固定 RGB 涂抹参考 RGB 像素坐标中的方形笔刷掩码
三维支持映射可见三角面与深度一致性门禁
区域文件完整三角面、孔洞、边界与来源血缘

方形笔刷

  • 默认边长 40 屏幕像素，范围 8–160
  • 连续鼠标事件之间扫掠方形，避免快速拖动产生断点
  • 每次松开鼠标形成一笔，草稿最多保留 100 笔撤销
  • 超过轮廓复杂度预算时拒绝当前笔，不用凸包填掉孔洞

性能优化

  • 预览刷新合并到最多 30 FPS
  • 拖动时只更新当前涂抹层，背景和已完成区域复用
  • 区域掩码按画面尺寸和轮廓缓存，轮廓变化自动失效
  • 像素判定和轮廓追踪限制在选区包围盒

单次提交与保存

  • 产品页最多保留一个已提交区域
  • 新区域计算成功后原子替换旧区域，计算失败不清空旧结果
  • 名称和备注在继续操作或保存导出时自动应用
  • 区域格式仍兼容研发侧多区域数据

坐标与来源

  • 内部统一 W0 / RDF：+X 右、+Y 下、+Z 前，单位米
  • 初始相机光心是局部模型坐标原点
  • GLB 使用场景节点完成 RDF 到图形坐标变换
  • 每份区域 JSON 记录源几何哈希和导出文件哈希

7质量边界、风险与待验证项

当前已经确认

  • 原始 RGB-D 与派生结果分层保存，区域操作不改源数据
  • 工作区、禁止区及二者组合的自动导出语义已实现
  • 方形笔刷支持尺寸、擦除、撤销、孔洞和分离区域
  • 单次提交只保留一个区域，保存时自动应用名称备注
  • 区域导出保留来源、坐标、单位和文件哈希

仍需现场验证

  • 真实移动补采在不同材质、遮挡和人体体动下的稳定性
  • 已知尺寸、重复采集和不同操作者条件下的物理误差
  • 长时间连续运行的帧率、内存和交互延迟
  • 区域边界与真实目标边界的可重复性
  • 产品打包、隐私、许可证和医疗用途分类门禁
对外口径：当前是研发产品演示，可展示采集、选区、三维映射和文件导出能力；不得把软件分辨率、内部残差或单次目测吻合描述为临床精度、接触安全或机械臂执行能力。

8产品汇报建议与常用入口

建议演示顺序

  1. 展示最新采集结果和固定初始 RGB。
  2. 调整方块大小，涂一个工作区域。
  3. 切换禁止区域，在工作区内扣除一部分。
  4. 点击完成，展示粉色单次结果。
  5. 点击“保存并导出当前结果 GLB / PLY”。
  6. 打开导出文件夹，说明 GLB / PLY / CSV / JSON 的用途。

当前不进入产品演示

  • 标记回读、实测距离、同位置几何诊断
  • 精度测试报告和研发验证记录
  • 区域方案保存、另存、草稿恢复和规划工作台
  • 路径生成、机械臂或治疗执行表述
  • 3DGS 训练与旧验证数据

# 三维采集与规划工作台 · PySide6 原型

本目录是独立的桌面产品原型，不导入 `femto/`，不连接相机或机械臂。没有可回放项目时使用 Mock 数据；检测到仓库中的已保存重建结果时，启动页会自动进入“项目回放 · 只读”模式。

## 启动

在本目录运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以直接运行自包含单文件版本：

```powershell
python standalone.py
```

单文件由 `python build_standalone.py` 从可编辑模块生成；在当前仓库内运行时同样支持项目回放，脱离仓库运行则自动退回 Mock 演示。

建议在 1600 × 900 或更高分辨率预览；最小窗口为 1180 × 720。需 Python 3.10 或更新版本。

## 演示路径

1. 启动后优先读取仓库内的 `datasets/scene_*_local_*` 与 `outputs/complete_demo_*/reconstruction`，校验区域、网格、参考 RGB/深度和轨迹文件后显示项目回放；源文件不会被修改。
2. 回放模式可在 RGB、深度热力图、选区 RGB、三维网格、点云和路线图之间切换。区域和路线保留原始记录，缺口以粉色端点标出。
3. 若没有可回放项目，则进入模拟任务，顶部常驻栏显示患者、任务、坐标系和设备。
4. Mock 模式下点击“建立参考位置并开始采集”，观察已接纳区域变化；点击“完成采集并检查质量”。
5. 在固定 RGB 画面中使用规划区/禁入区画笔拖动标记，点击“确认标记并检查三维几何”。
6. 在第三步切换直接行距与宽度计算模式，点击问题项定位位置，再打开规划预览摘要。
7. 核对摘要后保存规划方案（预览）。回放模式只能查看，不能重新规划或执行治疗。

顶部“研发场景模拟”可切换五种演示状态：正常流程、数据缺失需补采、三维几何缺失、禁区干涉 / 轨迹断开、参数超限。切换会重置 Mock 任务。历史记录为侧边栏，不是主流程的一步。

流程与页面分工见 [DESIGN.md](DESIGN.md)。

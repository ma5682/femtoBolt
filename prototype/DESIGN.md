# 三维采集与轨迹规划工作台：交互与视觉规范

本目录独立于现有 Femto Bolt 业务程序。目标是让操作者在同一工作台中看清当前阶段、检查结果与下一步操作。当前修改范围是 PySide6 产品原型，不改变现有采集、重建或规划算法。

## 1. 启动与数据模式

在仓库根目录运行 `python prototype/main.py`，默认使用 Mock 演示。需要查看历史项目时显式运行 `python prototype/main.py --replay`，只读载入已保存数据，不能写回或重新规划。`start_femto_app.cmd` 启动现有业务程序，不是本轮原型入口。

最低窗口尺寸 **1280 × 760**，建议 **1600 × 900**。左侧里程碑在高度不足时滚动，底部设备状态和主操作保留在固定位置；右侧参数区允许独立滚动。

设备状态必须区分三种来源：

- 未开始：相机未就绪，RGB/深度未获取，参考位置未建立。
- Mock 采集：设备和图像明确标注“模拟”；参考位置与生成结果也是模拟状态。
- 项目回放：显示已保存数据，标注“只读”和“相机未连接”，不冒充实时采集。

不编造帧率、分辨率、GPU、稳定性或覆盖率作为实时遥测。Mock 视口使用 Qt QPainter 绘制示意表面、点云、区域与路线，不是真实患者解剖数据。

## 2. 流程与状态映射

正常操作路径：建立参考位置并采集 → 完成采集质量检查 → 标记规划区/禁入区 → 检查三维支持 → 核对轨迹与参数 → 规划确认 → 保存预览方案。

左侧展示六个里程碑，底层沿用原有四阶段状态机：

| 左侧里程碑 | 原有阶段 | 当前/完成判据 |
| --- | --- | --- |
| 01 建立参考位置 | 0：采集 | 待开始时为当前；参考位置建立后显示完成 |
| 02 移动补采 | 0：采集 | 采集中为当前；提交采集检查后完成本轮采集 |
| 03 检查模型 | 0：采集 | 检查中、检查失败或检查完成时为当前；通过后完成 |
| 04 区域标记 | 1：标记 | 标记页为当前；区域三维支持有效后完成 |
| 05 轨迹规划 | 2：规划 | 规划页为当前；当前版本轨迹有效后完成 |
| 06 规划确认 | 3：确认 | 确认页为当前；保存当前方案后完成 |

点击里程碑只请求切换到对应的既有页面，不暗中开始采集、重置任务或生成轨迹。未满足前置条件时禁止跳转，检查期间保留状态保护。已完成的采集里程碑返回当前采集页面，不重放历史动作。

质量不足时提示缺失位置并提供“继续补采”；区域缺少三维几何时保留已画区域与参数，返回补采后继续。轨迹断开或参数超限时留在规划页处理，不能进入最终确认。“重新采集”会清除采集草稿、标记和未保存规划，需明确确认。

## 3. 页面信息架构

| 位置 | 内容 |
| --- | --- |
| 顶部 | 品牌、工作台名称、任务/模式与参考状态，研发场景、历史和设置入口 |
| 左侧 | 六个流程状态节点与连线；下方固定设备状态和模拟/回放标识 |
| 中间 | 主要图像视口；采集页一级切换 RGB / 深度 / 三维预览，三维内部再选点云/模型 |
| 右侧 | 当前阶段状态、采集信息、帧数，或标记检查、常用规划参数、确认摘要 |
| 底部 | 一句当前提示、弱化的状态详情/更多操作、一个固定位置的主操作按钮 |
| 历史 | 次级只读查看入口，不是主流程的一步 |

主操作依次为“建立参考位置并开始采集”“完成采集并检查质量”“确认标记并检查三维几何”“计算轨迹路径/进入最终确认”“保存规划方案（预览）”。文案随实际状态变化，避免显示多个竞争的主动作。

右侧先显示 24 px 当前状态，再显示紧凑数据行。说明放在数据下方，使用次级文字，避免把操作区域变成说明书。画笔、禁区、擦除、撤销与清空放在视口附近；回放中禁用修改。

## 6. 参数与业务边界

行距可直接填写，或按有效作用宽度 × (1 − 重叠率) 计算。重叠率允许 **0–90%**，最终行距允许 **0.5–100 mm**；非法输入拒绝，不自动夹到边界值。默认值明确标为“演示占位值，非设备参数”。保存包含最终行距、来源、参数性质和模型/区域版本。

治疗深度、治疗头外壳尺寸和外壳避让余量作为“暂未参与规划”的待用参数，当前演示记录没有实测数值，不参与行距计算。有效作用宽度不等同于外壳直径。

连接段不计入扫描。没有真实有效作用宽度时不计算治疗覆盖率；只展示几何覆盖状态、缺口和未确认区域。示意数据与历史回放都不构成治疗覆盖或临床精度验证。

本原型没有工具姿态、碰撞检查、焦点层定位或治疗执行能力，不提供“开始治疗”。当前范围为产品交互与视觉核对；保存的是研发规划预览。

## 7. 走查重点

走查正常、质量不足、区域缺失几何、路线断开、参数越界五种场景。核对当前步骤与完成状态是否可信，主按钮是否始终可见，错误位置与提示能否对应，补采是否保留区域与参数，回放能否清楚区分保存数据和实时设备。

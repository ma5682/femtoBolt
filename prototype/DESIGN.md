# 三维采集与规划工作台：第一轮产品原型

本目录独立于现有 Femto Bolt 业务程序。工作台支持两种明确模式：没有项目文件时使用 Mock 演示；检测到已保存重建结果时进入“项目回放 · 只读”，读取 RGB、深度、网格、区域和轨迹，但不写回源文件、不执行规划。目标是让医师在单一工作台上理解当前任务、下一步操作及阻断原因。

## 1. 医师操作流程

Mock 模式：查看任务确认栏 → 建立参考位置并采集 → 完成采集质量检查 → 在固定 RGB 标记规划区/禁入区 → 检查三维支持 → 计算轨迹路径 → 查看缺口和覆盖状态 → 进入最终确认 → 保存规划方案（预览）。回放模式只查看同一流程中的已保存结果。

正常流程只有一个醒目的下一步按钮。采集质量不足时，画面标出缺失位置并提供“继续补采”；区域缺少三维几何时保留已画区域，补采后恢复；轨迹断开时定位断点，留在规划页处理，不进入运行预览。

## 2. 页面信息架构

| 位置 | 内容 |
| --- | --- |
| 顶部 | 项目名称、本地路径和研发场景切换；连接与采集遥测集中到底部状态栏 |
| 左侧流程 | 四个界面状态：三维采集、区域标记、轨迹规划、运行预览；最后一项是第三步的确认子状态，不代表治疗执行 |
| 中间 | 始终显示主要图像：RGB、深度、点云/表面、规划区、禁入区、缺失几何和轨迹；工具贴近图像 |
| 右侧 | 只显示当前步骤的质量检查、常用参数或确认摘要；详细说明折叠 |
| 底部 | 一句当前提示、弱化的返回/辅助操作、一个主操作按钮 |
| 历史 | 次级入口；当前任务不经过历史列表 |

## 3. 每步核心操作

| 步骤 | 主操作 | 可见检查 |
| --- | --- | --- |
| 三维采集 | 建立参考位置并开始采集 → 完成采集并检查质量 → 进入区域标记 | 设备连接、空间基准、接纳视角、深度、位姿、表面连续性 |
| 规划区标记 | 画规划区/禁入区 → 完成区域 | 固定 RGB、三维支持、选中但缺少几何的位置 |
| 轨迹规划 / 运行预览 | 查看轨迹 → 调整参数 → 查看预览摘要 → 保存规划方案（预览） | 扫描段、不可连接间隔、禁入区、断开、边缘/孔洞周边；摘要含来源、行距、版本和检查结果 |

行距可直接填写，或按有效作用宽度 × (1 − 重叠率) 计算。重叠率允许 0–90%，最终行距允许 0.5–100 mm；非法输入拒绝，不自动夹值。默认值明确标为“演示参数，非设备参数”。治疗深度、治疗头外壳尺寸和外壳避让余量只记录为“暂未参与规划”。

## 4. 现有入口的取舍

- 采集页的多个同时显示的按钮按状态收束为一个主动作；RGB、深度、点云仍可切换查看。
- 历史采集、固定 RGB 选区、轨迹历史不再要求逐个开窗；只在需要追溯/导出时使用历史入口。
- 规划区、禁入区、擦除、撤销和清空工具贴近中间画面；不放进规划参数区；项目回放模式隐藏并禁用这些修改工具。
- 轨迹报告的逐块技术字段放到详情；首页先显示位置、是否连续、是否进入禁入区、缺口及其处理动作。
- 不在主流程中显示采集日志、文件目录、PLY/GLB 格式、算法版本等研发字段。

## 5. 画面反馈与异常

质量不足、几何缺失、轨迹断开均在中间画面直接高亮相应位置；底部用一句话说明原因与下一步，右侧列出检查项。普通异常不弹窗。清空已画区域等破坏性操作才需要确认。

## 6. 范围与核对

本版只做产品结构与交互验证。Mock 表面和轨迹不是患者数据；真实项目回放只读显示，覆盖数字不是治疗覆盖结果。没有有效作用宽度时不计算治疗覆盖率；只显示几何覆盖状态、缺口和未确认区域。不提供“开始治疗”。当前项目没有工具姿态、碰撞检查、焦点层定位或治疗执行能力，界面始终标为“规划预览，不可执行”。

走查场景：正常、采集质量不足、区域缺失几何、轨迹断开、参数越界。重点看首次使用者能否直接找到当前主操作，能否从画面理解错误位置，并能否在补采后保留已画区域。
